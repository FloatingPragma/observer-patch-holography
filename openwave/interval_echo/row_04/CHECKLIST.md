## Reproduction

The contact receipt and launch census are reproducible from the audited RER revision with Python 3.12, NumPy 2.3.5 and SciPy 1.18.1. Run from the repository root.

```sh
python -B openwave/interval_echo/row_04/native_check.py
python -O -W error -m model.experiments.interval_echo_consensus.record_receipt --extended
python -O -W error -m model.experiments.interval_echo_consensus.primitive_collar
python -O -W error -m model.experiments.interval_echo_consensus.row_four --all-launches
```

To repeat the cross-check, use OpenWave’s board loader and generator on the hash-checked 20-cell board. For each internal launch call its `chebyshev` function at exposures 1, 5, 7, 17, 31 and 37, retaining the 30 internal seams of the launch cell in sorted order. Square the amplitude magnitudes and append the quiet probability as their complement. Save the array in strength (8, 0, −8), cell, launch, exposure and outcome order, with shape `(3, 20, 30, 6, 31)`. Passing its path to `row_four --all-launches --compare FILE` checks every distribution.
