# Sender latency in the midpoint experiment

In a follow-up using the same recorded radar arrivals, allow each sender an unknown constant service delay in addition to an arbitrary positive rate. On all distinct-port appointments a nonnegative geometric distance requires the delay to be at most the shortest measured range for that sender. Give each of the six senders this most favorable bound independently. Check all fifteen physical midpoint conditions and all common lotteries of interior addresses again. A positive residual excludes that entire affine calibration family. A residual whose interval contains zero supplies no positive evidence of a midpoint. For edges that survive an upper bound on latency, also check independently observed candidate addresses against the required midpoint readings. Any witness gives only a necessary condition unless the same delays and physical middle stations work for all edges.
