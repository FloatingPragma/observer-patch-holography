# Can the measured response be distributed over ordinary service histories?

The uniform ordinary write uses all six enrolled sender addresses and two flight signs. A single mass normalization on that lottery is a restrictive hypothesis. Allow a separate nonnegative amount of ordinary write for each of the twelve sender/sign histories and a new allocation at each of the three flight windows. Put no upper bound on the amounts. The history specifies where and how the probe services the same memory. This experiment does not relocate the marked source heads to arbitrary positions in a galaxy.

Calibrate every column independently. Start once from the ordinary parked-energy write and once from the reference, physically perform the dense midpoint interrogation in both, and measure the active terminal head records with separate ensembles. For each ordinary-minus-reference difference infer the effects on the two marked forces, the two total momentum rates, the two integrated impulses and all thirty capped radar means. Scale the linear differences by the registered one-in-256 pulse fraction. Check the uniform average against independently counted ordinary material and radar controls.

Test the sparse-minus-dense target with the directly observed material records, using the higher precision repeat for the contracting window when available. Repeat with the independently measured source head predictions for those material readings. Use the same thirty directly measured radar contrasts in both tests. Evaluate both full-flight impulses alone, both marked forces alone, all six material readings, radar alone, and the combined readings. A single allocation must reproduce all the enrolled readings in each test. Permit each true column entry and target entry to vary independently across its uncertainty interval; that relaxation favors the ordinary-source explanation. If infeasible, give rational nonnegative weights on the original interval inequalities that separate the observed target from every nonnegative allocation. Retain unresolved tests. A feasible relaxed fit by itself does not establish a common physical source. The original one-in-256 calibration, the earlier clock signs and the lower-exposure material data were known when designing this follow-up.
