For the matched-readings replay, set `OPENBLAS_NUM_THREADS=1`, `VECLIB_MAXIMUM_THREADS=1` and `OMP_NUM_THREADS=1` before starting Python. The full primary replay recomputes the meter matrix, optical derivative, positive preparation recipes and counts. The full precision replay reads the primary source coefficients and checks the SHA-256 binding and every count against the separate receipt.
