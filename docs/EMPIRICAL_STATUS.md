# Empirical status and repair-rule comparison

**No retained laboratory comparison selects a native record law.**
The repository contains reproducible comparisons with physical measurements,
conditional postdictions, hardware implementation tests and executable designs
for distinguishing repair rules. These have different evidential roles. None
establishes that the executable observer reproduces the full range of physical
observations or supplies an OPH-specific empirical confirmation.

The target is agreement between observers' measurement statistics and their
effective interpretations. It does not require a fundamental spacetime object.
It does require identifying the same preparation, intervention and readout in
the model and the experiment before comparing their probabilities.

alternative fine-structure closure maps.

Every admissible record law has the same diagonal action, so classical
record data assign the same probabilities under all of them. For C and E the
statement is proved in its strongest form. For every one of the 78 load
basis states, the C and E instruments have the
same joint law of coin, current and post-repair load when E's extra contrast
label is summed out. The equality continues by induction through finite
adaptive classical protocols from diagonal preparations with the same
populations, using common coin/current access and outcome-by-outcome
diagonal-preserving controls, with the same scheduler and stopping rule. Under
that shared observation contract, any admissible classical record dataset
has likelihood ratio `L_C/L_E=1` wherever defined. Feedback using E's extra
contrast label, or coherent interventions, is a different contract.

For the public oscillator and Bell records there is an additional problem:
no identified native C/E apparatus map supplies the two laboratory
likelihoods. “Not specified” is not a computed Bayes factor of one. Better
oscillator fits, classical agreement, and a Bell-null rejection cannot fill
that missing map.

The exact [source discrimination](../model/observer/source_discrimination/README.md)
also identifies E as C followed by retained seam-parity measurement. Forgetting
the extra record does not undo its dephasing. A measured E-like response can
therefore distinguish the C/E instrument hypotheses only with the relevant
ancillary/environment records and errors fixed; unrestricted unmodelled
parity recording can make C look like E.

### Does the empirical pipeline test repair and consensus?

The current oscillator prediction functions have no C/E selector: they execute
source-compiled controls for a supplied apparatus. Their numerical agreement
tests that conditional preparation/dynamics/readout model. It does not show
that changing the native repair instrument would spoil the agreement.

The [repair-observability checks](../model/identifiability_checks/README.md#repair-and-consensus-in-an-empirical-comparison)
also exclude a simple attempt to close this gap. Actual C/E operations have
the same native diagonal-block evolution, even with an entangled work/reference
input. Common-record-controlled work and work-record-controlled seam choices
preserve this equality. A detector restricted to work/reference and the common
records cannot distinguish the two laws. Coherent native access or a different
coupling must be identified physically before the native distinction reaches
that detector; adding more of the same classical feedback does not suffice.

The exact replay checks every native matrix unit on all 30 seams
(`182,520` cases), plus 504 complete adaptive record histories, including
stopping, zero-probability outcomes and an untouched reference. The retained
native quantum outputs differ even when every accessible work/reference
output agrees. Thus the equality is a proved limitation of this observation
interface, not evidence that the two instruments are identical.

The local compatibility solver executes repair for all 130 existing
anharmonic endpoints, retaining all four outcomes per endpoint and reproducing
the existing 125-observation RMSE `0.2876427868`. Preparation calibration and
apparatus maps are unchanged. Fair orders reproduce the complete chronological
output law; an unfair order need not close. A changed supplied action can also close
while giving different observations. This extends the implementation check
to local history completion, not to autonomous meaning selection or the full
consensus tower. Native C/E seam events have not been shown to implement the
global history solver. Its update count is not the apparatus's duration.
The maximum full output-density discrepancy against the separate chronological
executor is `1.79e-14`. This is a numerical implementation check; it does not
reduce the empirical RMSE or certify an apparatus error budget. At the fixed
schedule-control endpoint, changing the supplied action changes the complete
four-outcome law by total variation `0.16139288`, although both histories
satisfy their respective local constraints. Agreement alone does not select
the action.
