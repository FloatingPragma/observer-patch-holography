Source material for the learning app and blog. This text presents the
results and their boundaries without release history or tracker language.

## The closure principle

OPH has three local axioms: the twelve-port observer-screen architecture,
observer agreement, and conditional maximum randomness. A global closure
principle sits beside them. It is not a fourth axiom.

The universe is modeled as a self-referential structure. The simulating and
simulated descriptions are one system. When an outer construction and an
inner readback are independently proved to denote the same invariant,
self-identity forces their values to agree. That equality is compulsory.
It does not manufacture the physical bridge that says the readings are the
same quantity, nor does it prove that their return map has a solution.

A complete closure therefore has four parts:

1. an outer construction;
2. an inner readback;
3. a typed bridge showing that they read the same invariant;
4. existence, uniqueness, and stability on the physical domain.

The screen-grain proposal is

    P = phi + sqrt(pi) / A_T(P).

Its declared map has one interval-certified fixed point. Connecting that
map to the physical low-energy electromagnetic coupling requires
same-scheme hadronic transport.

## The capacity candidates

The direct universe-level proposal is

    N = log M_0(U_N),

where the correctable public-record code of a universe with capacity `N`
is read back from inside that same universe. This is the clearest
self-referential form. The completed finite source class contains
incompatible fixed sets, so it does not select a unique cosmic value. A
successful direct closure needs an additional source law.

A separate common-load branch compares a screen reading with an
electroweak reading. Its uncorrected balance is

    N_0 = pi exp(6 pi / (P alpha_U)).

On the finite screen branch used for the correction, declared total reserve
expectation `P/4` and six-class equidistribution give `P/24` as the presence
probability of each declared class. It is not a load measured in nats. If one
class is physically selected, its scalar-weighted receipt is discharged, and
its normalized finite collar-survival factor is proved to act on global
capacity, the source-typed candidate is

    N_presence = N_0 (1 - P/24)
               = 3.2921 x 10^122.

A Poisson or continuum reading gives

    N_Poisson = N_0 exp(-P/24)
              = 3.3001 x 10^122.

The exponential formula needs a separate mean-count or continuum carrier.
The finite projection theorem does not supply it. Neither branch has a
derived map from the local collar event to the global capacity.

The Planck base-LambdaCDM chain gives a comparison coordinate near
`3.313 x 10^122`. The finite-presence candidate is about `0.63%` below it;
the Poisson candidate is about `0.39%` below it. Both formulas were examined
after the cosmological target was known. These are retrospective
near-matches, not predictions, and the numerical proximity does not choose
between the physical readings.

The open mathematical work has a precise shape:

- identify the screen and electroweak readings as one physical load;
- construct the physical seam and global-form action;
- decide how a connected finite collar factor composes into a universe-level
  capacity;
- construct the horizon-record bridge required for a cosmological reading;
- keep the finite presence and Poisson carriers distinct.

## The Standard Model gauge algebra

The carrier geometry fixes the twelve-dimensional response space and its
symmetry action. Geometry alone leaves several equivariant dynamics. The
first axiom restricts the response to a complete faithful compact reversible
algebra. The second axiom requires overlap rechartings to act internally on
that same response.

The carrier action fixes exactly one line. A centreless alternative built
from four copies of `su(2)` has a fixed-space dimension divisible by three,
so it cannot realize that line. The centre is therefore one-dimensional.
Compact-simple classification leaves the unique semisimple split
`11 = 3 + 8`, giving

    u(1) + su(2) + su(3).

This forces the abstract local Standard Model Lie type without assuming an
ambient gauge group. The matrix current, physical matter action, global
quotient, family multiplicity, and laboratory current remain separate
constructions. The fifteen-state matter witness and its common `Z6` kernel
are exact inside their declared representation class.

## Editorial instructions for learning and web surfaces

- State the three axioms and the closure principle separately.
- Say that self-identity forces equality after the same-invariant bridge is
  proved.
- Do not call either capacity near-match a prediction.
- Use the finite-presence formula as a source-typed conditional branch, with
  the total-reserve, class-equidistribution, one-class, scalar-weighted, and
  global-attachment premises stated.
- Present the exponential formula only with its extra mean-count or
  continuum-carrier premise.
- Use “Planck base-LambdaCDM comparison coordinate,” not “measured cosmic
  capacity.”
- Keep code names, tracker numbers, release history, and internal theorem
  labels out of informal explanations.
- Distinguish the forced abstract gauge Lie type from the conditional matrix
  current, matter action, and physical global quotient.
