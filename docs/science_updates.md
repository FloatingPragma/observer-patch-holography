## The closure principle joins the axioms

The framework states three axioms: the oriented twelve-port observer
screen, observer agreement, and conditional maximum randomness. As of the
2026-07-31 corpus revision, one modeling principle is stated beside them on
every surface that presents the basis: the papers, the compact proof, the
repository README, the canonical axiom reference, and the book.

The principle: the universe is modeled as a self-referential fixed point,
so the simulating description and the simulated description are one
system. Any quantity that can be read from the construction side and read
back from the inside must then satisfy two requirements.

- Consistency. The readback return map closes on a unique fixed point on
  its declared domain.
- Identity. The two readings are readings of one invariant. Each identity
  is a separately typed physical attachment, never a free move.

The principle is a statement about the model class, and every axiom count
in the corpus stays at three. Its value is that it explains where the
quantitative closure equations come from: they are the consistency and
identity conditions written out for the two quantities the framework reads
twice.

The first instance is the screen-grain equation for the pixel constant,

    P = phi + sqrt(pi) / A_T(P),

The comparison with the measured fine-structure constant stands at the

The second instance is the capacity equation of the next section.
