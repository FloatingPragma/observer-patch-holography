# Computational evidence archives

This directory contains scientific data and receipt packages cited by the
papers. Each package states its own replay and claim boundary.

- [`icosa_82k_protected_consensus_20260827_r1/`](icosa_82k_protected_consensus_20260827_r1/)
  is the curated level-six icosahedral OPH-FPE run. It includes the protected
  authority, primitive and terminal arrays, full patch state, compressed
  observer rows, and a standalone exact normal-form verifier.
- [`vertex12_signed_record_feedback_20260827/`](vertex12_signed_record_feedback_20260827/)
  is the separate literal record-feedback receipt. It includes all finite
  events and controls, parent and implementation pins, and the output of a
  producer-free verifier.
- [`particle_simulation_receipts/`](particle_simulation_receipts/) publishes
  the hash-bound report receipts for the calibration-null and direct
  permutation-transport assays cited by the particle paper. Their upstream
  raw arrays are not included.
- [local_domain/](local_domain/) is the complete current 11-file local-domain
  family used by the spacetime, particle, and cosmology papers. It contains
  the compressed stage-one arrays, all four staged receipts, the five
  downstream finite-interface receipts, the binding manifest, and a
  standard-library archive checker. The checker validates byte custody,
  schemas, the 2,304-event identity, exact semantic replay, and every recorded
  nonpromotion flag without importing simulator code.
- [`causet_likeness/`](causet_likeness/) mirrors the complete receipt and a
  standard-library checker. The current 2,304-event local-domain cut is not
  similar to the synthetic four-dimensional reference controls at the frozen
  ordering-fraction gate; this is a current-cutoff diagnostic, not
  manifoldlikeness or a physical no-go. A separate four-seed geometry-seeded
  control compiles all twelve finite Minkowski (3+1) causets exactly through
  authenticated provenance without declared parent lists. Direct cover and
  transitive order, coordinate-map injectivity, sampled-interval membership,
  and carrier/order restrictions are independently rechecked. These give an
  exact seeded order embedding at each rung. Its conjunction with the
  separately checked fixed-volume Poisson count predicate is a
  construction-seeded causal-set faithful-embedding control. Geometry,
  density, event/read material, and coordinates are imported, so this is
  grammar compatibility rather than OPH selection or an OPH count-to-volume law. The
  simulator's producer-free verifier reconstructs both controls and their
  fail-closed mutations at
  [`oph-physics-sim` revision `6080f3a`](https://github.com/muellerberndt/oph-physics-sim/tree/6080f3a4045b7cbd821476a0a8fa0a6b57eeeeab).
- [`source_causal_history_family/`](source_causal_history_family/) mirrors the
  complete simulator receipt, its theorem-level publication projection, and a
  standard-library checker for the independently generated and replayed
  24-to-384-event source-history family. It records exact induced-prefix
  custody, constant width two, and the failed prescribed single-frame
  source-port placement. On the 24-event member all 30 Hasse links are
  authenticated reads with carrier-local normalized null-ray labels; the used
  port ranks are 2, 1, and 2, pooled rank changes under an independent carrier
  relabeling, and naive integration is path-dependent. These results supply no
  local rank-three cone or inter-carrier gluing, and failure of the prescribed
  placement is not a no-go for other placements. The upstream producers and
  independent replay are pinned at
  [`oph-physics-sim` revision `6080f3a`](https://github.com/muellerberndt/oph-physics-sim/tree/6080f3a4045b7cbd821476a0a8fa0a6b57eeeeab).

Evidence directories are not interchangeable. A carrier count shared by two
packages does not make one run evidence for the observable tested by another.
