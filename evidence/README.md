# Computational evidence archives

This directory contains scientific data and receipt packages cited by the
papers. Each package states its own replay and claim boundary.

- [`icosa_82k_protected_consensus_20260827_r1/`](icosa_82k_protected_consensus_20260827_r1/)
  is the curated level-six icosahedral OPH-FPE run. It includes the protected
  authority, primitive and terminal arrays, full patch state, compressed
  observer rows, and a standalone exact normal-form verifier.
- [`vertex12_signed_record_feedback_20260827/`](vertex12_signed_record_feedback_20260827/)
  is the separate literal record-feedback receipt. It includes all finite
  events and controls, parent and implementation pins, and the output of a
  producer-free verifier.
- [`particle_simulation_receipts/`](particle_simulation_receipts/) publishes
  the hash-bound report receipts for the calibration-null and direct
  permutation-transport assays cited by the particle paper. Their upstream
  raw arrays are not included.
- [`causet_likeness/`](causet_likeness/) mirrors the complete exploratory
  interval-comparison receipt and a standard-library checker. The current
  2,304-event local-domain cut is not similar to the synthetic
  four-dimensional reference controls at the frozen ordering-fraction gate;
  this is a current-cutoff diagnostic, not manifoldlikeness or a physical
  no-go. The simulator's producer-free verifier reconstructs the interval
  population and Minkowski, de Sitter flat-patch, and nonmanifold controls at
  [`oph-physics-sim` revision `6080f3a`](https://github.com/muellerberndt/oph-physics-sim/tree/6080f3a4045b7cbd821476a0a8fa0a6b57eeeeab).
- [`source_causal_history_family/`](source_causal_history_family/) mirrors the
  compact theorem-level projection of the simulator's independently generated
  and replayed
  24-to-384-event source-history family. It records exact induced-prefix
  custody, constant width two, and the failed prescribed single-frame
  source-port placement; this ansatz is not source-derived inter-carrier gluing
  and its failure is not a no-go for other placements;
  the full embedded-event receipt and producer-free replay are pinned at
  [`oph-physics-sim` revision `6080f3a`](https://github.com/muellerberndt/oph-physics-sim/tree/6080f3a4045b7cbd821476a0a8fa0a6b57eeeeab).

Evidence directories are not interchangeable. A carrier count shared by two
packages does not make one run evidence for the observable tested by another.
