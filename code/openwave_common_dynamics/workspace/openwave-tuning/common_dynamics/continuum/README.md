# Carrier walk to continuum records

The same local carrier walk has a derived scalar–longitudinal wave limit,
with both propagation signs and stationary modes retained. Exact matrix
identities and a uniform error bound compare its complete terminal records
with continuum records on a shared clock. The theorem assumes a bandlimited
preparation and does not supply an interacting or Maxwell field limit.

Run `python continuum.py` for the exact algebra, complete-state controls and
source checks. [PROOF.md](PROOF.md) states the mathematical domain;
[RESULT.json](RESULT.json) contains the source-bound results. A native
implementation across the refined family and its precision scaling are
separate obligations from the size-two compiled source.
