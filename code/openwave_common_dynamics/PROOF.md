## Isolated replay and equality

The snapshot binds each original path and byte string. Static import discovery
adds transitive local modules omitted by producer manifests, without changing
their source bytes. The public workspace contains one copy of each such
path. The two-charge consumer requires its own `inputs` layout; the runner
materializes those paths only in its disposable execution workspace from the
flat manifest, checks each materialized hash and uses no links or live files.

Every experiment runs in a fresh interpreter with isolated environment and
site startup disabled. Only explicitly selected standard-library and numerical
runtime directories are admitted outside the snapshot. The guard denies
external project/data reads and subprocess launches, restricts writes to
declared regenerated outputs, tests an external-read rejection, and checks
the origins of every imported module. Numerical dependencies are restricted
to NumPy, SciPy, SymPy, mpmath and the carrier's declared graph/schema dependencies.
Optional installed packages are excluded by an import gate. Denied optional
runtime reads are recorded and obtain no data. The dependency versions and actual local import
closure are recorded for each execution.

The integration result and block program, and the independent two-charge
result, are deleted in the disposable workspace before execution. Their
regenerated bytes must exactly match the pinned originals. Every other
source byte must also remain unchanged. Quantum-cycle probabilities use the
declared `2e-12` numerical tolerance, while native words, fine effects,
repetition counts and rational certificate values are compared exactly.
The reference factors also compare their exact words, encoder and rational
certificate values. Their complete primitive stream hashes are archived
producer evidence, not a claim that this replay re-expanded those streams.
