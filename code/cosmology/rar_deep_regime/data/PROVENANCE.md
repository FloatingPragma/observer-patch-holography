# SPARC data snapshot

Files `ReadMe`, `table1.dat`, and `table2.dat` are the CDS/VizieR copies of
catalogue J/AJ/152/157 (Lelli, McGaugh, Schombert 2016, AJ 152, 157),
retrieved 2026-08-21 from
`https://cdsarc.cds.unistra.fr/ftp/J/AJ/152/157/`. They are stored unchanged
so that the deep-regime diagnostic runs without network access. The data are
an external observational input and carry no OPH derivation content.
