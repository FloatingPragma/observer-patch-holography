# Can the same inventory cover every measured radius?

The outer-ring result is known. Its two-error budget admits a narrow intersection with the nominal DESI+BBN profile interval. Use the same 118 galaxies and every radius passing the existing cuts. Work with the measured speeds and their catalogue errors, a single distance, inclination, stellar normalization and gas normalization within each galaxy's specified box. At each radius independently allow a circular speed anywhere within its box. Give each galaxy any nonnegative spherical distribution of the available extra stock, with unrestricted nondecreasing enclosed mass. Grant an unrestricted residual stock outside the last measured orbit.

Test the generous cap at the upper cosmic profile endpoint, the highest cap of any of the three stocks, and unlimited inventory. Include the outer-ring-only replay, individual galaxy verdicts and the sample counts in each nuisance box. Write an explicit construction of a mass profile whenever the constraints admit one. Provide a numerical margin for infeasibility. If the most favorable cosmic inventory fits every selected orbit, that is a consistency result with fitted radial profiles. If the test rejects, distinguish an inventory shortage from a failure of the shape constraints even with unlimited inventory. The ring cuts use measured speeds and the same catalogue underlies the outer test. No independent discovery significance is assigned.
