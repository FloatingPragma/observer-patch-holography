# Shared physical units

The native clock, particle phase and routed electric flux determine one
common conversion to physical measurements. The executable reconstructs
the exact coarse field coordinates and derives the conditional wave speed
and charge coupling from the same electric and magnetic coefficients.
The quantum field-state and interacting continuum hypotheses are explicit.

Run `python units.py`. The source-pinned result is [UNITS.json](UNITS.json),
with the derivation in [PROOF.md](PROOF.md). No observed constants or
species masses enter this calculation.
