## Source, criterion and hypotheses

The literal row is “emergent ω² = k² + m² for matter waves”. This package

readout with vanishing implementation error. It does not add an observed
mass, an interacting pole, uniqueness of the coherent continuation or a
physical electron identification to this criterion.

The source is the declared coherent processor architecture, with its M6
proper-code load/export services. Its native primitive generator is a
specified linear combination of twelve actual carrier responses. The
controls are exact rationals with interval error bounds. The architecture
allows coherent event-register reuse. A record of every source event is a
different process, and its failure to carry coherent waves is an explicit

The source law, before any spectrum is computed, is

    W_mu = S C_mu,    C_mu = cos(mu) R - i sin(mu) I,
    R = 2 |u><u| - I,    mu=h*m.

Here u is uniform on twelve event slots, S exchanges the actual moving
slots on the cubic-routed carrier, and the remaining encoded slots are
retained. The finite source includes every physical, stationary and
padding component. The mass parameter m, routing, coherent services and
clock scale are architectural inputs. No empirical mass, Klein–Gordon
frequency, target speed or spectral eigenvector enters the source word.

The consumed manifests identify the scalar walk, not the distinct routed
Dirac source. Coupling the scalar source to a field does not transfer the
free theorem to that interacting source without a separate proof.
