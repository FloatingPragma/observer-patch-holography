# Mass Candidate Status

Retained alternative mass candidates, calibrations and rejections, grouped by comparison family with their separate domains and claim tiers. Generated by `scripts/build_source_only_mass_prediction_surface.py`; the JSON artifact is `runs/status/source_only_mass_prediction_surface.json`. No row is a public promotion.

The rows retain alternative domains, calibrations and rejected candidates. Combining favorable rows does not produce one particle spectrum. A physical identification must follow the same source object or excitation through its state, charge and symmetry action, repair dynamics, propagation, detector records, clock and jointly normalized kinetic and energy response. A topological invariant must be demonstrated if invoked; repair counts, quadratic disagreement and path surprisal are not mass units. See the [field-reconstruction guide](../../docs/research/OPH_FIELD_RECONSTRUCTION.md).

| Tier | Meaning |
|---|---|
| T0 | comparison-only; never an ancestor of a prediction |
| T1 | empirical closure; certified intervals |
| T2 | declared-model conditional |
| T3 | source-only dimensionless |
| T4 | source-only absolute (closed operational clock ratio) |

GeV/MeV displays inherit the externally normalized Planck-energy decimal E_star = 1.220890e19 GeV; the clock audit classifies its clock readback as a calibration checksum. No operational absolute scale is closed. Archived electroweak coordinates retain the MSSM-like running packet. A consistent SM rerun must first fix the active particle content, thresholds, matching and hypercharge normalization: b1 = 41/10 for g1 = sqrt(5/3) gY, or bY = 41/6 for gY. The existing two-loop engine uses g1 and retains only the top Yukawa. These historical values are not outputs of that future rerun.
