# Addressed source and pointer execution

The apparatus assumes exclusive addressed access. Each requested attempt acts
on its specified seam with one independent fair coin. A uniformly sampled
seam process is a different scheduler and is outside this apparatus law.
The source executes its prescribed schedule first, then idles while the
pointer runs. The reported class is latched at the end of that source prefix.
Source evolution during the pointer requires a separate continuation contract.

Discovery scans the thirty seams in the order stored in the frozen
`source_packet.json`. For each seam it makes at most R attempts, stopping
discovery at the first nonzero current. Its sign identifies the endpoint
reached. If all attempts return zero, discovery times out. An unknown initial
pointer port is a configured input column; no distribution over ports is
assumed.

From the discovered endpoint, `native_cycle_meter.route` chooses a shortest
path to port 0 by breadth-first search, considering incident seams in the
same stored order. Each requested hop gets at most R attempts; a nonzero
current advances the pointer, and R zero currents cause routing timeout.
The signed measurement cycle is 0→1→8→6→2→10→0. Each requested unit requires
six directed successful hops, each with the same retry rule. A failed hop
causes measurement timeout. Even a zero-class display performs discovery and
routing. Every failure retains its native tape and reports no charge.

The pointer displays the current-derived controller class through its native
trajectory. It is not a second measurement of the source occupation. On
success it returns to port 0 for all three admitted classes; its path winding
records the signed class. Validating an implementation requires replaying its
native tape, not merely comparing a returned value with the command. Removing
or poisoning terminal-load diagnostics must leave the controller unchanged.
