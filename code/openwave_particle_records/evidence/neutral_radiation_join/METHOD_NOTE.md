contact/current, declared memory slots and local swaps, and a declared
current-conditioned inverse detector. This packet supplies an additional
record-only field observation and a separate native storage/census lift.

dispersion. The signed slot currents and local sum/difference decoder fix the
field before evidence. The executed swap matrix fixes all Fourier phases.
The field norm is tied algebraically to the old frozen budget. That relation
is useful but remains distinct from independently calibrated physical energy.

of swap layers. It does not require every auxiliary repair attempt to be a
physical unitary tick. The native reset/write/census attempts have their own
explicit counts, and those counts are not identified with the coarse flight

current and timeout. It does not implement all transport/inverse operations
on one persistent native memory register. Its measurement work must be counted
separately from the old symbolic work budget.

review, platform registration/pin and any official cell decision are separate.
