# A concrete field-cycle continuation to examine next

The same electric source already implements U_gamma as the three actual
seam operations(0,5),(5,11),(0,11), with its inverse the reversed word.
Both are complete permutations, including electric-window holds, and both
preserve Gauss. The old coherent loop detector is therefore available on
the same CAR object after the proved carrier map.

Without boundary interference, a tag initially at0 returns to0 and the
electric field changes by the oriented cycle c, with entries(−q,−q,+q)
on these three seams. Its active memory changes as specified by the source.
The word is not a pure field shift on every source column: a tag initially
at5 ends at11 and one initially at11 ends at5. Finite-window boundary
columns can change even the first return statement. These cases must stay.

A fixed fair-direction, lazy source protocol can execute identity with
weight3/4, U_gamma with1/8 and U_gamma inverse with1/8. The weights can be
sampled by three retained fair bits. On the full quantum state this is a
complete random-unitary channel. Its amplitude comparison kernel is

    P_gamma = (3/4)I + (U_gamma+U_gamma*)/8,

with spectrum in[1/2,1]. This is a positive source-defined transfer and has
a well-defined logarithm. A complete reference comparison of the three
actual words can measure this kernel. The transfer kernel and random-unitary
channel are different mathematical objects; neither is silently substituted
for the other's physical clock.

To isolate a field-cycle response, let B prepare the returned tag at0 and
the chosen compensator while leaving all electric and memory coordinates.
The complete instrument first executes the actual word, then reads tag
return versus nonreturn. The return amplitude is K=B*U_gamma B, a contraction;
the nonreturn probability is retained. Its two-direction lazy compression
(3/4)I+(K+K*)/8 remains positive. This formula does not normalize successful
returns and does not pretend K is a unitary field translation at the boundary.
The full event history still reports the matter used to make the loop.

This offers a constructive route to a divergence-free field response from
native closed histories. Before it can close row5, one candidate must specify
how its actual return/nonreturn instrument and current-query walk share a
clock and preparation, and distinguish persistent matter transport from the
closed-history field response in their measurements. The combined source
must then yield a stationary spin-resolved dipole and an orbital/Larmor
comparison. Those are new tests, not consequences of the cosine notation or
the positive transfer alone. This note is a written proposal and contains
no new executed loop data or magnetic-row claim.
