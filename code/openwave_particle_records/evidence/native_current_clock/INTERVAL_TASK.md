# Frozen interval audit of already emitted words

This is a post-execution audit of the unchanged source words and receipt,
not a new source experiment. The original conditional aggregate geometric
allowance1e-12 is tested explicitly; a failure of that allowance is retained.
No source input, walk, spectrum, detector record or prior gate is changed.

1. Bind SOURCE_WORDS, RECEIPT, original preregistration and all212 source pins.
2. Certify every distinct emitted full-six-level native primitive with the
   existing directed-integer synthesis routine and its fixed1e-11 raw gate.
3. Independently propagate exact binary-angle ideal pulses through integer
   interval matrices. Recenter after each pulse at an exact dyadic matrix;
   the previous Frobenius radius is preserved by the exact unitary pulse,
   and the newly enclosed rounding radius is added. No floating sine,
   cosine, eigensystem or geometric approximation supplies the certificate.
4. Construct exact uniform3/reflection targets and algebraic spin directions
   from the pinned Q(sqrt5) response frame. Retain independent intervals for
   uniform preparation, reflection, all spin gates and complete multiplex.
5. Compute aggregate target error delta_prep+16(delta_ref+delta_multiplex).
   Report whether the original1e-12 allowance covers this certificate.
   The separately frozen conservative audit gate is aggregate≤1e-9 and
   corrected compiled-piece half-diamond bound≤2e-7. These bounds are fixed
   before this audit and apply to the declared exact current oracle only.
6. Keep original receipt unchanged. Write a separately named audit receipt;
   replay performs no writes. A failed audit is retained before correction.

The first naive box-propagation audit is retained in attempts/interval01.
It certified all40 primitives but accumulated an unusable1.61e17 multiplex
enclosure. The correction changes only enclosure propagation. Source words,
experiment outputs, original allowance and all audit thresholds are unchanged.
