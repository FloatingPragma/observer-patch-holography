# Controls and identities

The zero-current control keeps the full query completion, spin attachment,
reflection and detector but suppresses every source move. Both charge cases
change the complete reference law. Omitting the reflection changes the same
object's law after the first tick. Both are complete unitary alternatives;
neither substitutes a different input or detector.

Using proposed current on overflow is a deliberately invalid oracle mutant.
The actual boundary source remains held. Its current query then fails
Hermiticity/involution by3.902113 on q=1. The q=0 law has no overflow and
appropriately does not discriminate this mutation.

The independent phase-plane plant uses lambda0 and1/2 and the same
plus/minus reference-array function. Both quadratures and all17 times are
read. A constant-zero detector misses an order-one signal and is rejected.
The plant calibrates the detector; it is not source evidence.

The invalid source flag has unit failure probability and unchanged output.
Query-one and event-padding outcomes remain in every array. Query holds are
coherently retained internally; conditioning on query zero is never used to
define the continuing walk.

Unitarity of a correctly constructed query, the Clifford square, and a
Chebyshev identity for a generic SELECT/reflection pair are mathematical
identities. They do not distinguish the native law by themselves. The actual
native current matrices, record laws, changed-law differences, electric
continuity and stationary-source constraints carry the source-specific
content. These controls do not establish physical radiation or a magnetic
moment merely because the algebraic coefficient in the Pauli square is two.
