# Loops and stationary current

Actual native loop records balance a nonzero stationary current contribution
in one complete CAR/Gauss observer clock. Removing the loop removes that
current. The test keeps every boundary and nonreturn outcome, and separates
this finite circulation from the physical magnetic-dipole question.

Run `python3 openwave/shared/native_field_cycle/headline.py` for the read-only
replay. [Results](RESULTS.md), [proof](PROOF.md) and [frozen design](DESIGN.md)
state the complete domain and the source/clock interpretation required for
a magnetic field and Larmor comparison.
