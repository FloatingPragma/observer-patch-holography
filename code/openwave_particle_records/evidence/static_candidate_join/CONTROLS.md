# Controls and reader identities

The signed source is the same object in each native experiment. A control
changes its disclosed rule or an observer record, never the acceptance target.

| Control | Object and required response |
| --- | --- |
| Swap/hold | Same pair coordinate and cell seams; swap with probability1/2 or hold. Nonzero pair never absorbs. |
| Held source | Same pair coordinate with zero body current. Nonzero pair never absorbs. |
| Half-current plant | Same incidence decoder on q=e0-e2 and seam(0,1), with explicitly non-native current1/2. It must report sharp halves at0 and1; integer truncation must disagree. |
| Fixed addressed seam | Same native current-vector reader, but only seam(0,5). At least one source-axis or uniaxial-shape test fails. |
| Off-axis plant | Same moment/tensor reader on two opposite x-axis records. The tensor fails the original p=0 source-axis shape. |
| Old fine-record instrument | Same coarse relative source law but a retained coin/current/background record. The fixed coherent witness loses an off-diagonal that the signed source preserves. This rejects an incorrect quantum join. |
| Compact dephasing | Same source ray detector, dephased input. Pair eigenray certificate falls from1 to1/16. |
| Compact sign plant | Same source ray detector, one component's sign reversed. Pair certificate becomes1/4. |

The last two controls belong to the sealed compact provider and are bound to
the current candidate by literal equality of the full addressed source map.
They are not rerun or relabeled as newly measured counts here.

Reader identities carrying no law credit: incidence continuity for any current
tape; integer output for an integer-valued source; the abstract Smith quotient;
sign reversal of a manually negated vector; R squared equal to identity; and
the algebraic return of a tensor built by simply squaring an assigned vector.
Law credit instead comes from actual native branch rewards, stopped response,
nonzero independently computed covariance, source-axis attachment, and the
source-count compact transfer/eigenray with a discriminating detector.

No timeout or unresolved coordinate label is deleted. Classical source
branches are counted exactly; the implementation comparison is a full-channel
bound including reset failure. These are distinct from conditional success.
