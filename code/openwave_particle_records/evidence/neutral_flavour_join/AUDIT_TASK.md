# Post-run artifact audit

No native source is executed, and no gate or source parameter is changed.
Treat every stored floating-point matrix component as its exact binary rational.
Recheck the charged kernel's Q(sqrt(5)) polynomial root brackets by outward
rational arithmetic. Bound every stored frame column's distance to its
corresponding exact eigenline using its full residual and certified separation.
Combine that bound with entrywise bounds on the actual source matrices; require
forward/inverse frame envelopes2e-10, basis-X envelopes1e-10 and native-pointer
envelope1e-11. Compose reset, pointer, frame and X errors for the main instrument
and up to six intermediate full-family reads, retaining all failure flags.
Require each complete conditional operator envelope below1e-6. Report the
unconditional successful cycle3 return weight separately from its conditional
return. These are stored-artifact bounds, not authenticated hardware errors.
