# Proposed common source pin

The proposed candidate is `A-static-signed-source-v1`, class N+. Relative to
`A-paired-charge+moment`, it replaces the two independently represented binary
sources by one directly prepared and measured signed-coordinate source. Its
coherent memory branch amplitudes are explicitly positive, including the full
invalid/vacuum complement. The old fine-record instrument is not equivalent.

The fixed240-position federation and its630 seams are declared once. Two
observer addressing settings are admitted:30 cell seams for stopped charge
and initial tensor/frame experiments, and630 seams for compact energy. Only
the latter defines the intrinsic static transfer-energy convention. New basis
preparations and current-pointer assays are executed on the same work/source
register used by the compact provider. All scalar endpoint destinations and
currents use the unchanged native function.

The proposal carries one511keV reporting anchor and its1024.4508487023415keV
pair consequence. It also carries the lower source modes, optical-continuum
limitation, finite geometry and supplied code-service precision from the
compact provider. Older failed/partial packets and the false coherent-join
counterexample remain part of its visible ancestry.

No author commit, platform task number, owner pin selection or G6 acceptance
is invented. Bind those fields only through the actual publication/review
procedure. The archive is a proposed publication artifact, not an upstream PR.
