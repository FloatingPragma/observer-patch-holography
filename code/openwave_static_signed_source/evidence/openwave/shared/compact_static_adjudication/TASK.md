# Frozen exact interface test

Freeze this design, task, code, the sealed compact provider and all source
inputs before running `verify.py --record`. No stochastic seed or fit is used.
All comparisons below are exact integer equalities except consumption of the
provider's already frozen floating-point arrays.

1. Execute all eighteen endpoint/coin cases through the pinned native
   function. Reconstruct the exact 240-port/630-seam federation and compare it
   with the provider's retained graph.
2. Check all 65,536 pair labels in all 1,260 contexts. Require 57,361 valid
   labels (including vacuum) and 8,175 invalid labels. Every valid output is
   valid. Every current-zero body column is identity. Every fixed-current
   branch is injective. Together with the stated 1/1260 weights and invalid
   identity flag this proves the full effect sum on arbitrary references.
3. On every context, compare the vectorized action with fresh scalar native
   endpoint calls for both contact orientations, all four one-endpoint plus
   spectator cases, vacuum, and two invalid labels. Retain counts separately
   from the full vectorized column domain. Both contacts must annihilate.
4. Check both fixed regional continuity identities on every valid pair
   column. Check all 256 single-source labels for both signs and every
   context. Accumulate complete positive, negative and pair compact modes;
   require exact native eigenvalue numerators1254,1254,1248 over1260, with
   every exterior and vacuum output included.
5. Consume the source-compiled full256-column preparation/inverse matrices.
   Require their prepared rays to equal the declared compact source rays up
   to their fixed global phase, norm error<1e-10; inverse residual<1e-10.
   Consume all256x256 pointer-law arrays. Their single marginal must give
   coherent1, dephased1/4 and sign-plant1/4, with tolerance5e-10; its complete
   position marginal must equal the fixed four-site profile at that tolerance.
   All unresolved, padding and failure terms retain the provider's complete
   error certificate6e-7; no sampled reset frequency replaces it.
6. The held law must give identity transfer, hence source energy0. A fixed
   chart swap of labels(4,16) and(8,16), while leaving the source reader
   unchanged, must fail at least one source column. Report actual failure
   counts without fitting the choice.
7. Write compressed exact actions with explicit zero-current defaults and
   invalid flags, source pin hashes, all counts and elapsed time. Normal
   replay must not write provider files. Headline replay must exit0 within
   60seconds; if it fails this bound, retain the result and preregister a
   separate replay-only optimization rather than rewriting the experiment.

Expected static numbers are existing provider results, not fresh predictions:
E6=6.014331228348673 and E12=12.057508280349891. The anchor predicts
E12=1024.4508487023415keV under this finite clock; lower modes and divergent
