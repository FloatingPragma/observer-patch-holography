# Waves and interactions from native records

Native repair histories support a common free Maxwell and massive scalar
description, boosted packet contraction and hydrogen-like standing levels
on one declared observer construction. Separate native constructions give a
linear triality potential, scale-dependent core response, neutral emission
from a fixed-charge core and positive gravitational-response components.
The [proof map](PROOF.md) and [claim register](../../claims/openwave_native_record_rows.json)
keep their sources, finite errors and physical identification boundaries explicit.
They supply no official OpenWave award or single interacting physical theory.

The663 frozen evidence leaves include complete written proofs, code, records,
receipts, same-group reviews and failed attempts. `ORIGINS.json` preserves each
original manifest. Unexecuted light/clock and string-clock drafts are separately
classified. Historical filenames and candidate identifiers are provenance.
The independent package `code/openwave_wave_rows/` has different source laws
and review claims; no equivalence to that package is asserted here.

From the repository root, use Python3.13 and NumPy2.3.5:

```sh
python3 code/openwave_native_record_rows/replay.py
python3 code/openwave_native_record_rows/replay.py --mode representative --output /tmp/native-record-replay.json
python3 tools/build_openwave_native_record_claims.py --check
```

The default verifies custody without executing a scientific source. The
representative mode uses temporary copies to replay the unified wave source,
the complete triality reader and the fixed-charge producer and reader. It
checks regenerated artifact bytes and retains every source outcome. The
other archived source receipts receive custody verification, not a claim
of fresh execution. Replayed ancestral histories are not independent trials.
No laboratory measurement is used as a numerical input by these components.

The retained [replay receipt](RESULT.json) records6582294 literal native calls
across producer, reader and ancestral replays in16.033111seconds. Scientific
output bytes match the bound artifacts. This count includes repeated histories
and does not count independent experiments. The custody rejection test checks
that both a changed scientific leaf and a replaced origin manifest fail.
