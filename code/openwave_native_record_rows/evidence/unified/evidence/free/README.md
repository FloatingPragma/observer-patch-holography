# Local OpenWave submission bundle: rows29 and30

This standalone directory contains the complete proposed **MFR-common-native-field-v1** free-wave source task, its frozen native code/inputs, full local record evidence, controlled mathematical reconstruction, draft method notes/cells and explicit owner pin change. It is a local submission draft; no platform task, pin move or acceptance is asserted.

Install Python3.13.7 and the pinned NumPy requirement in an ordinary environment, then run:

```sh
python3 scripts/task_common.py --row both
```

The script verifies131 bound evidence files, copies the frozen common member to a temporary directory, re-executes all169364 native calls and requires exact receipt/archive bytes. It reports row-specific numbers and retained finite errors. It writes no source evidence. `--row 29` or `--row 30` selects the summary; both execute the same source. `--custody-only` checks all evidence hashes without executing. A changed Python/NumPy environment can change floating-point serialization; a byte mismatch is reported rather than concealed. All numerical gates are also explicit in the frozen producer.

Read TASK.md and DESIGN.md first, then CLAUSES.md, METHOD_NOTE.md and OWNER_PIN_DIFF.md. The full controlled reconstruction is essential to the free-wave claim: the small finite cube is a source/replay check, not by itself a continuum physics measurement. SOURCE_PINS.json fixes all included artifacts. EVIDENCE_MAP.md identifies which theorem supplies each mathematical clause and which run checks its native input.

The same-group reviews are included for adversarial reuse. A new reviewing group must assess the complete source/model correspondence and register the platform task before the platform run. The owner decides and performs any pin/posting action. Official rows29 and30 remain untested.
