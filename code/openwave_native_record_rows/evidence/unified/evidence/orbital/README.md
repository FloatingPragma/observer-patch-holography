# Local OpenWave row31 submission: native orbital source

This standalone bundle supplies a native interaction, actual global production
records, a same-history field/clock map and the controlled hydrogenic standing-
level proof on one specified parameterized source. It is a local filing draft,
not an owner pin or a platform acceptance statement.

With Python3.13.7 and NumPy2.3.5, run:

```sh
python3 scripts/task_orbital.py
```

The script verifies every bound source leaf, runs the frozen production source
in a temporary directory and requires byte-identical receipt/record archives.
`--custody-only` checks the evidence without executing. All347533 native calls
are included. The output separates actual short records from analytically
compressed populations and the written large-shell limit.

Read DESIGN.md, TASK.md, CLAUSES.md and OWNER_PIN_DIFF.md. All original local
preregistrations, failed/timeout outcomes if any, manifests and same-group
reviews remain under evidence/. Another group must review the complete source
correspondence and the owner must decide/register the platform pin/task before
an upstream execution. No upstream action has been taken.

The production source's initial producer-pass attempt failed independent
band-decoder review because a NumPy view was normalized in place. Its entire
archive and finding remain included. A preregistered copy/projector-check
amendment corrects the readout; native events, occupations, clocks, curl and
population predictions remain identical. Both attempts must be reviewed.
