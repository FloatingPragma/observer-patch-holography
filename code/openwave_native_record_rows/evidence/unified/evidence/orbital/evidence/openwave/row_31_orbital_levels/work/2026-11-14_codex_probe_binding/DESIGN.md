# Native-probe binding controller

Auxiliary N+ candidate **MFR-native-probe-binding**, unpinned. The endpoint
law is unchanged. Its added memory holds two disclosed one-unit positions,
a target-cell predicate, route/probe counters and all native current letters.
One unit is an inner probe; the other is the outer response source. A
reusable zero-load pair implements feedback holds by ordinary native events.

The calibration member uses two copies of the open[-2,2]^3 array of
twelve-port graphs, with port-preserving spatial edges and weight1. All
inner/outer relocation and reset operations are sequences of native edge
attempts, chosen from known current positions. No source location is reset
by an external setter after initialization. The law has a declared
calibration mode for controlled local-seam preparations; the theorem also
defines a global-proposal production mode. That production mode and its
long occupation fields are not executed in this calibration study.

On a controlled outer internal proposal, the inner observer first reaches
the outer cell by native route retries, then runs until target or boundary.
A target hit redirects the outer proposal to the zero-load pair; escape
permits the original outer event. A bounded probe timeout also redirects
to the hold. Source probabilities, the capped kernel and preparation costs
are derived and retained. No numerical h table, gamma, potential phase or
Hamiltonian is used by the controller.

again with feedback disabled. Each case has4096 trials. The record observer
reads hit and outer-move frequencies. The reference predictions come from
the complete native endpoint census and its exact three-orbit first-hit
equations. These data are compared under a conservative simultaneous99%
martingale Hoeffding bound for twenty bounded tests, with preparation-bias
allowance. Every preparation/probe failure, wait and held event is retained.

The computed finite outer operator is a consequence of the controller law,
L_eff=L_external+(1-h)L_internal. Its three positive native bands have a
stable well strictly below their asymptotic thresholds; disabling feedback
removes it. This is not yet a hydrogen spectrum or a production-field run.
The row's remaining orbital/shell limit is named explicitly in `PROOF.md`.
No value of nature and no physical charge assignment enter this study.
