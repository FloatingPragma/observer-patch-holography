# Method and custody

All producer code, the independent reader, proof, task, format and source inputs were hashed in PREREG.txt before the first native call. The parent registered A-native-harmonic-lapse-GR7 and posted the prereg hash before authorizing execution. No parameter search, seed search or post-run threshold change is permitted. This file and the other scope summaries are post-prereg documentation; the frozen executable apparatus remains authoritative.

The producer imports a frozen GR6 engine copy whose sole behavioral extension is immediate hit/escape classification after a successful reset to a terminal endpoint. The old experiment entry point is never called. The independent reader imports neither producer nor helper; it reconstructs every event address, RNG draw, signed current, location, gate and JSON summary from raw bytes, and computes source absorption by forward recursion.

The statistical interpretation assumes independent fair branch choices in the native model. Frozen pseudorandom seeds make the finite demonstration reproducible. The22 simultaneous interval tests use a conditional martingale bound plus deterministic cap/reset offsets, as specified in TASK.md. Changed-control contrasts are predeclared effect checks; their separate observed passing does not create an additional confidence claim.

Primitive native operations and observer address choices are distinguished in RECORD_FORMAT.md. Outer address headers and length prefixes are not counted as endpoint calls. All executed padding/hold events are counted. Replaying a record archive is an independent validation computation, not an independent physical sample.
