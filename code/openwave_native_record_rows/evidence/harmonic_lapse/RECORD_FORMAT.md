# Complete native record format

METRIC_EVENTS.bin.gz decompresses to18432 consecutive837-byte words, in TASK order. Each byte is(direction<<3)|(coin<<2)|(current+1). Directions0..5 are+x,-x,+y,-y,+z,-z;6 is an actual empty-pair padding event;7 is the active metric main pair. The main current can be negative. Each word has four209-byte plus slots followed by one main event. Each plus slot begins with a native empty-pair fair bit, then144 reset and64 body/padding native calls. METRIC_TRIALS.json provides the full derived states/flags; it is checked against the raw tape.

OUTER_EVENTS.bin.gz is a sequence of2560 length-prefixed records. The prefix is4-byte unsigned little-endian decompressed-body length, not a native record. The body begins with144 native outer-reset bytes, then zero to512 blocks of420 bytes. Each block begins with a one-byte requested-direction header0..5 (an observer address choice, not a native call), followed by two209-byte inner plus slots and one native outer-attempt byte. The final native byte uses the requested direction if allowed, or6 for a hold. Actual movement is the current0or1. Every outer block therefore contains419 genuine native calls. OUTER_TRIALS.json gives full states, slots and termination. No unexecuted padding is counted after outer termination.

HIT_CENSUS.json, EMBEDDING.json and INTERNAL_SPECTRUM.json retain all pretrial native inputs/outputs or their exactly reconstructible branch addresses. POPULATION.json contains exact rational source-derived targets, not a lookup consulted by the policy. RECEIPT.json counts producer native calls; VERIFICATION.json counts separately executed native replay calls. JSON decimal walltimes are resource observations, not physics gates.
