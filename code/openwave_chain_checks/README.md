# Native records, common clocks and finite field comparisons

This package reproduces two finite constructions and rejects unsupported joins.
The coherent source passes through two complete regional charge instruments
and an energy instrument on its actual Hamiltonian. A separate reciprocal
classical source supplies a measured drift and a controlled field calculation.
Their source, preparation and clock differences remain explicit.

Run with Python, NumPy, SciPy, SymPy and mpmath installed:

```sh
python3 code/openwave_chain_checks/replay.py --output /tmp/chain-replay.json
```

The runner checks every public input, copies the reviewed files to a temporary
workspace, and executes the unchanged entry point with isolated Python startup.
It requires exact equality of the scientific result and imported local module
list. Runtime metadata is checked separately. No mutable project source is
used, and no reviewed file is rewritten. The snapshot retains the original
relative paths needed by its source and audit packages.

[The contract](provenance/CONTRACT.json) and [proof](provenance/PROOF.md)
state the complete outcome laws, numerical admission tolerances and field
bounds. The original result includes 95 rejected malformed inputs and false
joins. The useful field precision belongs to the larger register member;
transferring it to the smaller particle calculation requires an additional
proof. The newer shared LOCAL12 mass-and-field source is a separate candidate.

[The row map](provenance/ALL31_GATE.json) preserves the scope of every
criterion. These finite checks do not establish all 31 physical criteria or
award OpenWave validation. Native coherent code transfer and the spectral
energy apparatus retain the architectural services stated in the contract.
