# Native records, fields and measured force

This package executes a quantum source through two complete charge detectors
and an energy readout, and a reciprocal classical source through an integer
field controller into a measured current score. Typed checks identify their
source and clock domains. The useful integer-field limit changes the quantum
regulator, so its particle measurement transfer requires a separate proof.

Run from the workspace root:

```sh
python3 openwave-tuning/next/CHAIN/integration/run.py
```

The command checks frozen inputs, executes both finite compositions, rejects
malformed inputs and false joins, and writes the scoped result and 31-row
claim map. Read [PROOF.md](PROOF.md), [CONTRACT.json](CONTRACT.json), and
[RESULT.json](RESULT.json) for the domains and evidence.

The bundled historical workspace preserves the reviewed source bytes and
original relative paths. The command disables site startup and rejects mutable
project reads; it does not validate the concurrently edited live source tree.
