# One clock for recorded events

The same interacting 384-state source evolves between recorded native
attempts. A complete Poisson instrument joins its supplied Hamiltonian
durations, every native attempt and their operation costs, including
zero-current events and controller idles. All charged-preparation labels
and the infinite-count complement retain their density matrices. A
positive-probability zero-attempt branch changes an actual native readout,
so duration cannot equal a fixed multiple of attempt count. Physical time
calibration and a native compiler for the coherent service are separate
requirements. See the [proof](PROOF.md), [typed contract](CLOCK_CONTRACT.json)
and [reference checks](REFERENCE_REVIEW.json).
