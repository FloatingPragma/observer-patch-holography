# Native force readout

The frozen two-mobile-copy source produces a signed native seam drift
that responds to its shared lattice energy. Complete first-event outcomes
give a finite force relation and a bounded linear response. Reflected
sources reverse the drift; zero coupling and a held field remove the
corresponding response. A separate 40-bit controller comparison has an
explicit error bound for complete capped path laws.

This is the classical reciprocal source with supplied energy and rates.
Its relation to the quantum source and a dynamical continuum is outside
the proved domain. See [the proof](PROOF.md), [the contract](FORCE_CONTRACT.json)
and [the executed result](RESULT.json).
