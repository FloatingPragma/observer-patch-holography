# A reciprocal camera with an unlabelled physical reference

A fixed arrangement of Interval Echo contacts measures a reciprocal two-way signal on the 80-cell camera when it receives **two independent preparations of the same source**. One preparation is sampled by the traveling probe. The other is supplied after the probe's four-tick flight and is read as a physical reference. The apparatus never receives the preparation labels or estimates the density to set its analyzer. A hit requires two actual local Bell coincidences and equal directly measured reversal parities. Missing the appointed pixel, failing either coincidence or obtaining opposite parities all count as failures.

For independently prepared source and reference blocks $X_\pi$ and $Y_\pi$, its accepted probability on route $i\to j$ is
\[
 P_{ji}(X,Y)=\tfrac14\sum_\pi\operatorname{tr}(Y_\pi^{\mathsf T}K_{ji}X_\pi K_{ji}^\dagger).
\]
For $Y=X$ it is exactly symmetric in the two pixels at every flight time and for each probe charge. The native generator is real symmetric, so $K_{ij}=K_{ji}^{\mathsf T}$. The formula is linear in each of the two preparations and quadratic when both are varied together. The single-preparation fixed-analyzer obstruction remains valid for its specified instrument. ## Independent starts and held controls

For each of ten emitting pixels, two probe charges, and three stocks, the simulated count bank uses $2^{46}$ independent paired starts. Each start consumes one source for flight and one independent reference, including outside or rejected trials. Every row retains all 26 exclusive outcomes. Within each of five detector pixels these are different parity, two Bell accepts, only the left accept, only the right accept, and neither accept. The last bin is outside the five receiving pixels. The acquisition constructs the probabilities by applying the compiled gates to both complete state matrices, and uses multinomial sampling instead of individually stepping through quadrillions of identical starts. There are also three separate zero-flight source/reference calibration banks. Joint 99% Clopper–Pearson bands for the 300 signed-and-directed per-pixel double-accept probabilities and three calibration probabilities describe the simulated source center. - For the even source equally mixing $|00\rangle$ and $|11\rangle$, two independent draws give zero-flight acceptance $1/8$. Matching the hidden source lottery label instead gives $1/4$ while both one-copy density matrices are unchanged.
