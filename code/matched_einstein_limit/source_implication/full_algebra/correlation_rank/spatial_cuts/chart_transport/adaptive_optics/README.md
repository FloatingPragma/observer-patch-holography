Take the tracial reference $I_8/8$ from a fair lottery over the four computational products, followed by the unread left reversal write. For a channel with interference score range $[-C,C]$, use a fair switch to interrogate either the unknown stock or the reference, reversing the score sign on the reference arm. The randomized terminal bit has probability $p=1/2+(Bd)_j/(4C)$ for the trace-zero coordinates $d$ of the unknown state relative to the standard. Hence $4C(k/N-1/2)$ from the binary count $k$ estimates this coordinate of $Bd$. Every miss is retained. The receiving observer needs only these counts and its detector calibration.

Each numerical bank represents $N=2^{148}$ independent binary trials per setting. This is a sufficient finite exposure; it is extremely large. Aggregate sampling avoids iterating through the individual trials. A seeded fair-bit stream samples a binomial with the native probability rounded to a $2^{-192}$ grid, preserving the whole binomial support. For reproducibility the envelope is centered at the binomial mode $m$ with blocks of length $w=1+\lfloor\sqrt{N}\rfloor$. Block $j$ has envelope height $2^{-\max(0,j-1)}$. Beyond either first shoulder the adjacent outward likelihood ratio $r$ satisfies $w(1-r)\ge1$. Log-concavity makes later ratios smaller, and $r^w\le [1+w(1-r)]^{-1}\le1/2$. Thus the block heights dominate the target probability divided by its modal value. Sampling a block in proportion to its height, choosing a uniform integer in the block and accepting by the binomial-to-envelope ratio gives the specified distribution. Directed log-gamma evaluation and additional bits settle each acceptance comparison.
