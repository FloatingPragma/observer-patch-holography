# Custody and release boundary

BRIDGE_ORIGINS.json binds the immutable component manifests and each copied
input's original relative path and digest. Copied data are checked against
those component manifests, not merely against local checksums. PREREG.json
binds the primary path, falsifiers, complete candidate and inputs before the
integration outcome. MANIFEST.sha256 subsequently seals the whole producer.

This local common successor is not an adopted upstream candidate pin or an
official row decision. The previous isolated local Git bundle predates these
new components and must not be advertised as their custody version. Root
integration owns a new retrievable source snapshot and exact outgoing diff.
External other-group G6 and release remain OPEN unless separately recorded.
No private source transfer to Anthropic is authorized by this local research.
