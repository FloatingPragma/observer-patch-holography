This completes the bounded audit of the previously paused graph proposal.
The new graph has exact scalar compact rays and sixty fixed-graph rotations;
the complete signed-source instruments, chart complements and source-law
controls are checked. The prepared ray nevertheless leaks under the actual
unread channel: fidelity11867/12144 and escape1/506 after one event. Neither
physical spin emergence nor electron state selection is established.

The result is a local mathematical/source component, not an award request.
The original draft apparatus compiler remains unexecuted; the readout tested
here is an explicitly ideal complete ray effect. See PROOF.md, CLAUSES.md and
[the external checklist](../../../shared/source_repair_root_review/ANCILLARY_CHECKLIST.md) for exact scope and submission obligations.

From this directory, with Python3 and NumPy installed:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python3 audit.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python3 independent_check.py
```

The first command checks the frozen source and reproduces every receipt value
and stored array without writing them. The second independently rebuilds the
finite graph, rotations and all branch columns. It imports no producer code.
No network, shell payload or external source checkout is needed.

The twelve-port repair snapshot and prior draft files are under inputs/.
ORIGINS.json records their original paths and hashes. PREREG.json predates the
first producer run; the independent implementation is a retrospective review
of known results and is labelled accordingly. No retrospective discovery claim
is made. Old240 results remain with their original source and manifests.
