# Prospective task

Freeze DESIGN, TASK, source function, graph, executable, inputs and gates
before first execution. Local registration does not claim platform preregistration.
Prior binary response and unit selection were known; this is an implementation
and extension, not a blind discovery of either earlier result.

1. Enumerate all 9^4 pairs of local endpoints in −4…4 and both coins.
   Gate: zero differences between paired and direct difference branch multisets.
   These execute 39,366 native calls: 6 per endpoint quadruple.
2. Verify exact rational graph inverse and reward identities on every ordered
   primitive discrepancy (132 states), all 30 edges, and both coins.
   Gate: zero Gauss, mean-current, or harmonic-reward residuals. Execute all
   7,920 source events, retaining their current/destination rows.
3. Run 48 fixed preparations (12 axes times four families) through 512 common
   selection attempts; same native current-only tree probe with cap32 per edge.
   Compare a swap/hold selection body with identical choices and reader.
   Gate: all conclusive native selections reach span≤1, no control does.
   At least one actual preselection double is read as span≥2.
4. On each successful native selection, select the first graph edge whose
   current-reconstructed endpoint contrast has magnitude1, and retry that
   native intervention on X alone with cap32 until its current is nonzero.
   Gate: all conclusive interventions emit magnitude1 and have primitive q.
   If the selected state is uniform or the retry times out, keep that outcome.
5. Run 4096 common-choice response attempts. Analyze separate native and
   swap/hold response arms, each with its own freshly executed selection and
   intervention. Gate: all conclusive native responses synchronize; none of
   the conclusive controls do. Finite misses are retained as such and cannot
   replace the general proof. At synchronization every compared flux obeys
   BF=q and every daughter sharp regional charge is integral. The latter is
   an explicitly noncreditable alphabet identity.
6. Forced cap1 probes return inconclusive, never a selected/synchronized result.
   A genuine double input is distinguishable from a binary input with same
   total. A displaced current record is rejected by independent event replay.

Seeds: each preparation i uses 72311000+i for selection, 72312000+i for
the native intervention and 72313000+i for the response; control arms use
the same seeds. These were fixed before any new execution. They are finite
validation seeds, not a held-out empirical prediction. Full records and all
flags are retained. Gate thresholds may not be changed after inspection.

Headline: `PYTHONDONTWRITEBYTECODE=1 python3 headline.py`. The run must verify
the frozen source and regenerate the receipt and full evidence identically;
runtime target under60seconds. Independent checker imports no producer code.
