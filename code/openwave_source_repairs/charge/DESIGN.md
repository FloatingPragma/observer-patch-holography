# One process selecting units and measuring their source response

Candidate `A-native-multiload-gauss-selection-v2`, classical N+. The ancestor
pin remains `A-static-signed-source-v1` at `c330c6e7`. No new pin is selected.
The actual row test is “integer topological charge; a split e → e/2 + e/2
impossible.” The PR723 decision offers dynamical selection of single units
from larger native loads as a constructive route. This experiment joins that
selection to a same-source response. It does not treat integer arithmetic or
the old relative-homology dictionary as a new dynamical discovery.

The new theorem is local and unrestricted in integer load: two sources X,Y
with a common edge and placement coin have a difference whose conditional
two-coin transition distribution equals the native distribution on X−Y.
This extends the existing binary paired-source result. At equal total the
difference synchronizes almost surely, including arbitrary signed loads.
Compared native currents therefore realize an exact finite Gauss response
for that measured difference, independent of the shared background.

The experiment uses twelve ports and the thirty pinned seams. Two sources
start with equal, supplied integer configurations; the reader never receives
the configuration or its total. A common uniform seam and fair coin run the
selection body. Native current probes read the endpoint modulo a constant.
Probe changes are tracked from their own currents. An edge of contrast one
is chosen from that reading, and repeated native attempts on X alone move
one of the selected upper-level occupancies. Y supplies the unchanged
comparison for that intervention. No position of a unit is supplied to the
controller. The subsequent common-choice response is followed by two native
current-only probes. Equal source totals fix the difference's otherwise
unobservable uniform offset. Backwards continuity recovers the response
trajectory and its first synchronization entirely from records.

Supplied: finite graph, integer alphabet, equal twin preparation, common
random choices, classical current memory, finite attempt budgets, native
contrast-probe controller, source/reference intervention protocol, and
faithful records. No observed physical constant enters. A zero absolute
background and a numerical source total are not reader inputs. Calling the
compared source “electric” remains an interpretation to be assessed; the
experiment derives its finite flux response without evolving a field law.

The relevant competing law is common swap/hold. It preserves the graph,
total, integer alphabet, and rotational equivariance. It retains a double in
the selection stage and never synchronizes distinct paired sources in the
response stage. Both controls are read with the same native terminal probe.
The native probe is an intervention; backwards current transport refers all
reported results to the body before the probe.

Native doubles are actual source states and test the detector's ability to
see a nonselected object. Record corruptions test integrity only. Fractional
ensemble averages are representable by the analysis but are not fractional
sharp source loads. No claim derives the integer alphabet, independent
configuration topology, electromagnetic force, continuum 1/r, coupling
strength, or electron interpretation from these finite records.
