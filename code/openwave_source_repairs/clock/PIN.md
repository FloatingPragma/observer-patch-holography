# Candidate and clock ancestry

`A-native-poisson-event-clock-v1` is a new local N+ candidate descended
from the OLD240 signed source at `c330c6e7`. The endpoint function and
graph are unchanged; the event-count clock/controller is new.

Law: actual OLD240 native endpoints, plus a persistent two-port native
unit supplying fair movement-bit records. Memory: complete bits, prefix
interval, count, address retries, source currents, time labels and all
failure flags. State: single-unit or signed-pair OLD240 sources including
vacuum, with an orthogonal auxiliary/controller register. Decoder: exact
rational Poisson count, complete current-derived source paths and native
transfer/generator certificates. No coherent continuation is silently
introduced into the count-clock experiment.

An ideal uncapped sampler defines the exact count law; the executed
128-bit/count32 version has an explicit complete failure flag and error.
This is distinct from the16-bit exhaustive inspection approximation and
from the old fixed-one-attempt clock. All are kept separately. No source
pin moves and no earlier clock result is overwritten.
