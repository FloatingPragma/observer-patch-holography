# Stage1: fixed source and compiler proposal

This stage performs no acceptance test of a free-flow experiment. Freeze this
task, DESIGN, proposal.py, source snapshots and source pins before execution.
After it runs, freeze all resulting integer proposals and source records
before the independent rational certificate and source-word execution.

1. Run the pinned literal native endpoint on each of302400 charged
   position/seam/coin columns. Keep current and destination. Construct the
   full240×240 integer transfer counts and verify exact symmetry, column
   sums1260, trace301140 and the existing compact eigen-equation.
2. Hold the first native seam with exactly one endpoint in{4,5,6,7}. Retain
   its altered current/destination for all source columns, rebuild the full
   counts, and preserve the same1260-context denominator. The altered
   branch explicitly overrides the primitive's current on that seam. Its
   eigenbasis is proposed independently, never copied from the main source.
3. A symmetric floating eigensolver proposes all240 eigenvectors and
   eigenvalues per law. Orient each vector by its first maximum absolute
   coordinate and round every value to the2^-44 grid. No vector or low mode
   is discarded. No energy, frequency or confinement gate is evaluated.
4. Save exact source arrays, rational proposal JSON and algorithm/library
   versions. Record both primary and changed-law source columns. Subsequent
   validation must reject an invalid proposal; it must not silently improve
   it or tune any physical threshold after viewing a result.
5. Expected identities inherited from the provider are explicit: original
   lambda_f209/210, TrT239, H=-1260logT. They are not new fits. Invalid
   coordinates remain outside the reference denominator.
