# Native units from unknown total loads

The native source now supplies the canonical signed pair without a +1/−1
compartment-total promise. A current-only controller selects units from
unknown signed multi-loads, retains one of each sign, and clears the surplus
through actual native annihilations. Reversed signs are physically rerouted.
No source reset or hidden-state substitution is used.

All 25 native preparations with unknown K=−12,…,12 reached their selected
class. The 24 nonzero cases produced the actual entire source δ0−δ14 and
the recorded positive frame; the zero case returned no-unit. All 25 same-reader
swap/hold controls failed selection. The active run used 5,576 literal native
calls and 50 changed-law calls. Full event tapes, a 64-hold native timeout,
occupied-target rejection and wrong-sign rejection remain in the records.

`python3 -B headline.py` performs a read-only source reconstruction,
independent record check and common-input replay with Python 3 and NumPy.
No network or sibling checkout is needed. The separate checker imports no
producer or native module. The consumer re-executes two 512-epoch compressed
pumps on the actual source-encoded basis inputs and exactly reproduces the
common terminal densities; it does not rerun the full native processor words.

The all-input proof gives complete preparation-inconclusive probability at
most `8501/2^58`, about 2.94938e-14, on the declared bounded neutral family.
The initial vacuum datums, graph, integer source alphabet and control/read
architecture remain supplied. The unit occupancies are selected by the law;
the decision to retain one of each sign is a controller choice. Independent
topological/electric identification remains an applicable full-row obligation.

`attempts/first_seeded_run_v1`. V2 uses the same public coin seed for every K,
and its checker cannot silently rewrite saved evidence. See `AMENDMENT_V2.md`.
