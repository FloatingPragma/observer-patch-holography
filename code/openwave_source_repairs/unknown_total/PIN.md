# Local candidate custody

The new candidate changes the preparation domain and current-controlled
selection/extraction schedule. Its native endpoint function and OLD240 graph
are copied from the exact sealed signed-pair loader. `inputs` binds the common,
loader and route manifests; `CONSUMER_ORIGINS.json` binds the copied downstream
maps to the common manifest. The two preregistrations preserve execution order,
and the V1 predecessor is retained in full.

This packet does not replace an official candidate, source commit or pin.
An accessible outgoing source commit, full other-group review and any pin
proposal remain separate review/release actions. No external source transfer
is authorized or performed by this local construction.
