# Common instrument v2, prospective review correction

The first interface and its passing compatibility receipt remain unchanged.
The independent reviewer found two scope gaps: it accepted any addressed pair
of fourteen ports, and returned only an aggregate failure probability after
erasure. Its positive success-map results stand; it was not an implementation
of every post-measurement failure source state on the intended graph.

`A-pr723-common-positive-instrument-v2` restricts addresses to the original
thirty cell seams plus the separate zero-load reference seam. Invalid nonedges
are rejected, while both orientations of every real edge remain available.

It implements the same Householder flag analyzer as row 7, extended by identity
on the additional current flags. Let w be uniform on ticket×coin×{-1,0,1}, and
u=(w-e0)/||w-e0|| with e0 the (0,0,-1) flag. Every output branch is

    K'_r = K_r - 2 u_r sum_s u_s K_s.

This is a complete orthogonal change of record basis. The first branch is the
old success map; every other branch now retains its actual output source ket.
Higher-current flags remain in the failure complement unchanged. The v2 audit
compares all 384 original row-7 probabilities at each scheduler setting and
checks a larger-current input, in addition to the v1 embedding tests.

Paired row-2 assays use two instances of this source under the declared copy
clock; no shared interaction or clock equivalence is inferred from that tensor
product. The primitive/interface compatibility still does not compile the
observer controllers, coherent preparation, eraser or analyzer from native
integer records, and changes no official cell or source pin.

The source, audit, this amendment and the original record inputs are hashed in
`COMMON_V2_PREREG.json` before v2's first run. This is a verification correction
of a known conditional component, not a new physical prediction.
