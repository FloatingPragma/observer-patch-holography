3. Its observable is computed from observer records and has a possible native
   counterexample. Corrupted data tests do not substitute for a changed-law test.
4. Row 1 checks a domain permitting double loads, an invariant selected class,

5. Row 2 checks actual source evolution, a state-selection control, lower modes,
