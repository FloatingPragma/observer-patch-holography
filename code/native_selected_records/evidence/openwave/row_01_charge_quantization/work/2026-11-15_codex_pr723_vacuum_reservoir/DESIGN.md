## Exact falsifiers and tests before execution

1. **Absolute selected units:** a conclusive native record history with any
   post-burn reconstructed state outside 0/1 or -1/0 rejects the finite-window
   success claim. Such states are representable: all preparations include
   magnitudes B≥2, and the control retains them. A late entry is a failure of
   this finite-window gate, not a counterexample to the asymptotic theorem.
2. **Native transport selection:** use the first nonzero current in the fixed
   calibration window of trial0 as u. A held-out native current with magnitude
   outside {0,u} rejects the claim. A control with no magnitude larger than u
   in its held-out window fails the intended finite discrimination. No control
   is recalibrated. Missing calibration is inconclusive, not successful.
3. **Second transport prediction:** from each reconstructed pre-event unit
   state, count D unequal graph edges. Predict P(j≠0)=D/(2m), independently of
   the calibrated magnitude. For all 36 native held-out windows, reject if
   |observed−sum D/(2m)| exceeds sqrt(T log(2/alpha)/2), alpha=10^-6. This is a
   bounded martingale test; it assumes no stationary burn-in approximation.
4. **Exact local/finite statements:** execute every local contrast [-B,B]^2 and
   both coins. Enumerate every state and native branch of totals0,1,2 on both
   new graphs; reject any binary exit, unreachable state, stationary column-sum
   mismatch, or nonzero-current rate differing from k(N−k)/(N(N−1)).
5. **Instrument:** the same observer must recover every separately retained
   initial audit vector. The scientific plant is a feasible multi-load control
   state; integrity mutations and forced probe timeout are separate checks.
