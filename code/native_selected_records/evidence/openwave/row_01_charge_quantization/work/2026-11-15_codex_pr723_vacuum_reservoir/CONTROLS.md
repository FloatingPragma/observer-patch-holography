# Scientific, sensitivity and integrity controls

**Scientific alternative:** the body event swaps its endpoints when coin1 is
returned and holds on coin0. Geometry, public capacity, preparation, attempt
schedule, raw current interface, native terminal observation and decoder are
unchanged. Swap/hold conserves load and its multiset. Doubles, triples and signed
contrasts are valid source states, not out-of-domain plants. All36 control
histories retain nonunit states and show held-out transported magnitudes larger
than the one common native calibration. Native selected-unit transport therefore
does not follow from the integer alphabet or the initial preparation alone.

**Feasible detector trials:** controls.py executes native probes on actual zero,
single, positive double, negative double and filled-first-cell/empty-reservoir
states. Both the producer reader and the independent reference-current reader
recover the complete input from records. The main run's saturated preparations
then test the filled first cell after native relaxation. The reader's ability to
see a double is established before using absence of doubles as the result.
These diagnostic executions were separately frozen after the main result was
known; they are validation, not a retrospective prospective claim.

**Timeout:** two repeated coin0 native probe events on a double exhaust the
deliberately shortened cap2 and return inconclusive in both readers. The main
cap64 readings have no timeout; every actual probe event is still retained.

**Vacuum-reference boundary:** two full native runs, one uniformly zero and
one uniformly two over all24 ports, have identical current tapes. The latter
violates the initial-vacuum preparation and is retained in CONTROLS.json. This
demonstrates exactly what the supplied initial reference provides. It does not
undo the main valid all-double FIRST-cell experiment, whose reservoir begins
empty and whose records select absolute ones.

**Integrity:** eight separate mutations change a census current, body current,
probe current, initial vacuum datum, declared preparation, decoded final state,
control count or calibrated summary. They are verification tests only, earn no
emergence credit, and are recorded in MUTATIONS.json.

**Identities receiving no credit:** supplied integer outputs, total conservation,
incidence continuity, integer-valued boundary sums, load-vector topology,
arithmetic impossibility of half an integer, and a calibration reproduced in
its own window. The claimed law-dependent result is selection of the single-unit
state/transport class from representable multi-load states. The held-out
conditional nonzero-current prediction is a second test beyond fitting u.
