# Probability and preparation conventions

The theorem's probability law is the declared IID uniform edge/fair-coin
source. Finite reproducible execution uses Python Random at the frozen seeds.
The finite records are literal native event calls on those branch choices;
the all-input theorem is a statement about the specified IID law, not a theorem
about every pseudorandom seed or the infinite behavior of the Python generator.
No physical randomness certification is claimed.

The transport test needs the unit-state hypothesis at the beginning of its
held-out phase. That hypothesis is checked separately through the complete
record reader. Once reached, the native unit class is closed. Conditional on
the starting unit configurations, each held-out indicator has the stated
conditional mean and range-length-one martingale bound. A failed settling gate
would block use of that bound for the claimed experiment; it could not be
silently dropped or rescued by recalibration.

The initial vacuum reference is a declared preparation datum. It is not a
secretly observed simulator variable. Its terminal value is reconstructed
from all intervening current records and may be nonzero. The full-graph
uniform-shift control makes the dependency explicit: currents alone cannot
authenticate the absolute vacuum preparation. This datum supplies the origin,
while native repair versus swap/hold tests the selected magnitude distribution.

The new source family is a product graph of the original cell and a finite
path of B cells. It is not the fourteen-port common instrument. A future
cross-row join must prove the protocol and observation compatibility on this
actual family and cannot rely only on identical endpoint bytes.
