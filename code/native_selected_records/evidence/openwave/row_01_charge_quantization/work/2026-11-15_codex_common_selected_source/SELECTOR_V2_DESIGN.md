# Native ticket-selector successor (prospective)

A-native-selected-source-menu-v2 retains v1's scientific run and every failure.
It replaces the remaining declared uniform source ticket preparations with
native blank-coin programs. Coherent reflection, reversible record uncomputation,
Fourier counters, path split/recombination and erasers remain explicit memory
services. This is not a claim that floor/ceil alone synthesizes arbitrary gates.
The earlier conditional result and all numeric spin/clock targets are known.
The new test is source selection, coherence, complete failures and changed cost.

For n choices let b=ceil(log2 n). An attempt uses b fair native events on the
actual empty reference seam, retaining coin/current records. The b-bit word is
kept coherently. Measure ONLY the predicate word<n. On rejection retain the
whole old word register, allocate a fresh register and retry, at most8 times.
Keep the attempt index and every previous rejected-word register. Timeout is
an explicit terminal outcome. The final accepted word is NEVER measured or
replaced by a uniform classical mixture. For n2M this is an exact power-of-two
preparation without rejection. Native spin ticket=word//2 and edgebit=word%2
reproduce the parent's ordered-star routing at every M4/M8 slot. Address
workspace computed from(arm,slot,word) is reversibly uncomputed after the
native event; word/coin/current enter the complete Helmert eraser.

For n3 use two bits, accept0..2; for n5 use three bits, accept0..4. On acceptance
at attempt t the joint selector-memory amplitude is (2^b)^(-t/2) for every
prior rejected-word prefix and final accepted word. Its state factors as a
uniform rejected-prefix register times a uniform accepted word. Both arms use
the SAME selector preparation and attempt register before arm-controlled routing.
Thus there is no accepted-word or attempt-count which-arm record. The explicit
finite prefix lists and native one-attempt records retain the full coherent
outcome; the numeric check traces the ancillary registers of an arbitrary
Bell-correlated reference and requires the unchanged reference density times
the exact coarse-outcome probability. Classical uniformity alone is not used.

Charge every weighted-triangle cooling preparation (9) and each initial/final
clock A preparation (2):11 selectors of n5. Charge one n3 selector per optical
plane filter, and four n2M selectors per frame. Clock A also uses four native
blank bits for the epsilon1/4 word and one native blank bit for its source-coin
coordinate; these are charged twice. The shared choice register is then carried
through all W words; its declared coherent reflection does not pretend to be
a fresh classical random draw. Fourier-counter preparations are declared memory
operations and are not counted as native selector calls.

The exact new success factor is s5^11 s3^(3M turns), s_n=1−((2^b−n)/2^b)^8.
The full conditional final density is unchanged by these path-independent
selector registers; this is explicitly checked on all16 actual finite states.
The factor is charged to the already tiny v1 coherent success, CONDITIONAL on
the filed successful classical charge/route prefix. It is not an unconditional
finite-horizon charge success rate. Record maximum and conditional-mean blank
native costs. Literal enumerated source calls remain separate from events
represented by a factored branch language.

Reject any nonzero blank current, nonuniform accepted amplitude, missing prefix,
reference crossblock residual≥1e−12, routing-word mismatch, success+timeout≠1,
or full conditional density change≥1e−12. Rerun all11 v1 gates unchanged. A
selector that records its accepted word separately in each arm is a represented
failure of the coherent contract, even if its classical histogram is uniform.
No inherited gate becomes an external review or physical award.
