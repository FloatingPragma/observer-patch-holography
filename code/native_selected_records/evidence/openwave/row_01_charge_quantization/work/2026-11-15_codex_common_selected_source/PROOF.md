## Scope of the result

Theorems1–3 give the stated finite-family interface; the executable common
state-through-rotation test covers B2,M4/8, epsilon1/4, one/two turns, both
orientations and the specified alternative stage law. It establishes a tested
common object and controller menu at that scope. It does not claim every B,M,
every epsilon, arbitrary-axis rotations, exchange statistics, a continuum,
SI electric strength, ambient confinement, inertial mass or a lab time scale.
Further family extension is a concrete new experiment/proof task. The present
conditional join is stronger than identical endpoint code or matching spectra,
because the actual finite density and reference blocks cross the interfaces.
