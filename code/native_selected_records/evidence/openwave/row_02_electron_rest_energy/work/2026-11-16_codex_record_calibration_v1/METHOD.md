# Exact method and interfaces

The scalar source update on an oriented edge is
j=(q_a−q_b−(2c−1)(|q_a−q_b| mod 2))/2, followed by
q_a←q_a−j, q_b←q_b+j. The alternative probe law swaps endpoint loads,
j=q_a−q_b. Admission, routing and blank probing use the native law under
both controls; only `calibration_probe` changes. Thus the probe control is a
declared stage substitution, not a claim that its entire admission mechanism
selects units. The same current-only calibration and compiler serve both laws.

The frozen admission module first reads an unknown signed/multiunit input
through actual source currents, retains its excess reservoir and identifies
a target of observed sign at leaf1. Initial markers and the vacuum reference
remain supplied premises. There is no Q=1 input guard. The trial harness
creates one source closure before admission; it neither resets nor replaces
that closure during calibration. The event closure returns only requested
addresses, the fair coin and the current. The full-state inspector is used
only after execution and in a separately labelled audit.

For input positions 0,1,2 and each of the three triangle edges, the controller
first routes the actual unit to that position. Each route waits at most 64
native events on the appropriate edge for a current-confirmed move. It then
probes the chosen edge, updates its position from incidence and repeats until
both coin values have been seen, using at most 64 probes for that group.
Every repeated conditional column must agree. A final native route returns
the unit to leaf1. A subsequent blank probe records both coins or a timeout.
All failed and successful events stay in the record.

The exact eighteen rows are indexed by observed input position, public edge
and observed coin. The compiler never receives a law label, sign label,
target phase, eigenvector, energy, hidden initial load or random seed.
The scalar raw current remains signed. Averaging each coin with weight1/2
gives P for a declared edge-ticket distribution. The cooling tickets are
[01,01,02,02,12]; the additional active-weight3/4 menu is explicitly a
diagnostic weight, not a new physical prediction. For every M=4,8,32 and
every one of its 3M observer slots, the star tickets mix adjacent incident
two-edge stars with a total of 2M tickets.

The fine map retains output position, ticket, coin and raw current. Its Gram
matrix is calculated from equality of those actual output labels; the code
requires identity. The current-reversal map also flips the coin exactly when
the observed current is nonzero. The complete finite permutation and its
square are tested, not assumed. Inactive blank coin identity is represented
on its declared coherent coin vector; orthogonal padding belongs to the
complete quantum instrument in downstream candidates. These calculations
establish conditional faithful compilation, not a phase-coherence experiment.

The frozen input data contain all totals −12B through 12B for B=2,3,4,
two public admission streams and marker refinements M=4,8,32. Each case
uses both probe laws and two input-independent calibration streams. The M32
rows extend known M4 admission inputs by a public idle marker refinement;
their continuing trajectories were actually executed in this new run.
Independent checking validates exact multiplicities, not just membership.

The no-producer-import reader independently implements the scalar rule,
reconstructs each controller decision solely from the current tape and
checks the full background after every calibration event. It separately
recomputes all P, Gram and reversal columns. This is a second implementation
by the same Codex group, not independent external review. Its complete-input
audit uses hidden initial vectors only to test the already recorded source;
the operational observer and compiler do not use that information.
