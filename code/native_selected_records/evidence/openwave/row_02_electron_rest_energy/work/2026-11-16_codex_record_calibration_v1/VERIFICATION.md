# Execution and verification contract

The first producer recorded the actual source run after `PREREG.json`.
All 16 frozen source/input/document hashes still match. Its data include all
5,256 trajectories, both signed native/control tables, all compiler outputs,
zero terminals and three complete forced timeout histories. No observed
scientific gate failed in this first run. The known static endpoint formula
was not a new prediction; the new execution claim is continuing-particle
operational calibration on the registered backgrounds and public streams.

`VERIFICATION_PREREG.json` froze the no-producer-import reader before its
claimed verification. It passed in 10.138 seconds, checking 936,660 actual
fair-run source endpoint records,590 timeout-control records and 536 menus.
The observer replay consumes ordered current records; its independent source
audit uses the explicitly separated hidden initial vector. Exact trial and
column multiplicities prevent dropped or duplicated inputs from passing.

The original producer's default comparison covered all saved evidence but
only the receipt's pass flag/hash. `experiment_v 2.py` is a complete descendant,
not a wrapper that substitutes an external verdict. Its scientific `run`
function is AST-identical to the frozen producer. It additionally requires
the entire saved receipt equal the fields derived from the saved evidence.
The original source, original receipt and complete evidence are unchanged.

The verification-only repair and mutation plan were frozen separately in
`VERIFICATION_REPAIR_PREREG.json` and `MUTATION_PREREG.json`. Fifteen actual
process tests passed, retaining command, status, stdout, stderr and elapsed
time in `VERIFICATION_TESTS.json`. Every scientific rejection was matched
to its intended predicate, not accepted merely because some error occurred.

- Clean full producer under `-O`: exit 0,27.587 seconds.
- Independent full saved-record reader under `-O`: exit 0,11.470 seconds.
- Inverted native/control discrimination: intended failure, exit 1 in normal
  and optimized Python. Only the copied mutant's custody binding was updated
  so that these test the actual scientific predicate rather than a hash check.
- Changed saved evidence and changed ancillary receipt: intended failures,
  exit 1; existing evidence was not regenerated or overwritten.
- Missing/duplicated trial, missing conditional column, changed first
  calibration current and changed reversal column: intended reader failures.
- Invalid actual coin and duplicate compiler column under `-O`: rejected.
- Existing record directory: rejected; explicit fresh recording: succeeded
  and reproduced the complete result except the excluded runtime field.

All tests mutate only temporary copies. The frozen source, inputs and saved
evidence retained their exact bytes, modification times and inodes. The test
suite took 149.529 seconds total with two concurrent processes; the longest
individual process was 31.879 seconds. The full mutation suite is not claimed
to satisfy a single under 60-second headline. The complete 208-line independent
reader and full producer replay each do.

The primary semantic claim is deliberately narrow: one continuing admitted
unit, actual measured conditional columns, source-faithful conditional maps,
retained background and return. Parent integration independently checks a
separate 32-source/16-pair continuation and joint operator. Those records do
not retroactively count as external review of every primary trajectory.
