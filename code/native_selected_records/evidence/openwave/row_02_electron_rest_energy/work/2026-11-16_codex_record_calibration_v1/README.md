# Continuing-source operational calibration

This component closes an operational interface gap: the same admitted signed
unit is routed, probed and returned, and actual observed coins and currents
produce all eighteen conditional endpoint columns. It does not independently
discover coefficients already implied by the declared native law, demonstrate
quantum coherence, establish physical mass, or change an official row mark.

The first actual run was frozen by `PREREG.json` before execution. It passed
5,256 trials in 15.069 seconds: 5,184 complete calibrations and 72 honest empty
input terminals. Three deliberately biased-stream timeout controls retain
their complete records. There are 622,380 actual admission events and 314,280
actual calibration events in the fair runs; 69 is the largest observed
calibration cost. These include 69,336 always-swap probe control events, so
the total 936,660 is a source endpoint count, not an all-native count.

The exact cap-64 theorem gives failure at most 597/2^64, including the blank
check, at most 37,568 endpoint calls and expected cost at most 86. It assumes
stationary deterministic coin-conditioned dynamics and IID fair future coins.
The two fixed public replay streams are crossed with every hidden input;
the finite runs do not independently establish fair randomness.


The standalone 208-line independent reader imports no producer modules. It
checks every saved current, seed stream, requested action, signed spectator
invariant, return, table and all 536 compiled menus without regenerating the
source. Its initial verification took 10.138 seconds. Its output field
`native_records` is inherited terminology for 936,660 source endpoint records,
including the explicitly counted always-swap probes. The complete producer
replay executes fresh source trajectories and compares existing evidence;
default verification writes no files. The active full producer is
`experiment_v2.py`, whose calculation is unchanged and whose receipt comparison
is complete. The originally frozen `experiment.py` is preserved: its default
mode checks full evidence but does not compare every ancillary receipt field.
Only explicit `--record-to NEW_DIRECTORY` creates a fresh exclusive record.

`MEASURED_TABLES.json` extracts four representative tables from the saved
actual records. The runnable common-source API is:

```python
request, inspect_audit_only, record = integration.start(
    initial, public_graph, admission_seed, calibration_seed, probe_law)
```

Only the harness receives `initial` and seeds. The observer consumes the event
closure, public graph and record-derived admission sign. Downstream code must
consume `record['calibration']['columns']` from its own actual continuation;
the representative table labels are audit metadata, not a hidden-label reader.
The returned request closure still owns the same full source state. For B=2,
M=32 the graph has 223 ports, target [0,24,25] and blank [29,30].
