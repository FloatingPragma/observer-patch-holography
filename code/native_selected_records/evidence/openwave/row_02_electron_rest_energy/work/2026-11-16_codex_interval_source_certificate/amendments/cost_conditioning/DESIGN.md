# Outward certificates for the actual finite source

This is verification of the reference-menu source at local commit
`b6df2961f4ec8fc9a9f70a3c65e39da8dafa7e60`. Its nominal 224 results and
impurity margins are known. This work does not claim prospective discovery of
those results. It replaces the numerical premise of the interval reader with
outward enclosures of the source state, pair population and binary laws.

The certificate uses the exact invariant four-dimensional walk sector. The
literal native integer transitions determine the position mean and the walk
eigenblocks. A finite counter is evaluated as its geometric sum of native
word eigenvalues, retaining both eigenphase signs and both optical modes.
The retained counter outcomes define a completely positive Schur map. Actual
cooling, decoding, path crossblocks, re-encoding, selected path and independent
pair moments follow in that same sector. No pure target ray replaces a state.

Interval arithmetic uses the installed mpmath 1.3.0 outward real/complex
arithmetic and square root. The Fourier root uses a Machin arctangent series
and finite sine/cosine series with explicit remainder enclosures. These
apparatus coefficients are distinct from the source eigenvalues. Every
serialized endpoint has an exact dyadic representation. Decimal summaries
are display values rather than machine certificates.

The numerical tests require positive conditioning denominators, certified
single/pair unwanted-band population below the filed 0.002/0.01 bounds, and
enclosures agreeing with the filed binary laws within 1e-10. Native one-turn
visibility must be strictly negative, native two-turn positive, and swap
visibility positive. Matched exact dark-port outcomes are treated by the
source-derived positive scalar law rather than clipping a floating center.
Complete selected-clock and pair preparation probabilities are retained.

The default verification command compares a recomputation with saved evidence
without changing it. First-record creation requires an explicit exclusive
destination. Failed scientific checks produce a nonzero exit, including under
optimized Python. Known old source data, all source hashes, the code and gates
are frozen before the certificate execution. Arithmetic pilots are labelled
as such. Source or apparatus descendants require their own certificate and
full common-source transfer; this certificate grants them no borrowed result.
