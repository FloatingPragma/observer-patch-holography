# Free waves from observer records

Finite observer records support a conditional free scalar and Maxwell
reconstruction under the declared preparation, routing, clock and readout.
The package contains the source records, their mathematical assessment and a
portable replay with explicit numerical comparison rules. Physical source
admission and the complete candidate pin require author and external review.

See the [method and reproduction commands](METHOD.md), the
[proof assessment](evidence/notes/wave_review_20261115/PROOF_REVIEW.md) and the
[complete source specification](evidence/shared/unified_wave_submission_20261115/evidence/unified/PIN_SPEC.md).
