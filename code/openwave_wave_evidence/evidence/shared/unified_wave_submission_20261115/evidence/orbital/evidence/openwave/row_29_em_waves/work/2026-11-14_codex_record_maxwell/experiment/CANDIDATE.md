# Proposed auxiliary candidate MFR-Maxwell-product

Class N+, unpinned. Pinned native endpoint function is used unchanged. The
physical common-source owner decision is not inferred from permission to study
this candidate. The proposal extends the graph, scheduler and observation tape.

One component has a 3x3x3x8 periodic array of twelve-port graphs, thirty
internal seams per cell and twelve port-preserving external seams per positive
coordinate direction. All 16,848 seams have weight one. A disclosed uniformly
drawn one-unit initial position is followed by IID uniform seam and fair coin
choices. Four independently randomized components are observed in blocks of
16,384 events each. Channel mu labels the mu-link centred record fluctuation.
Its field-strength readout is the antisymmetric nearest-neighbor difference.

The endpoint/spectator census exploits the local endpoint rule: for each
global seam, three local loads represent the unit at the first endpoint,
second endpoint or a spectator. All six branches are executed by the pinned
function and retained. For the first 64 global seams the same branches are
also executed on full 2,592-entry vectors. This is declared compression of
identity spectator branches, not a claim to enumerate all global histories.

The population calculation uses the exact macro transition obtained from those
current branches. It sums the finite-block covariance analytically. Block
lengths 10^7 and 10^9 are population calculations, not actual long tapes. The
65,536 actual current events are separately retained and replayed. Their
field-strength values are not claimed to estimate the limiting covariance to
one-percent accuracy.

The changed-law control redraws the location independently and uniformly at
each event. It retains the same covariance normalization and curl decoder.
This control is computed from its exact population transfer; it is not the
pinned endpoint function, and no synthetic native tape is claimed for it.
