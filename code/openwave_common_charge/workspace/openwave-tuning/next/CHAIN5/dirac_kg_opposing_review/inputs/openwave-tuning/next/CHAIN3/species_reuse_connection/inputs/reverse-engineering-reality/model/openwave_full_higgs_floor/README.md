# Charged mass floor with the complete Higgs action

All three native Higgs channels, sharing the declared family analyzer,
remove every charged zero mode of the free source. Exact charge and
spectral identities give a complete charge-one energy floor while retaining
neutral zero modes and all spatial valleys. The shared quark spectra are
conditional outputs; unequal observed quark masses require a different
family selection.

See the [derivation](PROOF.md) and [complete records](results.json).
Run `python3 -m model.openwave_full_higgs_floor --check`.
