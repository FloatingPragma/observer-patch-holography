# Register coefficients in the shared mass slot

The actual 432-state generation register supplies a finite analyzer effect.
An explicit native flavor word installs its three positive coefficients in
the shared field source's mass slot while preserving its currents and
clock. Weak-return failures, analyzer complements and native export outcomes
are retained. A separate full native Higgs-Wilson calculation substitutes
the same coefficients without removing neutral, quark or corner states.

The [proof](PROOF.md) states the source boundaries and retrospective input
ancestry. Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 run.py` for
the finite checks. The full field iterator and the million weak rounds
are finite resource constructions, not executed large simulations.
