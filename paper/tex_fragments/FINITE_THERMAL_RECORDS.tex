\subsection{Stationary native populations and the thermal obstruction}

\begin{proposition}[Full-support equilibrium obstruction]

stationary for $K$. In particular, $\exp(-E/T)/Z_M(T)$ is neither
stationary nor detailed-balanced for any finite $T>0$. The endpoint

\end{proposition}
\begin{proof}
The pointwise drift $d=KE-E$ is nonpositive. Each nontrivial sector has
an executed strict-descent edge, so $d(s)<0$ for some state $s$. A
stationary law would satisfy
$\sum_s p(s)d(s)=\langle pK,E\rangle-\langle p,E\rangle=0$,
contradicting full support. A strict-descent edge also has zero reverse
probability. The generic finite push/pull argument is kernel-checked in
\path{Lean/Dynamics/StationaryLyapunov.lean}; the source supplies its
exact drift premises.
\end{proof}
