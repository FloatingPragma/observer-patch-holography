# Native current memory and protected source charges

## One source and complete records

This result uses the fixed fair C/E process of `openwave_native_process`.
The elementary H66 sector consists of two occupied positions among twelve.
The federation examples use the full global two-load sector on 240 and 960
ports. The source, record alphabet, coins and repair rule are unchanged.
There is no added Z6 link state, fractional charge matrix or Hamiltonian.

The preparation declares two known distinct occupied positions. An observer
receives that preparation and the complete committed record tape. The decoder
replays each record's partial injection and checks its actual law, raw label,
coin and current against the supplied initial configuration. It returns an
explicit invalid-record or incompatible-preparation outcome when these fail.
The terminal hidden source appears only in an independent equality check.
For an unknown initial configuration this position decoder is not available.

For oriented seam `(a,b)`, let the recorded integer current be j. The native
update satisfies

```
n'_a - n_a = -j,       n'_b - n_b = j.
```

Summing events gives `n_final - n_initial = -div J`, with outgoing-current
divergence. Consequently every region S satisfies
`N_initial(S)-N_final(S)=J_out(S)`. The verifier checks each active vertex
and every cut of the active support in every positive-probability history.
Spectator vertices have zero current, so this proves every global cut
identity without enumerating 2^960 subsets. Every raw history, including
padding and failed identification, retains its probability. A complete
three-event tape has 15,625 raw blocks; no selected trajectory replaces it.

## Complete memory instrument

The acquired integer cut current can be reduced modulo six by classical
postprocessing. The six effects are the sums of orthogonal complete-record
projectors with the respective residues. A seventh effect collects invalid
or incompatible record strings. They partition the entire declared record
space and sum to identity. On the executed valid preparation the seventh
effect has probability zero, as do the raw native padding branches. All six
numerical probabilities and the failure probability are retained.

These effects act on records that the repair instrument has committed.
They add no hidden-source measurement. The original instrument includes the
source backaction and the physical energy of recording is unspecified;
attempts, blank record slots and classical processing are explicit services.

## Exact source-only algebra

Let G be any connected finite graph with V ports and fix 0<N<V. Each E
branch effect, divided by its positive scalar weight, is the diagonal
projector onto a prescribed endpoint difference `n_a-n_b`. The products of
these commuting projectors distinguish every N-element occupation set.
Indeed equal edge differences imply that two configurations differ by a
constant on a connected graph. Equal total number forces that constant to
zero. Therefore the generated algebra contains every rank-one configuration
projector P_x.

Every occupied-vacant edge exchange is a positive native branch. Edge
transpositions on a connected graph generate the full permutation group,
which acts transitively on its N-element subsets. For each allowed movement
x to y, `P_y K P_x` is a nonzero scalar multiple of the matrix unit E_yx.
Their products and adjoints along configuration paths give every matrix
unit. Thus the actual all-seam branch star algebra equals
`M_binomial(V,N)(C)` and its source-only commutant is scalar.

The H66 computation supplies all sixty-six E-effect signatures and sixty-five
actual branch witnesses forming a configuration spanning tree. The two
federations check connectedness and every one-load E signature. The general
N proof uses those graph properties; it does not claim enumeration of every
two-load federation state or every large operator matrix.

If a complete instrument preserves a sharp source projection P, positivity
of leakage probabilities gives `P K(I-P)=0` and `(I-P) K P=0` for every
Kraus branch. Hence P commutes with all branch maps. For the all-seam fixed-N
source above, P is zero or identity. A complete preserved sharp observable
is therefore constant in that sector. The statement concerns source-only
observables, all permitted seams and the declared C/E mixture. It does not
classify additional coherent memory, an incomplete seam schedule or all
particle-number sectors taken together. Total integer load is conserved.

## A complete native loop control

The native triangle `(0,1),(1,5),(0,5)` admits a trajectory
`0 to 1 to 5 to 0`. Its current chain is `(1,1,-1)` in those seam
orientations and its total probability, summed over both C/E law choices
at every event, is exactly 1/8. The zero-current history has probability
1/4. Both return the source to position zero; their current-memory residues
on seam `(0,1)` differ. The complete experiment retains all other histories.
A single allowed repair changes a prepared zero residue with probability
1/2. This measured modulo-six history variable is not a protected source
charge.

The triangle is a graph cycle bounding a face of the native sphere complex.
It supplies no nontrivial sphere winding. The native source has no Wilson
link register, so its current chain is not an identified centre-flux field.
Integer occupation units are not measured electric-charge units. Choosing
a factor of one-third would be an additional normalization choice.

The existing ordered-pair memory construction provides a distinct example
of a protected quantum charge after adding coherent memory with a specified
transport law. This source-only theorem does not reject that enlarged
carrier. It identifies precisely why an added memory operation or a proved
field interface is required for a physical charge claim.
