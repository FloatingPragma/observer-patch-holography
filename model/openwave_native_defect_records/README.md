# Charge information in native repair records

Complete native current records locate two prepared loads as they cross
240- and 960-port federations. Every cut obeys the exact integer continuity
law. A six-outcome memory statistic records current modulo six, but a closed
repair loop changes it while returning the source to the same position.
The complete source-only branch algebra has no nonconstant protected sharp
charge within a fixed particle-number sector. A physical charge therefore
requires an explicit coherent-memory or field attachment.
