# Separated charged responses

A charged probe must retain its opposite charge and the connecting electric flux. On the same eight-cell source, complete apparatuses with one-, two- and three-link separation have positive dressed energy-transfer probabilities exceeding 16%, 8% and 2.8%. The [proof](PROOF.md) controls full source hopping, the original prepared state and every failure record; the [receipt](results.json) records exact rational bounds. Turning these pair responses into a particle rest mass requires control of the compensating endpoint and a joint energy/momentum threshold.

Run from the repository root:

```sh
python -m model.particle_candidate_endpoint_threshold --check
python -m pytest -q model/particle_candidate_endpoint_threshold
```
