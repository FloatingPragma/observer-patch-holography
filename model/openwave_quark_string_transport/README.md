# Moving quark-string records

A fixed gauge-covariant hopping action moves the native fractional-charge
endpoint while its quantum reference and complete flux string remain in the
records. A reducing-subspace theorem gives rigorous autonomous dynamics on
five- and nine-vertex carriers with full fermion and rotor complements.
These are source-unit transport records, with no physical quark rest-mass
identification. See [the proof](PROOF.md) and [the records](results.json).

Run `python -m model.openwave_quark_string_transport --write`, then the
same command with `--check`.
