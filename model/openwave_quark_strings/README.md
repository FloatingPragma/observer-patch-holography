# Native fractional-charge strings

Actual native quark-family holes carry charges +2/3 and -1/3, with their
compensating reference and colour flux on the complete 119-state links.
The native hopping law gives positive finite-time arrival probabilities.
An exact colour-centre phase completes the fractional electromagnetic turn.
The input is a declared filled state; physical quark masses and fractional
spatial winding are not inferred. See [the proof](PROOF.md) and
[recomputed results](results.json).

Run `python3 -m model.openwave_quark_strings --write` or `--check`, then
`python3 -m pytest -q model/openwave_quark_strings` from the repository root.
