# Ordered-spin source receipts

This verifier compares four retained receipts with their complete producers:
the normalized particle scaling measures, canonical continuum fields,
canonical continuum energy and current spectrum. Every scientific flag and
source binding must agree exactly. It supplies one command for replaying those
owners through the model verification registry.

The receipt binds the four inputs, their declared mathematical sources and
their imported package initializers. The provider checks execute their exact
arithmetic and finite controls. Their analytic proofs retain their stated
hypotheses, including the cubic source and selected ordered state. Historical
ancestor snapshots are checked as declared by each provider; this adapter does
not execute every ancestral producer. The particle-scaling provider's false
`dependency_custody_pass` and `all_pass` flags are preserved verbatim.

This is a verification adapter. It adds no particle identification, Lorentz
covariance, scattering theorem or physical mass prediction.

Run `python -m model.spin_source_chain --check model/spin_source_chain/results.json`.
