# Particle masses and one GeV scale

The fixed lepton ratios give conditional electron-anchored values of
0.10565941450 GeV for the muon and 1.77698497081 GeV for the tau. A common
GeV scale cannot make the equal native up/down record-zero energies match
the unequal calibrated quark parameters. The seventeen-species target table
separates native responses, empirical action parameters and unproved rest
masses. The physical source-to-rest-mass mapping is the remaining step.

The [receipt](results.json) retains all quark energy bins and the
[proof](PROOF.md) states the calibration theorem. Replay with
`python3 -m model.defect_mass_catalogue.catalogue --check`.
