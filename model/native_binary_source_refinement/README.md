# Native binary source attachment

This package checks a bounded connection from the actual binary native repair
function to the L=2 count moments and the full state consumed by the regional
response calculation. Its restricted source parser reads the function's
arithmetic, copy, ordered updates and returned signed record.

The Lean endpoint theorem covers binary loads at positions zero and one with
an arbitrary unchanged list tail. The complete 66-state attachment is exact
executable evidence: all 3,960 seam/coin branches, their signed records and
4,356 count-first moments are compared with the actual Python functions.
Standard rational and real-matrix lemmas supply the conditional algebra.

```sh
python -m pip install -r model/requirements.txt
cd Lean
lake exe cache get
cd ..
python -m pytest -q -W error --noconftest model/native_binary_source_refinement
```

Use the repository's pinned Lean toolchain. The strict verifier fails without
Lean. It enrolls `tools.strict_json` itself and rejects source modules loaded
before its enrollment; `--noconftest` keeps the plugins of `model/conftest.py`,
which import that module, out of the run. The `Native binary source refinement` workflow executes the strict
receipt replay and every kernel-dependent test; the no-Lean observer
regression runs the Python controls and skips those kernel tests. Receipt-only
verification uses `python -m model.native_binary_source_refinement --check
model/native_binary_source_refinement/results.json`. To retain
a separate receipt, use `--write` with a path that does not exist. `--evidence`
selects a local directory for receiver-owned compiler logs and artifacts.

The source-selected off-diagonal scene has moment `13/21465`. Its valid
diagonal replacement preserves trace one and all twelve one-port states,
while changing the full state and the selected effect. Omitting the word
coefficient gives `13/1287900`. The tests also exercise source arithmetic and
record changes, substituted case outputs, an outer-rehashed false source
proof, and private/transitive/vendor cache changes.

A receiving Python process fixes its local source context before importing
the native consumers. Warm reuse requires the same source bytes and enrolled
module and function identities, including the actual references held by callers
and cache wrappers. Removing module registry names or reloading the adapter does
not enroll retained producers. Actual callable bindings and cache-wrapper objects
must match their import-time records. A producer loaded outside that context, or source
changed after import, requires a fresh receiving process. Installed interpreter
dependencies retain their runtime trust boundary. Display paths cannot authorize
local source: the declared modules must have receiving import enrollment.
Transitive local imports bind their acquired objects to that same receiver.
Relative requests retain the module's recorded package context.
Shared consumers keep ordinary imports outside a receiving call. The receiver
checks their recorded local acquisitions before accepting a result.
