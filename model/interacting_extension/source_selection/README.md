# References selected by native records

A recorded repair movement selects a three-dimensional reference through a
specified chart transducer. The complete native instrument fixes its first
spectrum, the probability of rank loss after two records, and the correlated
movement-count law. An explicit activity tilt gives a quantum Doob channel
with a complete heralded implementation. These finite results select neither
an interacting vacuum nor a physical clock. [The proof](PROOF.md) states the
required source, access and conditioning assumptions.

```sh
OPENBLAS_NUM_THREADS=1 python -m model.interacting_extension.source_selection.certificate --write
OPENBLAS_NUM_THREADS=1 python -m model.interacting_extension.source_selection.certificate --check
python -m pytest -q model/interacting_extension/source_selection
```

The certificate retains exact counts, algebraic root enclosures and verified
numerical bounds. The array packet retains every padded native label, both
full carriers, every two-record probability numerator and all transfer
spectra. Integer arrays are checked exactly; floating arrays use an explicit
absolute tolerance of `3e-12`. No eigenvector basis is compared. This numerical
check is separate from the exact integer and symbolic identities.

`native_record_dynamics` provides `native_instrument`, `record_references`,
`two_record_reference_law`, `doob_instrument` and `filter_implementation`.
Equal-event counting functions reject weighted or tilted instruments. Full
filter failures remain part of the unconditional output; conditioning on
success gives the Doob channel. Each geometric reference conditions only on
the native record and traces the transducer's finer outcomes.
