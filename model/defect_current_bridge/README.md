# Gauge currents and masses on a defect

An explicit local fermion carrier puts the native gauge currents and the
retained pixel-dependent lepton mass matrix on the same localized radial
states. The complete quadratic Hamiltonian preserves this subspace exactly,
and its eigenvalues include all three lepton coefficients. The carrier and
local pairing are chosen simulator inputs; every site and complementary mode
is retained. See the [proof](PROOF.md) and [source receipt](results.json).

The physical particle interpretation requires dynamical defect formation,
repair-compatible evolution and a relativistic interacting limit. The
construction binds fermions to a supplied texture; adding a fermion does not
create winding.

Run `python -m model.defect_current_bridge --check` for complete source replay.
