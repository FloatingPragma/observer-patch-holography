A second exact code turns all fifteen compensated U(1) CAR hopping factors into fifteen source pulses. `construction.py` produces `results.json`; `finite_compiler.py` produces `finite_compiler.json`. `test_compiler.py` checks the exact source intertwiners, complete native records, reference preservation, padding, source execution, quantization bounds and malformed domains. ## 1. What is native, and what is added

The actual committed C/E operations in `model/observer/native.py` have recorded Kraus maps that are scaled partial injections. `native_interface.construction.exact_native_audit` checks their complete native domains. Finite adaptive compositions, classical conditioning and routing preserve diagonal states and have diagonal effects. They cannot synthesize a coherent phase from a diagonal preparation.

The separate `coherent_seam_repair.program.Observer` already *declares* coherent address preparation, the uniform-address reflection, and owned memory. On an addressed seam its actual repair is

\[
Q=I-ss^T/2,\qquad s=(1,-1,-1,-1)^T,
\]

a real involution. The executable reads all four columns from `Observer.repair`. Real words preserve real density matrices on the same real code. The exact target Cayley state `(15/17,-8i/17)` has off-diagonal density `120i/289`, so those real words alone cannot implement that target on this code. This is not a no-go theorem for a larger rebit encoding. The optional addressed `quarter_turn` is an apparatus phase already present in the Observer API; neither its existence nor the real reflection proves an arbitrary-gate compiler.

The sufficient additional interface used here is precise:

1. Coherently load one or two selected memory bits into the existing two/four-dimensional proper code of the six-level processor, preserving all references. The native configuration chart and the field code are declared memory dictionaries.
2. Apply the signed integrated port control `exp(sum_p c_p D_p)`, with supplied real coefficients and a specified error allowance. The twelve `D_p` are the retained source response generators. Their exact `Q(sqrt(5))` control identities are checked by the existing source compiler before execution.
3. Export by the complete code-plus-failure channel. Success is the identity on the valid code; every complement basis vector has its own failure Kraus map. Retain failures, storage, routing and native records.

This is the existing coherent proper-code gluing (CCG) premise plus controlled source response, now specialized to explicit field services. Complex actuation and coherent transfer are independently stated obligations; calling the combined API one primitive is not a minimality proof. Reset, pulse, load/export, address schedule and native pointer costs are charged separately. The source's native integer repair does not establish CCG or the accuracy of an analog actuator.

## 3. Finite precision, leakage and complete-instrument error

For exact anti-Hermitian source generators and two real integrated control vectors, unitary Duhamel gives

\[
\|e^{\sum c'_pD_p}-e^{\sum c_pD_p}\|
\leq\sum_p\|D_p\|\,|c'_p-c_p|=: \eta.
\]

`coefficient_precision` constructs **rational** enclosures of every exact `a+b sqrt(5)` coefficient, using integer square roots, rounds controls to a `2^-B` grid, and bounds every generator norm by its enclosed entrywise absolute sum. This produces a rational per-pulse `eta`; no matrix-norm floating result enters the enclosure. It also executes those quantized coefficients through the full six-level response.

Independent coefficient error can destroy cancellation and leak outside the proper code. The symmetric default quantization retains the code in this example; a separate one-grid-unit port perturbation exercises a nonzero failure branch and includes that perturbation in the same rational bound. Both replays explicitly apply **all five export Kraus maps** and feed the *subnormalized* successful block into the native C pointer. Complement outputs terminate with their failure records; no successful branch is divided by its probability. The complete output mass is checked. At 32 coefficient bits the unperturbed rational enclosure is approximately **5.31e-9** per pulse, separate from the source replay residual. This is an exact-control quantization bound, not a measurement of hardware precision or floating exponential backward error.

More generally, if actual generator `D'_p` has error at most `zeta_p`, and coefficient error is at most `epsilon_p`, one may use

\[
\eta\leq\sum_p(\|D_p\|\epsilon_p+|c_p|\zeta_p+\epsilon_p\zeta_p).
\]

For `m` pulses, telescoping unitary products gives operator error at most `sum_l eta_l`. Half diamond distance between their unitary channels is at most this operator bound, including arbitrary references. Complete export/readout and adaptive record processing are channel contractions. If load/export/storage services have half diamond errors `delta_j`, native readout has error `delta_read`, and reset timeout bounds are `tau_work,tau_aux`, the whole stated output comparison is bounded by

\[
\min\{1,\tau_{work}+\tau_{aux}+\sum_l\eta_l+
\sum_j\delta_j+\delta_{read}\}.
\]

Any target-Hamiltonian/product-formula or requested-state approximation adds its own term. This bound compares complete outputs under the explicitly stated treatment of private reset logs; it contains no conditional-success denominator. Backend roundoff diagnostics do not fill an unspecified physical `delta_j`.

## 5. A finite generalization with explicit cost

For an explicitly supplied finite Hermitian `H`, pad it by zero to `2^n` and expand it exactly as `sum_j h_j P_j` using `h_j=Tr(P_j H)/2^n`. The source compiler already emits each `exp(-it h_j P_j/r)` using actual one-bit controls and phase-exact source CNOT words. No arbitrary logical basis change is free.

For `r` first-order product steps,

\[
\|e^{-itH}-U_r\|\leq
\frac{t^2}{2r}\sum_{j<k}\|[h_jP_j,h_kP_k]\|
=\frac{t^2}{r}\sum_{\{P_j,P_k\}=0}|h_jh_k|.
\]

There are at most `4^n` terms and at most `max(1,8n-5)` source pulses per Pauli exponential, hence at most `r 4^n max(1,8n-5)` pulses and twice as many proper-code service events. This is a finite constructive upper bound, not efficient scaling. Intermediate Pauli factors need not preserve the native Gauss subspace; their total deviation is controlled by the stated norm bound. The two exact codes above avoid that intermediate-Gauss issue.

The executable decomposer is deliberately capped at four qubits. It emits and executes all eight columns of the actual native five-state Yukawa cyclic block plus three padding coordinates. At `t=1/3,r=16`, it uses **3,088 pulses**, has exact bound **11/288**, and observed operator error about **0.010168127**. Padding is never discarded. A separate complex-state preparation compiles amplitudes and relative phases from a reset blank, executing **290 pulses** with a separate numerical error about `8.1e-15`.

This supplies an algorithmic replacement for an arbitrary finite target-unitary oracle once its finite matrix/target coefficients and coherent memory services are available. For a larger supplied purification such as `vec(Q)`, amplitude-tree preparation and phase synthesis give a finite circuit in principle. The enormous primary spatial matrices, their state preparation, nonabelian controller and all physical service accuracies have not been constructed or executed by this package. Source/state/clock identifications and continuum claims do not follow from these finite service compilers.
