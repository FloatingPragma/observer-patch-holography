# Retained source identity and atlas navigation

The primary Wilson certificates use content-addressed identities. In
`particle_common_contract.contract.member`, the source contains a map of
implementation hashes. The digest of the source enters the state, reference,
clock and member digests. A receipt-custody change can therefore change the
names without changing a Hamiltonian coefficient or an apparatus record.
The original contract and its immutable-ancestry checks are preserved.

The atlas consumes six retained certificates: regional fermions, composite
spin, the reduced sector, loop fusion, candidate correspondence and candidate
confirmation. Their exact bytes and original identities are bound by
`retained_source_equivalence_authority.json`. That authority also identifies
six canonical receipt files with separately executed live custody renewals.
For these six files, the admitted difference consists of equally shaped
source maps and three individually named nested receipt pointers. Every
non-provenance value is exactly equal. Source-map additions, deletions and
unlisted pointer changes are rejected.

All other retained input files, including the complete executable closure,
must match their historical hashes. The six changed files resolve to exact
archived bytes for historical execution. The isolated view contains 1,997
authenticated inputs, including the common-contract and finite-ratio parent
guards. It changes no producer, numerical comparator or provenance rule.
`replay_retained_atlas_source.py` executes all six unchanged certificate
producers there and requires complete semantic JSON equality. It also
reconstructs the original common members at levels zero and one and checks
their entire member values and content-addressed identities.

For the physical comparison, remove only `source.implementation_sha256`,
the explicitly named source/state address fields, and the resulting member
and identity digests. Retain every carrier, operator, coupling, preparation,
reference, time convention, resource bound and record-law value. The unchanged
program and equal non-provenance input data specify the same matrices on the
same complete basis. The identity map consequently intertwines the
Hamiltonian, prepared state, reference and clock. This assertion concerns the
specified finite program; it adds no physical species or continuum claim.

The leaf atlas returns the original certificates and original physical IDs.
It records current file custody, archived inputs and the historical execution
under a separate `navigation_digest`. It does not label the retained primary
receipts as newly emitted live producer outputs. Exact receipt-value checks
preserve the original scientific gates, including empty physical-particle
and GeV-mass inventories. No current primary identity is synthesized by
rewriting a digest inside a frozen proof.

Run the historical execution with
`python tools/replay_retained_atlas_source.py --write`. A change to its bound
receipt requires explicit review of the replay digest in the leaf adapter.
The two genuinely live atlas parents have the separate command
`python tools/renew_atlas_parent_custody.py --renew`, which invokes their
unchanged producers and preserves all scientific values and rendered reports.
The separate navigation projection is generated or verified with
`python -m model.particle_atlas_explainer.retained_source_equivalence --renew`
or `--check`.
