# Conjugate source excitations

The full Wilson source has an exact particle/hole symmetry when the
fermions and gauge-link coordinates are transformed together. Opposite
native-occupation sectors have identical energy spectra. Conjugate
preparations and complete detectors have equal original energy-record
probabilities, with the same state and clock. The [proof](PROOF.md)
includes the Gauss and cutoff checks and keeps the reference explicit.
This source symmetry supplies no Lorentz spin or observed antiparticle name.

Run `python -m model.particle_primary_charge_conjugation --write` and
`python -m pytest -W error model/particle_primary_charge_conjugation`.
