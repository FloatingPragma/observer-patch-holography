# Retained test identities and current dependency validation

This adapter executes 1,005 explicitly enumerated cases from 81 unchanged test
files against their original scientific source at Git commit
`bc63b3dd8b7a352337b2080d025cbd46934bc36f`. Their original test bodies, fixtures,
parameterizations, configuration and immutable identity checks run in a fresh
private checkout. A historical pass has that domain; it does not establish a
claim about a changed current scientific function.

The session header, terminal summary and each case's report properties name
that execution domain and commit. Collection retains the same selected case
IDs, count and order after the existing shard and selection hooks finish.
Every unlisted test continues to execute against the current tree. There are
no skips, dropped cases, cached outcomes or replacement scientific assertions.
A passive reporter records the original setup, call and teardown results.
Missing outcomes, unexpected skips, xfails, failures, process errors and
unreviewed imported executable differences fail the outer case. An original
failure keeps its original diagnostic in the outer failure report.

## Execution

Use the repository's Python requirements in a real environment: subprocesses
run Python in isolated mode. Full Git history must already be available. The
adapter never fetches over the network or mutates the main checkout. Observer
CI and the narrowly affected completion `program-native` job use full-history
checkout. A missing retained commit is an explicit failure.

The normal model pytest collection installs the adapter. For an explicit
check without automatic installation, use
`python -B -W error -m pytest -p model.retained_identity_execution.plugin` with
any selected original paths. The original historical horizontal-atlas
producer runs in the private checkout when its tests need the ignored SVG.
No source or test file is rewritten there.

Each execution writes the original output, complete phase journal, current
comparison summary and source commit beneath
`.pytest_cache/d/retained_identity/`. The private checkout is removed after
execution. The old result receipts never substitute for actual test outcomes.

The scientific dependency checks run both before and after the actual
original cases. If the live publication manifest differs from the sealed
one, the sole alternate route is the separately authenticated documentary
successor: it preserves every current scientific file and checks the actual
current PDFs. A rejected or missing documentary authority never falls back
to historical success. The two original current-custody suites have their
own explicit 35-case current-source/documentary view; they are disjoint from
this 1,005-case historical inventory. See `VERIFICATION.md` for the precise
scope of completed executions and the completion-workflow routing.
