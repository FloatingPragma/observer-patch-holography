# Untruncated SU(2) plaquette spectra

Exact character arithmetic encloses the energy levels and positive gap of
a pure SU(2) plaquette while retaining its infinite representation tail.
The same source supplies nonzero curvature variance and Euclidean
correlations with explicit error bounds. Complete finite character records
are reported alongside the full-space bounds.

The [proof](PROOF.md) treats a one-plaquette restriction, not a growing
three-dimensional volume or a physical glueball mass.

Run `python -m model.openwave_su2_spectral --check`.
