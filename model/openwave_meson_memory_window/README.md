# Controlled meson emission

The same native meson current gives a positive outgoing-emission probability
on an infinite line over a controlled finite interval. A cubic memory bound
controls repeated emission and return, while an exact family reduction keeps
all nine channels. Local coefficient, numerical and finite-volume errors are
included. The finite interval does not establish a physical strange decay or
an irreversible lifetime.
