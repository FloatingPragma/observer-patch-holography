# Native integer-charge criterion packet

Run `python -m model.native_criterion_packet --check` from the repository root.
The command executes the same charged source and electric links for two steps,
measures complete regional charge/flux records, and checks the full inverse.
It does not substitute stored probabilities for the source calculation.

Integer Gauss charge and odd-charge indivisibility are finite results. The
physical electron assignment and review of the declared simulator extension
are explicit remaining requirements. The pinned official31-row table is
retained without local awards. [Proof and scope](PROOF.md).
