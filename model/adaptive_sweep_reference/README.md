# A faithful reference under native feedback

The observer's own repair records select its next complete sweep. On all
66 binary states of the twelve-port carrier, this continuing process has
one faithful stationary state jointly with its two working memory bits.
An exact quantum contraction bound gives preparation to half trace distance
below one millionth from any input, including correlations with another
system. A preliminary sweep also admits all 78 total-two states.

The [proof](PROOF.md) and [replayable certificate](results.json) give the
source law, finite bounds and full outcome accounting. The stationary
reference is tracial; a nontrivial physical modular clock and a field or
gravity limit require separate constructions.
