# Native charge and the necessary matter carrier

This package closes a finite **same-carrier capacity and obstruction** premise.
It composes the actual C/E ordered-cover instruments in
`model/defect_protection` with the existing conditional exterior matter module.
It does not identify the native memory charge with a particle. It is useful
precisely because matching a two-valued charge or an eigenvalue signature
alone leaves a substantial gap.

There are two different results. An internal weak-grading control fits into
a designed eight-dimensional fiber, but it gives seven positive and eight
negative **native exchange characters**. It therefore cannot realize a
requirement that one collective fifteen-label module have uniform negative
character. That particular encoding requires a fifteen-dimensional fiber
instead. This is not a universal fermionic memory bound. The later
`defect_field_bridge/colored.py` construction gives each particle its own
internal state: its true two-particle exchange is `-SWAP`, and both native
characters occur. This package retains its full positive-sector complement.

Run from the repository root:

```sh
python3 -m model.defect_identity.identity --check
python3 -m pytest -q model/defect_identity/test_identity.py
```

`identity.py` derives the exact receipt `results.json`. Its source bindings

supplied persistent ordering bit. Route A proves, from all complete native
branches, that its generated star algebra is

\[
\mathcal A=M_{66}(\mathbb C)\otimes\operatorname{span}\{I,X\}

\mathcal A'=\operatorname{span}\{I,Q\},\quad Q=I_{66}\otimes X.
\]

Thus every continuous internal unitary action commuting with each fixed
complete branch is abelian on this domain. A nontrivial action of either

that permute source addresses, seams or recorded outcomes have a different

## Exhaustive involutions, then the centrality obstruction

A unitary involution is Hermitian, hence unitarily diagonalizable with
eigenvalues \(\pm1\). Blockwise conjugation therefore classifies all
involutions of \(G\) by the negative multiplicities \(a\in\{0,1,2,3\}\),
\(b\in\{0,1,2\}\), with \(a+b\) even. A block-unitary conjugator can
always be rescaled by a scalar to have total determinant one without
changing its conjugation, so these are also the conjugacy classes in \(G\).
The six classes are

\[
(0,0),\ (0,2),\ (1,1),\ (2,0),\ (2,2),\ (3,1).
\]

On the exterior module, every nonidentity class has signature \((7,8)\).
For example, if \(n=a+b\), the negative multiplicity is
\(n(5-n)+n= n(6-n)=8\) for \(n=2,4\): the first term comes from
\(\Lambda^2\), the second from \(\Lambda^4\). They nevertheless act on
different field blocks. Equal signatures do not establish equal charges.

Suppose now that the native deck charge on the matter subspace is the image
\(\rho(J)\) of a **nonidentity** \(J\in G\), and that the full internal
\(G\) action commutes with every native branch. The commutant formula forces
\([\rho(g),\rho(J)]=0\) for every \(g\). Faithfulness makes \(J\) central.
The only nonidentity central involution is

\[
J=\operatorname{diag}(I_3,-I_2).
\]

It is negative on \(Q\) (six states) and \(L\) (two), positive on
\(u^c,d^c,e^c\) (seven total). The other four nonidentity involution classes
cannot give the full commuting gauge action, despite their identical
signature and the existence of abstract charge-intertwining embeddings.
In particular this operator is not fermion parity on all fifteen states.

\[

\]

## Uniform negative-character encoding uses a separate factor

The native \(Q\) eigenvalue is an exchange character. Suppose one
**collective** fifteen-label module attached to the entire native pair is
required to have uniform negative character. The weak-grading construction
has seven positive characters and fails that specified encoding condition.
This condition is stronger than saying that each particle is a fermion:
with a separate internal state per particle the exchange operator is
\(-\mathrm{SWAP}\), whose symmetric internal subspace has negative
character and whose antisymmetric subspace has positive character.

No element of the internal group can repair that mismatch: if
\(\rho(g)=-I_{15}\), then \(\rho(g^2)=I\). Global faithfulness forces
\(g^2=1\), while the exhaustive involution classification has negative
multiplicity zero or eight, never fifteen. Thus the native uniform
negative collective character must be represented as a separate factor
commuting with the internal \(G\) action.

For one collective fifteen-state module with \(Q=-I_{15}\), the negative
memory eigenspace must have dimension at least fifteen. Consequently
\(m\geq15\), and the smallest design in this declared class is

\[
\mathcal H=\mathbb C^{66}\otimes\mathbb C^2\otimes\mathbb C^{15},
\qquad W_-=\begin{pmatrix}I_{15}\\-I_{15}\end{pmatrix},
\qquad V_-=W_-/\sqrt2.
\]

It obeys \(W_-^*W_-=2I\), \(QW_-=-W_-\), and the full internal action
\(I_2\otimes\rho(g)\) intertwines with \(\rho(g)\) through \(V_-\).
The code verifies all twelve gauge generators, all 144 ordered Lie
brackets, and every complete C/E source-and-matter column, including
the zero and abort slots, for this construction as well.

The full carrier has dimension 1,980; the encoded source-and-matter
subspace has dimension 990. Its other 990 states, the positive exchange
sector, are retained as a second copy of the same internal module. They
are outside the chosen encoding, not erased from the process. Preparing
the ordering bit as \(|-\rangle\) by \(H\) then \(Z\) on \(|0\rangle\)
and tensoring any internal state is a unitary initialization design, not
postselection. Native branches and the specified internal action preserve
this negative sector. The abstract preparation is exact; source execution
and resource accounting for the whole new fiber remain separate work.
