# Paired scales and conditional bare quark masses

All 32 paired archive streams supply rho, conventional string and
explicit r0-benchmark inverse spacings, scale comparisons, hadron GeV
coordinates and bare Wilson quark GeV coordinates at all original hopping
parameters. The ratio-tuned and critical parameters are propagated together.
These bare action parameters are not identified physical quark masses.

[Proof](PROOF.md), [code](scale.py) and [receipt](results.json) retain the
calibration ancestry, full covariance, crossed fit allowances and controls.
Run `python3 -m model.paired_hadron_quark_scale --check` from the repository root.
