# Neutrino propagation through matter

The literal native electron-neutrino current gives the matter potential
sqrt(2)GF n_e. Complete finite electron-spin instruments approach its
coherent three-flavour law with an explicit channel error, retaining both
helicities, sterile outputs and antineutrals. A declared 2.5GeV, 1300km
medium gives electron appearance 0.06970 versus vacuum 0.04910.
The source is an explicit forward-current port construction; measured
beam-event rates and unfiltered scattering are separate questions.

Run `python3 -m model.openwave_neutrino_matter --check` and
`python3 -m pytest -q model/openwave_neutrino_matter`.
See [the proof](PROOF.md) and [receipt](results.json).
