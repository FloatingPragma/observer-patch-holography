# Native regional entropy and response

## The common source and state

Use the binary total-two sector of the twelve-port native source. Let `C_xy`
count the seam/coin choices sending configuration `x` to `y`. The executable
calls the original endpoint function on all 66 × 30 × 2 choices. The resulting
integer matrix is symmetric, has row sum 60, and obeys `40 I <= C <= 60 I`.
The lower bound follows from symmetric diagonal dominance. Native closed
history reconstruction gives

```
Z = Tr(C²) = 171720,       sigma = C²/Z,
sigma >= m I,            m = 1600/Z = 40/4293 > 0.
```

These are the same count moments and density as
`model/native_quantum_reconstruction`, at length two. A matrix state or trace
probability does not define the native loop weights. The matrix representation
follows from those weights. Its real matrix algebra is generated by the
native transfer and configuration projectors; its complexification is the
declared reconstructed quantum algebra. The present construction adds no
arbitrary-effect implementation or real-time interpretation.

## Exact state variations from unchanged native transitions

Choose a real configuration function `f` with `|f| <= 1` and
`sum_x (C²)_xx f_x = 0`. For `|t| < 1`, weight the midpoint of a two-attempt
path by `1+t f`. The original transition function and scheduler stay fixed.
Equivalently, after a return, retain an acceptance flag with conditional
probability `(1+t f_mid)/2`. Failed flags and nonreturns are accounted for.
For rational filters and parameters these are exact rational record weights;
the calculation uses simulator configuration access and makes no bounded
current-only implementation claim for the auxiliary rational coin.
These are weighted or postselected history ensembles. They are not a causal
quantum-state intervention executed on the forward native source, and they
do not establish physical preparation of the reconstructed density.

Summing the native paths from `a` through `x` to `b` gives

```
K_t(a,b) = sum_x C_ax (1+t f_x) C_xb,
rho_t = C (I+t diag(f)) C/Z = sigma + t X_f,
X_f = C diag(f) C/Z,       Tr X_f = 0.
```

Every matrix coordinate has the same closed-word reconstruction as the
unweighted source. In particular its positivity is proved, not inferred from
the signs of matrix entries: congruence gives
`(1-|t|)sigma <= rho_t <= (1+|t|)sigma`. Acceptance among returns is exactly
one half, so the return/flag normalization is independent of `t`. The complete
terminal probabilities sum to one. Invertibility of `C` makes `f -> X_f`
injective; the normalized filter space has dimension 65. These are 65 real
symmetric directions, not all 4,355 complex Hermitian traceless directions.

## Regional algebra and completion

For a proper port set `A`, the native configuration basis has the exact
decomposition

```

M_A = direct_sum_q B(H_A,q) tensor I_Ac,2-q.
```

The tensor chart is the literal split of occupied port subsets; no fermionic
sign or physical locality is assumed. Put `d_q = dim H_Ac,2-q` and
`R_q = Tr_Ac(P_q rho P_q)`. The intrinsic regional density is the direct sum
`R = direct_sum_q R_q`, of trace one. The canonical tracial expectation has

```

```

This map is positive and trace preserving and fixes the displayed algebra.
It is completely positive: in each sector use Kraus operators
`I_A tensor |b><c| / sqrt(d_q)` and sum over `b,c`, killing cross-sector
entries. Its Hilbert--Schmidt orthogonality to the algebra proves the tower
law for nested regions. The executable checks the map and a nested pair on
the common source state, while independent tests use the tensor partial trace.

## Quantitative modular first law on the same states

Restrict the whole family `rho_t` to the same region. Denote its reference by
`R`, its tangent by `Y`, and its modular generator by `K=-log R`. Then

```
S(R+tY)-S(R) = t Tr(Y K) - D(R+tY || R),
0 <= D(R+tY || R) <= t² ||Y||_HS² / [2(1-|t|)m].
```

This follows for noncommuting matrices. Normalized restriction is linear;
each partial trace has `R_q >= d_q m I`, hence the common lower bound `m`.
Congruence and positive restriction give `R+s tY >= (1-|t|)m I` along the
entire interpolation. The Fréchet derivative

```
D log(B)[Y] = integral_0^infinity (B+u I)^-1 Y (B+u I)^-1 du
```

has positive quadratic form at Hermitian `Y`, at most
`||Y||_HS²/lambda_min(B)`: diagonalize `B`, or bound the two resolvents and
integrate `(lambda_min(B)+u)^-2`. Twice integrating the entropy Hessian along
the segment gives the stated factor `1/2`. The identity follows directly
from the definition of relative entropy and trace normalization. Thus the
entropy differential equals the modular pairing and the remainder has an
explicit common-state bound; it is not inferred from a numerical derivative.
The same argument applies to the 66-dimensional completed densities.

The code certifies two nonzero cases using only rational spectra and rational
logarithm intervals. For `f=n_0-n_1` on the first seam, the middle-block tangent
is `diag(359/2385,-359/2385)`. It does not commute with the reference. Taking
`t = 3(259/42930)/(4(359/2385))` makes the two perturbed eigenvalues rational
by the `3-4-5` identity. Its first derivative is zero and its strictly positive
relative entropy is the controlled quadratic entropy loss. This tests the
noncommuting, rather than only the classical, first law.

## Fixed occupations do not imply geometric stationarity

The second filter is the Euclidean orthogonal projection of the native pair
occupation `n_0 n_1` onto the null space of all twelve mean-occupation responses,
rescaled to have maximum absolute value one. This projection specifies a
finite intervention statistic; it is not an entropy-maximization principle.
The integer response matrix has rank 12 (including normalization) and nullity
54. The certificate retains the exact filter, verifies each mean derivative
is exactly zero, and proves that its
bulk entropy derivative is strictly positive by outward rational logarithm
bounds. The finite state at `t=1/2` is faithful and has a nonzero entropy
response. The sector probabilities and edge contribution can change despite
fixed mean occupations. All quantities concern one state family and one
regional algebra.

The bare geometric candidate, the number of native edges crossing the fixed
seam region, is eight and has derivative zero. Therefore no positive constant
multiple of that static count cancels the displayed nonzero bulk entropy
derivative. This excludes that area candidate on this variation space.
Fixed mean occupation is not fixed proper volume; the counterexample proves
neither failure of all responsive geometries nor an Einstein no-go.
