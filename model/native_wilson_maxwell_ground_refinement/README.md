# Interacting ground records and photon capacity

The same finite cube and positive macrocell completion have a controlled
interacting ground at every photon cap. A fixed finite energy-agreement
apparatus prepares that ground with all failures retained. Explicit
cutoff estimates compare its complete records with a five-oscillator
mathematical description.

The [proof](PROOF.md) separates the uniform ground gap, actual preparation,
and the two constructive photon-capacity budgets. It keeps the native
source, charge references and physical clock fixed. This is a fixed-volume
result; it supplies no spatial or ultraviolet continuum limit.

Run `python -m model.native_wilson_maxwell_ground_refinement --check` and
`python -m pytest -q model/native_wilson_maxwell_ground_refinement` from the
repository root. The receipt uses exact
rational bounds and outward algebraic intervals, without an eigensolver.
