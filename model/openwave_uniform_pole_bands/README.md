# Uniform native particle bands

Every momentum fibre of the complete interacting one-dimensional neutron
and proton source has an isolated simple ground pole and a positive native
three-field residue. A three-coordinate Schur decomposition and subtraction
of a common kinetic scalar make an exact rational interval cover small.
Both high compact coordinates and every infinite relative-coordinate tail
remain in the certificate. Source parameters are unchanged and calibrated.
These are source poles, without a physical four-dimensional dictionary.

See [proof](PROOF.md) and [records](results.json). Execute
`python -m model.openwave_uniform_pole_bands --write` and independently
`python -m model.openwave_uniform_pole_bands --check`.
