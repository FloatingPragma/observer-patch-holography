# Local quantum measurements from native observer services

The existing coherent clock services and native repair records implement
three noncommuting local measurements on the same biased source. Retained
records also permit a correction that preserves each measured eigenspace,
including its unmeasured spectators. The full source supplies a nonzero
finite uncertainty bound. [The proof](PROOF.md) states the declared services,
complete error bounds and the distinction from a physical position–momentum
law; [the receipt producer](packet.py) checks their execution.
