# Propagation of periodic defects

Repeating the compact defect pair gives exact supercell momentum labels and
four isolated bands. Complete Bloch calculations find nearly flat,
direction-dependent bands; their zero-momentum energies do not establish
relativistic rest masses. Every complementary energy and probe outcome is
retained. The interacting source needs a separate propagation calculation.

Run `python3 -m model.defect_dispersion.dispersion --check` to replay the
[receipt](results.json). The [proof](PROOF.md) gives the band count and
complete energy–momentum instrument.
