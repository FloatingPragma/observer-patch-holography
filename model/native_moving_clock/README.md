# A clock carried by the native charged source

The full coherent walk transports the source code used by the finite native
clock. A reversible tracking apparatus reads that clock by undoing the walk,
performing the complete native measurement, and restoring the transport.
The calculation retains the source, memory, event and failure outcomes. A
fixed-code control loses `23/90` of its code population in one step.

The apparatus is explicitly controlled and uses nonlocal inverse transport.
It establishes a finite source interface; a local autonomous particle clock
and physical rest-energy identification require additional results. See
[the proof](PROOF.md) and the executable source.
