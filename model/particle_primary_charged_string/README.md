# Charged endpoint pairs

A link-dressed matter probe changes the two endpoint charges by opposite
amounts while preserving every physical Gauss constraint. Its complete
energy apparatus has a source-derived populated band on the selected
eight-cell state. The link projection is an intervention with a retained
failure record; it does not replace the preparation by constant links.

The [proof](PROOF.md) gives the charge selection rules, original weights
and errors. Physical species, dispersion and rest mass require additional
spectral identification.

Run `python -m model.particle_primary_charged_string --write` and
`python -m pytest -W error model/particle_primary_charged_string`.
