# Native record probabilities and diagonal representation

This package derives probabilities directly from the integer endpoint repair,
an exact initial classical law and independent fair placement coins. It keeps
the complete record tree, including zero-weight outcomes and explicit halts.
Adaptive seam choices read only the committed prefix. No density matrix,
trace probability or quantum runtime defines these weights.

Disjoint public events add. Their weights determine a unique diagonal density
on the classical record algebra. Additional native coin records implement
every finite dyadic acceptance rule. Order bounds extend these rules uniquely
to all real classical effects, without a continuity axiom. Future continuation
preserves every earlier public-event weight. The [proof](PROOF.md) states the
general finite-history result; the executable uses the existing 78-state
total-two carrier and an explicit enumeration budget.

The two existing quantum repair lifts have exactly this classical diagonal
restriction. This agreement does not select their coherent behavior or a unique
non-diagonal density. Separately, existing compiled complex tomography covers
all 4,356 Hermitian coordinates of the 66-state binary sector under its declared
coherent services and quantum semantics. It is implemented conditional evidence,
not a derivation of universal complex-effect operational equivalence.
