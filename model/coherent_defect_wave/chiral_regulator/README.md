# Left-handed particles without extra low-energy copies

A finite spectral clock propagates the actual fifteen-state native charge
module as left-Weyl fields. All momentum and occupation states are retained.
Its filled reference has positive particle and antiparticle energies, and
its free continuum is controlled by explicit Fourier-tail bounds. The
finite derivative is long-range; this choice does not prove a local
interacting gauge continuum or measured particle masses.

The [proof](PROOF.md) states the source, reference and locality boundary.
