# Native charged Weyl fields

Thirty complete fermion modes per spatial cell are encoded in literal
protected-flux objects carrying actual native charge clouds. A sitewise
encoding preserves the support of even operations in the declared graded
architecture. Exact finite gauge-link identities and local Higgs interfaces
use these same currents and all occupations. Binding and grading are chosen
construction data; a physical chiral regulator, interacting state and mass
parameters require their own derivation.
