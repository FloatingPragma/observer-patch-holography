# Chiral fields and their mass roles

An exact change of the native Weyl variables gives up-type, down-type and
charged-lepton Dirac fields in a specified neutral Higgs background.
Their electric and color currents agree between chiralities; the weak
current acts only on the left. The [proof](PROOF.md) preserves all source
states and explains why these conditional roles select neither a measured
generation nor the free Yukawa coefficients. The quantum interacting
vacuum and its physical mass corrections require separate control.
