# Native interaction on a routed protected object

One specified finite clock transports the literal paired-flux object and
couples its retained link register to native waves. An executed side-three
cube has a strictly positive, error-bounded defect-face response; both
detector outcomes are retained. Empty native registers recover the same
free Dirac route exactly. The [proof](PROOF.md) distinguishes this common
finite construction from an interacting relativistic field theory and
states why this coupling gives no empty-native mass correction.
