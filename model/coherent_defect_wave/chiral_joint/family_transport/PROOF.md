# Common-source compensated family transport

The source is exactly the complete Peter-Weyl Hamiltonian specified in
[`peter_weyl_links`](../peter_weyl_links/PROOF.md), on the \(N=2\) periodic
three-dimensional lattice, spacing \(\pi\), three unit Yukawa coefficients
and unit scalar/link penalties. Its carrier contains all 30 CAR modes per
site, all five scalar states and all 119 states of every link. No Hamiltonian
coefficient depends on the representation selected for preparation. No
source term is added, removed or replaced by an expectation value.

The one-family native representation has the following actual-current
dictionary. The conventional labels denote these finite representation

Every dictionary row is computed from the twelve native generator matrices.
The receipt gives every joint Cartan weight and the eigenvalues of

## One common static reference and physical preparation

Adjoin one static full 30-mode CAR reference at the origin. It has the dual
native representation and two ordinary spin components. For every native
Hermitian generator \(T^A\), its gauge current is

\[
Q_{\rm ref}^A=d\Gamma(-I_2\otimes(T^A)^T).
\]

The complete physical constraint at the origin is
\(G_0^A+Q_{\rm ref}^A=0\); the other sites retain \(G_x^A=0\). The reference
Hamiltonian is zero and the common clock is
\(e^{-itH}\otimes I_{\rm ref}\). Thus all reference Fock states are retained,
and \([H\otimes I,G_0+Q_{\rm ref}]=0\) follows from the exact full-source
Ward identity. The reference represents a declared static compensating
charge. It is part of the physical preparation and detector domain.

Let \(\Omega\) be the empty source/reference CAR state with every scalar and
link blank. For each block \(r\), prepare

\[
|\Phi_r\rangle=\frac1{\sqrt{2d_r}}\sum_{a\in r}
\left(c_{0,\uparrow,a}^\dagger r_{\downarrow,a}^\dagger
-c_{0,\downarrow,a}^\dagger r_{\uparrow,a}^\dagger\right)\Omega.
\]

This vector has norm one, even total fermion parity, zero total spin, and
zero complete local Gauss charge. The actual current matrices check every
one of these statements. Reversing the reference current orientation gives
the nonzero hypercharge residual norm squared \((6Y)^2/9\), so the reference
sign is tested explicitly.

The preparation pulse is generated by
\(K_r=|\Phi_r\rangle\langle\Omega|+|\Omega\rangle\langle\Phi_r|\)
on the origin CAR/reference pair sector. It is zero on the orthogonal
complement, and it acts as the identity there after exponentiation. Scalar,
link and other source memories are spectators. Its vectors are gauge and
spin singlets of even parity, so its complete operator commutes with the
corresponding constraints. On the two-dimensional orbit,
\(K_r\Omega=\Phi_r\) and \(K_r\Phi_r=\Omega\), hence
\(e^{-i\pi K_r/2}\Omega=-i\Phi_r\).

In the matrix ordering, reference modes follow every source mode. An odd
intervening source spectator therefore gives a minus sign to this local
even pair operation. The executor includes that parity factor and checks
it directly against the full CAR creation word. This is the graded local
extension of the pulse to every occupation; it does not restrict spectators
to the vacuum.

## Dressed arrivals and detector locality

The destination is \((1,0,0)\), cell 4. At side two, the two distinct stored
edges joining cells 0 and 4 have indices 0 and 12. Apply each complete actual
kinetic summand, including its adjoint, to \(\Phi_r\). Its output norm squared
is \(1/16\). Dividing by its coefficient magnitude \(1/4\) gives two
orthonormal states \(\chi_{r,0}\) and \(\chi_{r,12}\).

Each state has one native-\(r\) matter occupation at the destination, one
excited joining link, and the static dual reference at the origin. The link
is in the dual-\(r\) sector on edge 0 and the forward-\(r\) sector on edge
12. Every other source memory is blank. All endpoint Gauss identities are
checked on these complete correlated vectors. The internal reference label,
transported matter label and link indices remain entangled.

The exclusive detector and its complete complement are

\[
P_r=|\chi_{r,0}\rangle\langle\chi_{r,0}|
    +|\chi_{r,12}\rangle\langle\chi_{r,12}|,\qquad I-P_r.
\]

This detector has support on the complete source and reference. A local
detector \(F_r\) instead checks only the destination and its six incident
stored links. It requires exactly one matter occupation in block \(r\), a
blank local scalar, and exactly one excited incident link. That link must
be edge 0 in the dual-\(r\) sector or edge 12 in the forward-\(r\) sector.
Every other source memory and every reference state is unrestricted.

The selectors defining \(F_r\) commute with every actual gauge generator:
native-block number is invariant, the scalar vacuum is invariant, and each
link representation sector is invariant at both endpoints. The executor
checks the corresponding matrix commutators. Thus both \((P_r,I-P_r)\) and
\((F_r,I-F_r)\) are complete physical readouts, with \(P_r\leq F_r\).
Their outcomes can be copied into a neutral two-state pointer by
\(P\otimes X+(I-P)\otimes I\), a unitary because \(P^2=P=P^\dagger\).
Both pointer records are retained.

The full first image under \(H\), including all three Yukawa channels and
every native hopping block, obeys

\[
P_r\Phi_r=F_r\Phi_r=0,\qquad
P_rH\Phi_r=F_rH\Phi_r,\qquad
\|P_rH\Phi_r\|^2=\frac18.
\]

The complete first images contain between 456 and 3096 basis terms.
The preparation and first image satisfy all 96 site/current Gauss constraints
for each of the five blocks. No one-particle sector replaces the Hamiltonian.
For the preparation-off input, the same local detector obeys
\(F_r\Omega=F_rH\Omega=0\). This input uses the identical source, reference,
clock and detector, with only the preparation pulse omitted.

## Full-source remainder and unconditional records

For each of the thirty possible source spin/internal components, the code
applies the complete \(H\) twice. Fixed reference labels are orthogonal and
\(H\) acts identically on them. The norm of the physical second image is
therefore the average of their squared source norms. The code streams all
thirty components without discarding any source state or reference sector.
Equality of internal/spin norms is checked after their actual computation.

| \(6Y\) | \(\|H^2\Phi_r\|^2\) |
|---|---|
| \(-4\) | \(17893585/128\) |
| 1 | \(17894609/128\) |
| 6 | \(17896657/128\) |
| \(-3\) | \(18057745/128\) |
| 2 | \(17895633/128\) |

The vacuum control has \(\|H^2\Omega\|^2=141832\), with 33,841 actual second
image terms. All six squared norms are less than \(377^2\). Choose the one
common source time

\[
t_*=\frac1{4\cdot377}=\frac1{1508}.
\]

For every prepared or preparation-off state \(\psi\), the full finite
self-adjoint Hamiltonian gives

\[
\|e^{-it_*H}\psi-\psi+it_*H\psi\|
\leq\frac{t_*^2}{2}\|H^2\psi\|\leq\frac{t_*}{8}.
\]

Using \(1/3<1/\sqrt8<1/2\), the exclusive prepared probabilities satisfy

\[
\Pr_{\Phi_r}(P_r)\in
\left[\frac{25t_*^2}{576},\frac{25t_*^2}{64}\right],\qquad
\Pr_{\Phi_r}(I-P_r)\in
\left[1-\frac{25t_*^2}{64},1-\frac{25t_*^2}{576}\right].
\]

For the complete local readout,

\[
\begin{aligned}
\Pr_{\Phi_r}(F_r)&\in[25t_*^2/576,1],&
\Pr_{\Phi_r}(I-F_r)&\in[0,1-25t_*^2/576],\\
\Pr_\Omega(F_r)&\in[0,t_*^2/64],&
\Pr_\Omega(I-F_r)&\in[1-t_*^2/64,1].
\end{aligned}
\]

Consequently the difference between preparation-on and preparation-off local
arrival probabilities has the strict bound

\[
\Pr_{\Phi_r}(F_r)-\Pr_\Omega(F_r)\geq\frac{t_*^2}{36}>0
\]

for every native block, with the same source couplings and observation time.
All constants and intervals are exact rational numbers in the receipt.
The reference is retained throughout, with probability one. No outcome is
conditioned on an unreported success event.

## Scope and reproduction

This result concerns finite transport of a compensated gauge excitation
connected to a static reference by quantum flux. The input and the vacuum
control are declared prepared states; neither is asserted to be a stationary
interacting ground. String-supported arrival is not a free charged-particle
dispersion relation. No measured particle identification, mass, extra family,
relativistic continuum or confinement/Coulomb phase follows from these
probability records.

The executable checks the current dictionary, all reference/preparation
identities, complete detector outcomes and thirty full second-power source
calculations. Missing declared or transitive source inputs fail explicitly.
The receipt pins actual source code and proofs; it consumes no numerical
ground or spectrum receipt from another architecture.
