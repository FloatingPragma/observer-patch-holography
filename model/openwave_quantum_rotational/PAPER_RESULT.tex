\[

\]

$d_r=\sum_a(B_0)_{ra}c_a$ gives

Consequently $H\ge mN_{\rm ferm}+d\Gamma(N_m)+N_f$ on every retained
fermion sector. This is a linear quantum Hamiltonian with arbitrary
external references; no state-dependent field substitution is used.

Complete shells make the spatial differential and Maxwell mode actions

\[
 \|B\|\le\frac85+\frac35\sqrt C=a_C,\qquad
 0\le K-mI\le\frac{a_C^2}{2m}I,
\]
the two lowest levels of each reduced block are isolated below the number
