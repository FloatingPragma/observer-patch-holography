# Rooted source refinement

The sphere's midpoint rule defines a consistent corner neighborhood at
every finite radius. A local evaluator reproduces the source geometry and
certifies finite port-routing decisions without allocating the surrounding
sphere. These windows carry exact occupation-state restrictions and bounds
for complete local repair records. An infinite routed limit additionally
requires a specified arithmetic continuation. See the [proof](PROOF.md)
and [replay](packet.py).
