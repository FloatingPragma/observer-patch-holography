# Angular momentum and magnetic torque

A localized finite matter wave and its transverse magnetic field exchange
angular momentum while their total is conserved. Complete oscillator shells
supply actual spatial rotations, and the native spin matrices supply the
spin contribution. The field is driven by the derivative of the same matter
energy. This is an explicit rotational regulator and Maxwell mode
construction; its physical electron identification and electrostatic
completion are separate questions.

See [the derivation](PROOF.md) and [the executable receipt](results.json).
Run `python3 -m model.openwave_angular_torque --check`.
