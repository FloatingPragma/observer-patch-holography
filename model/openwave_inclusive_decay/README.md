# Inclusive weak-current decay

The native charged current gives a complete three-body emission calculation,
including its spin sums and phase-space coefficient. A declared contact model
has an exponential survival comparison accurate to about five parts in one
hundred thousand at one lifetime, with a proved finite-carrier error. The
calculated GeV width uses an electron mass anchor and a supplied contact
strength; it is not a measured weak-lifetime fit. See [the proof](PROOF.md)
and [the reproducible records](results.json).

Run `python -m model.openwave_inclusive_decay --check` from the repository root.
