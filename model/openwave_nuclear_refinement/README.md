# Nuclear levels and graph dependence

Exact native colour and angular representations reduce the low nuclear
spectrum to small cluster spaces, with rigorous bounds for every omitted
colour excitation. Paths and cycles of two to four cells retain one mass
calibration. They support binding and expose an additional bound spin-zero
channel, so the observed nuclear spectrum is not reproduced.

See [the proof](PROOF.md) and [complete spectra and record bounds](results.json).
Run `python -m model.openwave_nuclear_refinement --write` or `--check`.
