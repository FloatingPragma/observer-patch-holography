# Nuclear attraction from a dynamical field

A full neutral oscillator coupled to four-site native occupation records
generates a signed attractive interaction with a volume-extensive stability
bound. The inherited electron, strong and triton parameters are unchanged.
Complete GeV enclosures exclude the helion and alpha targets at the declared
coupling. A separate exact representation trace gives preparation work for
the entire original nuclear input. See [the proof](PROOF.md) and
[the complete bounds](results.json).

Run `python -m model.openwave_nuclear_field_attraction --write`, followed
by `python -m model.openwave_nuclear_field_attraction --check`.
