# Certified coupling response on the full gauge source

Seven declared couplings have certified full-Haar gaps, connected Wilson
responses and gap derivatives. The derivative calculation reduces the
unbounded electric term to the energy and a bounded magnetic expectation.
The [proof](PROOF.md) distinguishes the resulting necessary constant-mass
tangent from a physical running coupling or continuum construction.

Run `python -m model.openwave_haar_coupling_flow --write`, then
`python -m model.openwave_haar_coupling_flow --check`.
