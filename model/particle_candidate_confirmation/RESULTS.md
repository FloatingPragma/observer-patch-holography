# Candidate identity tests

These tests distinguish source excitations and constrain their physical
interpretations. No named particle or GeV mass is certified by this table.

The source calculations give:

- A complete 9-record compensated bare/dressed interference experiment, with positive original contrast `2*sqrt(2)/3 * c`. The transition frequency is unresolved and can include elastic response.
- A separate complete dressed menu has original reported weight greater than `1/40` in the source pair-transfer interval `[77/8, 271/8]`. The compensating endpoint and flux are retained; this is not a single-particle rest mass.
- A local coefficient commutant of dimension 5, with no extra onsite three-generation factor.
- A coherent 7-state increment counter for the six signed composite interventions plus failure, with an explicit multiple-excitation alias.
- Six interacting gauge multiplets: `A1g`, `A1u`, `Eg`, `Eu`, `T1g`, `T1u`. Their complete source menu retains the original rare-sector probability.

The neutral composite families have a separate [conserved-charge identity test](../particle_candidate_composites/PROOF.md). They are not inserted into the elementary-particle target rows.

A physical confirmation needs the same source current and spin dictionary, a populated propagating sector with controlled dispersion, and matching interaction records. Generation names require a source flavor discriminator. A unit conversion supplies none of these tests.
