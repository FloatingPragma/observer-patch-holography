# A dressed charge has a measurable profile

The same compact Maxwell and Pauli source gives a charge-position radius and
a frequency-dependent native current response. Exact padded residuals bound
the infinite-source ground profile and four response values. The regulated
electron radius is about0.12118 cell, so its resolved spatial coupling changes
by at most2.94% across the first Brillouin interval. This is a subcell core,
without a resolved order-one onset or a physical electron-radius fit.

The complete probe retains its compensating charge, spin, flux and failure
records, including the preparation and readout energy budget. See the
[proof](PROOF.md) and [replayable result](results.json).
