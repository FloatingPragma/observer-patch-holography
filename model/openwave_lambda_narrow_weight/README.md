# Native Lambda current near its rest energy

Rational proton and pion ground trials give a complete-source bound on the
native current's weight in a narrow Lambda-energy window. Every omitted
occupation and packet translation contributes to the residual certificate.
The calculation bounds a finite spectral window; it supplies no physical
decay rate or on-shell density. See [the proof](PROOF.md) and
[the reproducible bounds](results.json).

Run `python -m model.openwave_lambda_narrow_weight --write`, followed by
`python -m model.openwave_lambda_narrow_weight --check`.
