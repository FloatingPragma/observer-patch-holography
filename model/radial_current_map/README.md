# Conserved currents of the radial defect

The full radial fermion source has an exact eta-pairing SU(2). Its interacting
charged states form one doublet, while its ground pair consists of two singlets.
Every conserved sum of onsite even currents is classified, including quartic
terms. Center spin currents have a strictly positive leakage into the complete
excited space. The [proof](PROOF.md) and [receipt](results.json) distinguish this
source current from the declared Standard Model representation.

An identification with physical particle charges requires a source action and
current map beyond this finite local symmetry class.

Run `python -m model.radial_current_map --check` for an independent receipt replay.
