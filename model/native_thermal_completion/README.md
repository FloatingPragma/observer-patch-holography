# Reversible bath and finite cooling records

Adding the missing reverse edges to the native closed-cell state space
gives a declared thermal process with exact Gibbs stationarity. All
17,352 proposal, rejection and idle records are retained at each specified
temperature. Cooling and reheating experiments calculate class populations,
heat, entropy production and departure from equilibrium, with an explicit
probability-roundoff budget.

The bath changes the repair law. Its temperature and heat use the declared
cost units; physical particle abundances and a cosmic clock require separate
attachments. See [the proof](PROOF.md) and [complete receipt](results.json).
