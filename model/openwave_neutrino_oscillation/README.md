# Neutrino mixing from native family geometry

A declared neutral mass tensor built from the native family matrix and one
coherent port pulse gives three masses and a mixing matrix derived from the
actual weak current. Complete oscillation records retain preparation and
return failures, with an explicit bound on the usual unitary approximation.
No measured neutrino angles or mass splittings enter. Connecting this
construction to observed neutrinos requires an absolute scale and a successful
comparison. See the [proof](PROOF.md) and [records](results.json).

Run `python3 -m model.openwave_neutrino_oscillation --check`.
