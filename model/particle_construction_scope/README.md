# Finite particle constructions and their scope

Exact source operations can support useful particle comparisons without
identifying an observed particle. This package reproduces a two-seam
CP-violating candidate that fails its full comparison, distinguishes two
declared lepton-clock dressings, and checks the additional analyzer and
preparation required by a one-tick family construction. A finite scalar
countercontrol separates fixed-cap obstructions from controlled growing
registers. None supplies a Standard Model mass in GeV.

[Proof and domains](PROOF.md), [replay receipt](results.json), and
[retained source inventory](retained.json) keep exact identities,
numerical comparisons and architecture inputs separate.

```sh
.venv/bin/python -m model.particle_construction_scope.replay --write
.venv/bin/python -m model.particle_construction_scope.replay --check
.venv/bin/python -m pytest -q -Werror model/particle_construction_scope
```

The package runs from the public checkout. Original producers and
receipts are stored byte-for-byte with `.raw` extensions. Temporary
executables adapt only enumerated repository-path constants. Two
undefined CP phases in an original receipt remain undefined and are
represented explicitly in the strict current JSON. The retained
empirical references are historical inputs, not a latest-data claim.
The receipt records its numerical dependency versions. A different
numerical environment may produce different diagnostic residuals;
the strict replay reports those differences instead of applying a
blanket tolerance or changing an original result.
