`[V,N_H]Omega=-W Omega` has squared norm G=56, and the empty input acquires

obstruction. The actual ordered-cover and protected six-object proper

rotation identity. The existing
[independent Spin/matter construction](../observer_particles/spin_matter_join.py)

creation/exchange signs on all occupations. The neutral scalar vertex

neither odd matter fields nor an identification of a Z2 curvature endpoint
