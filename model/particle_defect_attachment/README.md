# Protected defects can change an interacting detector response

A specified controller couples a protected source charge to the complete
finite quantum-scalar interaction. The same clock and detector then read
different oscillations in its two sectors. The construction works both for
the actual ordered-memory charge and for regional curvature parity in the
declared link/work program. It retains the original repair and creation
records. This is a finite defect-to-observation map, with an explicit
coupling choice; it does not identify a relativistic particle.

The [proof](PROOF.md) gives the intertwiners, complete probabilities and
preparation-work accounting. The [executable](attachment.py) tests the
literal source branches and full retained scalar sector. The
[source catalogue](../protected_defect_catalog/CATALOG.md) distinguishes the
other protected objects and their existing field attachments.

python -m model.particle_defect_attachment
python -m pytest -q model/particle_defect_attachment/test_attachment.py
