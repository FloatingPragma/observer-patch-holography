# Bound mesons and three-quark states

A declared positive interaction built from the native colour and spin currents
binds colour-singlet quark pairs and triples. Exact symmetry reduces the
sixty-mode fermion problem to matrices of size64 and120, with the full
complement controlled by positivity. The [proof](PROOF.md) and
[complete records](results.json) give binding thresholds and preparation
failures. Physical hadron masses and relativistic identification require
additional matching; the light proton-like and neutron-like states are
exactly degenerate.

Run `python3 -m model.openwave_native_composites --check` and
`python3 -m pytest -q model/openwave_native_composites` from the repository root.
