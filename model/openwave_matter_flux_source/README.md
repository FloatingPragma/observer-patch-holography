# Full matter and an integer-flux cycle

The complete192-CAR source and all114 native terms couple to two compact U(1)
links with an independent unrestricted integer cycle. Exact Gauss
dressing, positive spatial hopping and bounded Wilson coupling give a
self-adjoint stable common Hamiltonian. All matter and flux sectors remain.

Exact rational full-tail bounds give a common positive charged-lepton
gap shift under this declared extension. Neutral one-lepton gaps keep
their inherited values after vacuum subtraction. The GeV conversion uses
the supplied electron anchor; these shifts are not physical mass fits.
A separate optional member subtracts the exact computed common shift times
charged occupation. Its global vacuum and all inherited one-lepton sector
rest values are preserved by the exact positivity theorem. This is a
declared normalization choice; its currents and work require its own
generator, and no physical mass prediction is added.
The package identifies the source-level assumption that must be justified
before transferring native rest values into a spatial field model.

Run `python -m model.openwave_matter_flux_source --write`, then
`python -m model.openwave_matter_flux_source --check`.
