# Frozen finite test

1. Enumerate all 66 site pairs, both transported tags and all four spin
   assignments on every actual native seam. Compare the direct CAR action
   with the old Gauss action through the tag-ordered creation map, for q in
   {-1,0,1}, local electric values {-1,0,1}, and both coherent selector bits.
   Memory translations are checked at every one of the six values on the
   nonadjacent crossing seam; the symbolic translation identity covers all
   seams. Untouched links tensor identity. Require exact equality, exact
   Gauss conservation, spin transport, involution and column injectivity.
2. Execute all C/E coins on the same source. Retain all 64 coin/raw/overflow
   labels and an explicit admission-failure identity. Require exact effect
   sum I and partial-injection branches. Include zero slots and overflow.
3. Lift the existing finite-window three-seam coherent loop with all four
   spin inputs. Retain source, tag, spin, links, memory and every reference
   outcome in two sequential reference comparisons. Require agreement with
   its existing pointer probabilities, unchanged spin, and recorded work.
4. On a closed finite source slice with one compensator at port1 and the
   other load on triangle(0,5,11), use electric window [-1,1] on its three
   links, the same native event, and all memory values. Build all admitted
   current operators. Compare the current contraction's square with a
   separately enumerated two-step oriented-path reader; require maximum
   numerical error <1e-10. Keep all source columns, hold and overflow. Run
   q=0 and q=1. Report scalar-transfer versus spin-current scope explicitly.
5. Each listed changed-law control must have at least one exact failing
   column. Write complete counts, source pins and hashes. Never promote a
   missing physical clause to pass. The design and this task are hashed
   before any new evidence run.
