# Reproduction

From this directory run:

```
python3 headline.py --check RECEIPT.json
```

The script verifies all14 source bindings and the four preregistered leaves,
then reexecutes960 literal native columns and480 HOLD-control calls. Its
exact rational receipt must reproduce byte for byte. Only elapsed time is
printed outside the receipt. No third-party numerical package is needed.

The complete products of the primitive coin/address/current records are
represented by disclosed product cylinders and deterministic counter maps.
The receipt names every primitive row and exact probability. The run does
not claim fresh endpoint calls for each product word. The original first
run and the full producer replay are retained in RUN.log and REPLAY.log.

Logarithms are enclosed by100 exact positive-series terms plus an explicit
tail. Decimal strings are diagnostics; no rounded spectrum is used as a gate.
No new Lean build, M6 pulse, coherent family analyzer or mass experiment is
executed.
