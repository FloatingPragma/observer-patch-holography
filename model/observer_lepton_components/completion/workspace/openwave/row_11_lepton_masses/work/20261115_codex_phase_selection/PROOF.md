# What the native count and a calibrated endpoint clock determine

Platform row 11 remains untested. The result is conditional mathematics on
the declared coherent family apparatus. It preserves the actual native
count and the constructive native exchange clock. It does not identify a
physical charged lepton or select a mass by comparison with experiment.

## 1. Four source facts with different domains

The complete retained-count proof defines a projector

    Q = B† Pi_xor B,       p = <s|Q|s> = 2/9.

Its value comes from all 3600 addressed pairs of two independently prepared
native count cells. Their single-flag weights are 1/12 and 1/6, with joint
weight 1/72. Coherent address reflection, prepared doubles, inverse services
and the two independent registers are disclosed inputs of that apparatus.

The existing oriented family-record operator has spectrum {-1,0,1} and is

    J = (V_minus - V_plus)/2.

This fixes which flag is counted with which sign. It does not yet specify
a duration or strength for a continuous interaction with that flag.

The lepton source explicitly defines

    T(eta) = exp(i eta J tensor Z_F Z_I).

Its exact toggle calculation gives a count kick with angle h=2 eta.
The identity holds for every eta. The weak round sets h=1/N; this is the
source's chosen integrated interaction relative to its declared clock.
The count identity alone gives no equation fixing eta.

The clock section separately defines

    H = sum_x(I-Re U_x) + sum_edges(pi/4) dGamma(I-S_xy).

The edge gate equals its evolution at times tau in 1+4Z, and choosing its
principal branch fixes tau=1. Its onsite consensus compression is I-K12,
the rate-one attempt generator. Those are valid statements on that declared
clock. The clock-edge test and onsite count test contain no toggle eta.
Consequently replacing the separate toggle by T(eta') leaves both of these
calibration equations exactly unchanged. It changes the subsequent family
phase experiment. This is a concrete separation of source equations, not
an objection to an emergent time or to use of a clock unit.

In the retained-count notation beta=kappa T, the accumulated family phase
is theta=p beta. A consistent time-unit change T->cT, kappa->kappa/c leaves
beta unchanged. Thus choosing beta=1 is a dimensionless interaction choice;
it is not obtained by merely naming a time unit.

## 2. Even an endpoint phase does not fix fractional weak kicks

Consider the source's integer-spectrum J and a complete endpoint calibration
of U_beta=exp(i beta J), including arbitrary reference systems. For every
integer n,

    U_(beta+2pi n) = U_beta.                                  (1)

Equality holds as operators on the entire J space. The same is true of the
strong count-controlled endpoint exp(i beta J tensor Q), because Q is a
projector and the spectrum of JQ is contained in {-1,0,1}. Every instrument
built only from those endpoints and common intervening operations therefore
has identical full outputs. This claim includes coherent endpoint reads;
it is stronger than equality of their committed record probabilities.

Now specify a continuous fractional implementation

    U_n(t)=exp(i (beta+2pi n)t J),       t in R.

Each is continuous, obeys U_n(t+s)=U_n(t)U_n(s), and agrees at every integer
time. Strong continuity, group composition, and the endpoint gate thus do
not by themselves select n. Intermediate-time records or a bound choosing
a logarithm branch would distinguish them.

In particular, implement the existing fresh-count protocol at N subdivisions:

    G_(N,n) = product_l exp(i (beta+2pi n) J Q_l/N),
    chi_(N,n)(q) = [1-p+p exp(i q(beta+2pi n)/N)]^N.             (2)

All count words remain. Equation (2) is their exact reduced coherence, not
a successful-path normalization. For a fixed finite n its limit is

    chi_(N,n)(q) -> exp(i q p(beta+2pi n)).                     (3)

The existing centered Taylor theorem supplies, for each fixed branch,

    ||A_(N,n)-A(p(beta+2pi n))||
      <= [(2+sqrt(2))/27] (beta+2pi n)^2 p(1-p)/N.             (4)

This is not uniform over unbounded n. The phase branch is part of the
fractional source implementation, and must be fixed before taking its limit.

For p=2/9, branches n modulo 9 give nine distinct labelled phases modulo
2pi, since 2n/9 is integral exactly when n is a multiple of 9. The family
R^3=I allows phase shifts by 2pi/3 to permute characters, and theta->-theta
also preserves the unordered spectrum. Therefore the nine phases need not
produce nine different unordered mass candidates. The next exact witness
shows that they do not all collapse to one spectrum.

Write

    M(theta)=aI+b(exp(i theta)R+exp(-i theta)R†),
    a=1/(3sqrt(3)), b=1/(3sqrt(6)), A(theta)=M(theta)^2.

Using Tr R=Tr R^2=0 and R^3=I, expansion gives

    Tr A(theta)=2/9,
    Tr A(theta)^2=17/486+(2sqrt(2)/243) cos(3theta).            (5)

For example beta=0 and beta'=2pi have exactly the same endpoint in (1),
namely identity. Their fresh-count limits have theta=0 and theta'=4pi/9.
Their fourth compression moments differ by

    Tr A(0)^2 - Tr A(4pi/9)^2 = sqrt(2)/81 > 0.               (6)

Both effects have equal trace. Equation (6) therefore proves an unordered
spectral difference which cannot be removed by a common positive scale or
by relabeling the three families. It uses no empirical spectrum. In this
example theta=0 also gives a degeneracy; the example is an identifiability
witness, not a three-lepton candidate.

The earlier closed-clock proof already distinguished a repeated unreset
count from fresh counts at beta=2pi. Here both compared implementations
use the same fresh-count architecture and differ only in their continuous
fractional extension of an identical calibrated endpoint. This is the new
calibration obligation. The differing fractional implementations are distinct
source programs and would be distinct candidate choices; their endpoint
agreement does not make them the same pinned process.

## 3. What the actual native exchange clock supplies

The current-fed native_internal_clock protocol completes an odd exchange
path with memory action X. It gives a measured period-two return signal,
including every retry and timeout. Its closed action can be written

    X = exp(-i pi P_minus),       P_minus=(I-X)/2.

This supplies an endpoint phase pi. It does not supply the family operator
J, its count coupling, or fractional gates exp(i JQ/N). There is no asserted
intertwiner between the exchange memory and the family phase apparatus.
Even after such an intertwiner, the endpoint logarithm retains multiples
of 2pi until the fractional path is specified.

There is a closely related algebraic check inside the family flag source.
Choose the positive pi logarithm L(V)=pi(I-V)/2 of each reflection V. Then

    L(V_plus)-L(V_minus)=pi J.                                (7)

This identity follows directly from the source definition of J. It gives
pi J for that particular logarithm convention. Dividing the generator by
pi to obtain J is an additional normalization of the interaction relative
to the clock. Equation (7) does not force beta=1. At an eigenvalue -1 the
opposite signed logarithm is also possible; a chosen fractional path or
branch convention is required in either reading.

None of these observations prohibits a source law from fixing the coupling
and branch. It identifies what that law must add to the existing endpoint
and count results.

## 4. A target-free phase measurement with all outcomes

There is a constructive calibration experiment on the same retained-count
dilation. It requires an admitted preparation of (|J=0>+|J=1>)/sqrt(2),
the prepared count state |s>, one actual G_h=exp(i h JQ), and complete X/Y
reads of the two-dimensional probe. These coherent preparation/read services
are explicit apparatus requirements; no new source word is executed here.

Let the two probe outcomes be +1 and -1. Tracing, or fully reading and then
summing, every count output gives

    chi(h)=1-p+p exp(i h),
    E[X]=Re chi(h),       E[Y]=Im chi(h).                      (8)

More finely, in the Q=q subspace with w_0=1-p and w_1=p, the joint outcome
weights are

    Pr(q,X=+/-)=w_q [1 +/- cos(hq)]/2,
    Pr(q,Y=+/-)=w_q [1 +/- sin(hq)]/2.                         (9)

Here the Q read means applying B and then the existing complete native
record read that resolves Pi_xor, or implementing its explicitly admitted
conjugated instrument. An arbitrary raw-coordinate read on the uncomputed
Q=B†Pi_xor B register need not resolve Q. Equation (8) needs only the full
count trace and is independent of this optional choice of count read.
The outcomes of (9) sum to one in either probe setting. Every finer original
count outcome of the specified conjugated instrument is retained; (9) only
groups those outcomes for this observable.
No count=1 conditioning, heralded-state normalization, or discarded failure
is used in (8).

Since p=2/9 is nonzero, both quadratures determine

    exp(i h)=[E[X]-(1-p)+i E[Y]]/p.                           (10)

This measures the implemented phase modulo 2pi using no lepton mass.
For the phase pi plant, the unconditional X-plus probability is 7/9,
whereas the phase-zero control gives 1. With the AND count p=1/72 in the
same formula, the phase-pi X-plus probability is 71/72. These are exact
analytical control predictions. They are not new execution results.

To identify beta from a weak gate h=beta/N, an a priori interval of width
strictly below 2pi N and an unambiguous placement of the measured phase in
that interval suffices. Without a branch/range premise the read determines
beta only modulo 2pi N. Reading several subdivision counts N_1,...,N_k
leaves beta modulo 2pi lcm(N_1,...,N_k). Indeed equality at every selected
subdivision requires beta-beta' in the intersection of the lattices
2pi N_j Z, which is 2pi lcm(N_j) Z. Arbitrarily fine exact subdivisions
would remove the ambiguity for fixed finite beta; a finite experimental
packet instead needs a finite justified range and error budget.

The existing calibrated_phase_inference interfaces implement interval
inversion only under a declared residual phase window and source-mean
contract. Their prior is explicit. They could serve a later finite-error
implementation of (10), but their mere presence does not authenticate this
source experiment or select a preferred beta.

An independent record feedback rule could tune the coupling until (10)
equals exp(i). That would operationally realize beta=1 within a stated
branch. The target exp(i), tuning rule and source hardware would then be
inputs of that new law. Measuring an enacted coupling and deriving why
that coupling is selected are separate obligations.

## 5. The coincidence count r is another operational choice

Let F be the actual selected family CP map, with mutually commuting Kraus
maps from the retained-count dilation, and A=F†(I). The existing theorem
shows that r fresh selected flags have effect A^r, while first failure at
stage j has effect A^(j-1)(I-A). Their sum is I.

On a family character with A eigenvalue alpha in (0,1), all probabilities
are therefore original probabilities:

    Pr(first failure j)=(1-alpha)alpha^(j-1),
    Pr(all r selected)=alpha^r.                              (11)

The r=1 and r=2 continuations agree on their entire first trial. They differ
on whether a fresh second trial is performed and on its retained records.
For a character with 0<alpha<1 their selected weights differ by
alpha-alpha^2>0. Thus the complete protocol observes r; it is not a hidden
choice of mass units. A calibration that observes only the primitive
single trial supplies no condition choosing which continuation is enacted.

The native count preparation uses two independent cells to obtain p=2/9.
That number of cells is not r. N counts how many prepared count pairs are
used to approximate the phase; r counts how many complete family flags
must coincide; a collision count M in the energy theorem counts another
operation. Substituting one of these counts for another changes the program.

Under the explicitly conditional common spatial first-hit law, the rest
response is

    m_f=sqrt(2 kappa epsilon) alpha_f^(r/2).                  (12)

For positive distinct alpha_f, both r=1 and r=2 preserve the number and
ordering of the three internal levels and the single spatial minimum per
family in that source. Their ratios are respectively
sqrt(alpha_g/alpha_f) and alpha_g/alpha_f. A common energy or length unit
cancels from each ratio and cannot equate them. Merely asking for three
family minima therefore does not select r=2. In the count limit A=M^2,
r=2 gives the mass-style M^2 ratios, while r=1 gives |M| ratios. This is a
property of two explicitly different detector continuations.

A simple operation-count objective also does not silently supply r=2.
For the classical sequential flag instrument stopped at first failure,
let each trial cost the same positive C. On a fixed alpha eigenstate,
expected cost is C(1-alpha^r)/(1-alpha), so successes per expected cost are

    alpha^r(1-alpha)/[C(1-alpha^r)].                          (13)

They strictly decrease with r, because x/(1-x) increases with x and alpha^r
strictly decreases. Hence this particular objective chooses r=1. Equation
(13) concerns that counted sequential instrument and declared constant
cost; it is no theorem about physical work or the cost of the coherent
all-r weak-filter compilation. An observer requirement for two confirmations
could choose r=2, but that requirement must itself be stated and realized.

## 6. The concrete remaining source selection problem

A sufficient next construction would supply, on one candidate:

1. the actual count-coupled source operation and a full-record phase read;
2. a branch/range specification or enacted fractional path, with errors and
   all failed source operations retained;
3. a source rule fixing its integrated action beta relative to the common
   spatial/energy clock, without a lepton mass used as a target;
4. an actual observer task selecting the coincidence continuation r, with
   its complete record and resource law;
5. physical charged-species and rest-energy identification on that same
   source, retaining every other accessible branch.

The existing native count, phase-sensitive read services, internal exchange
clock and conditional spatial theorem make these well-defined tasks. The
reviewed equations do not yet supply items 3 and 4. No universal exclusion
of other observer tasks, other memory laws or OPH follows.

This audit adds no full Lorentzian continuum or spin derivation as a new
prerequisite for the platform's static row. A justified finite-cutoff mass
interpretation is allowed. The variables called charge, species and rest
energy still need the operational meaning used by the asserted criterion.
