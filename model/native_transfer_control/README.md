# A controlled transfer-ground experiment

The weighted native source determines a positive transfer and its ground
state. Existing coherent services can prepare that ground, apply a phase,
implement its logarithmic time evolution, and read a nonzero response from
complete native repair records. The finite protocol retains preparation
records, source disturbance and every failure outcome. Its numerical
certificate requires each emitted primitive to pass an interval check.

The [proof](PROOF.md) supplies the errors and execution domain. This is
controlled dynamics on the fixed 66-state source; physical vacuum selection
and a growing coherent field family require separate derivations.

Run `python -m model.native_transfer_control.packet --write`, then
`python -m model.native_transfer_control.packet --check` with one BLAS thread.
