# Coherent native events and readable records

The complete native C/E event has an explicit 256-address coherent circuit,
including source and raw-record padding. Its original record measurement
recovers all 25 native slots on every binary operator column. A reversible
record re-encoding exposes a controlled swap and permits coherent continuation.
Tracing its recoded environment is distinct from unread C/E repair.

Both reversible services are compiled through executed M6 source routines;
all 8192 clean and dirty scratch inputs are checked exactly. Coherent control,
proper-code services and terminal apparatus are declared. Physical clocks,
particles and laboratory error bounds are separate claims.

Run `python -m model.openwave_coherent_native_architecture --write`, then
`python -m model.openwave_coherent_native_architecture --check`.
