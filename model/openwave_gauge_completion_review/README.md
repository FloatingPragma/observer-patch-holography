# Independent compact-gauge record checks

The review rebuilds the complete native preparation instrument and its
unprojected-pump countercontrol, derives the SU(3) class-state moments from
Schur constraints, and compares the charged rotor spectrum and dynamics
with an independently assembled larger carrier. The [receipt](results.json)
binds the reviewed sources and their finite interpretation boundaries.
It also reconstructs the final electric energy from all thirty displayed
position/flux tables, checks the preparation and absorption work with the
failure branch retained, and verifies the recorded detector charge in
Gauss law. The bare-flux input is distinguished from the true field vacuum.

Run `python -m model.openwave_gauge_completion_review --check`.
