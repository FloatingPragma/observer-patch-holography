# Localized quark-string records

A native fractional charge can be recorded at the end of a gauge-invariant
open string. The full quantum reference and link field make its coherence
measurable even though every undressed charged one-point mean is zero.
Exact calculations give the charge/flux profile, its time-dependent pointer
records and measurement work on several carrier sizes. This is a controlled
string preparation; a stable physical quark and its rest mass require an
interacting particle identification.

See [the proof](PROOF.md) and [complete receipt](results.json).

Run `python -m model.openwave_localized_quark_record --write`, then
`python -m model.openwave_localized_quark_record --check`.
