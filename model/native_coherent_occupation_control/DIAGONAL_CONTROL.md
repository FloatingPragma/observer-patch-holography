# Number-preserving source phases and finite logical operations

These are two further directions in the existing native response image, exposed
by explicit versioned coherent-control declarations. They retain the same M1
occupation-wire load/export premise and resource accounting as the B service.
They do not amend the frozen six-kind source-word grammar. The conditional
phase uses exactly the existing literal J actuator request on this dyadic
domain; its distinguishing feature is the structurally certified addressed native return.
The rail phase exposes a different exact combination of the existing ports.

Direct exact Q(sqrt(5)) computation of all 36 entries gives

    J = sum_(p=0)^11 D_p = i diag(1,1,1,0,0,0),
    Z = D_0+D_1+D_2+D_3
      = i diag((-4-sqrt(5))/3, (2-sqrt(5))/3,
               (5+2sqrt(5))/3, 0,0,0).

Equal literal dyadic integrated controls produce exp(theta J); equal controls
on the first four ports produce exp(theta Z). Both responses are exactly
diagonal on the entire six-level processor, including the complement. They
therefore preserve every addressed occupation bit and all spectator sectors.
No cancellation between separately rounded irrational control coefficients is
required. The source generator itself may contain sqrt(5), as its original
exact definition does.

On proper code |n_a,n_b>, the first direction is

    exp(theta J) = exp(i theta) exp(-i theta n_a n_b).

It is a conditional phase up to a common phase. Addressing one selected rail
from each of two logical dual-rail qubits in the same cell gives an entangling
logical operation while preserving the number in each rail pair. For two
logical |+> inputs its pure-amplitude determinant has magnitude
|sin(theta/2)|/2, nonzero at the admitted theta=1/2. The complete evaluator test
keeps this determinant above 0.12 for the actual stored response.

On a single dual rail, the Z response has relative phase

    theta [(5+2sqrt(5))/3 - (2-sqrt(5))/3] = theta(1+sqrt(5)).

Together with the B rotation, this gives two nonparallel logical rotation
axes. Continuous ideal controls generate SU(2). For finite binary64 payloads,
bounded-piece Euler rounding applies only to tolerances supported by the
admitted payload grid and the fixed numerical error budget. Each angle is
divided into bounded admitted pieces and rounded to an exactly representable
dyadic; every piece is a separately charged source pulse. This is not an
arbitrary-precision synthesis theorem: the finite payload domain has a minimum
positive angle, and any argument using long words of irrational rotations
would additionally need an explicit word-length and accumulated-error bound.
No universal compiler, exact pi payload, or unbounded free circuit is asserted. The present code executes declared
finite phase and B services and the two-qubit entangling example.

For numerical certification, the complete diagonal source phases are first
enclosed by directed 160-bit sqrt(5) arithmetic. Sine and cosine are evaluated
at each interval midpoint with an integer Taylor certificate, then widened by
the phase radius using their derivative bound one. The evaluator compares
all six complex diagonal entries to these enclosures, refuses any stored
off-diagonal entry, and applies the same e=10^-13 operator-error gate as the
B service. Consequently the same complete half-diamond and bounded-gain
estimates hold. Complement rows are retained as explicit outcomes and their

The addressed lift acts on exact rational real and imaginary operator parts;
it does not discard quantum phases to satisfy a real-only interface. The
native interpreter explicitly defines the complex-linear map using two real
calls, and both parts are passed through public native execution in tests.
All reference indices, fixed global occupation and spectator bits survive.

against ideal unitaries gives operator error at most (1+e)^L-1, hence complete
half-diamond error at most E(2+E)/2 with E=(1+e)^L-1. Any native instruments
interspersed afterward retain their complete failure/record channels.
