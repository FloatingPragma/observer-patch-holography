# Exact source control and a complete boundary Bell handoff

This package declares an explicitly versioned M1 coherent-control service.
It uses the existing twelve integrated port controls, six-level processor and
proper-four load/export law. It does not add a source response direction, and
it does not change the frozen `native_program.source_word` alphabet. That
alphabet rejects this opcode. Coherent occupation-wire loading is a
counted service premise, not a consequence of unread classical repair.

## Exact response identity

Write the retained exact six-level source generators as D_0,...,D_11.
Direct computation in Q(sqrt(5)) gives

    B = (D_6 + D_7 - D_4 - D_5)/2,
    B_12 = B_45 = 1, B_21 = B_54 = -1,

with every other entry zero. All 36 entries are checked from the authenticated
response and control-certificate files. Hence exp(theta B) rotates code
coordinates 1=01 and 2=10, and separately rotates complement coordinates 4,5.
The complete complement response matters: it is not replaced by an identity.
For a proper-four input, however, both complement export rows vanish exactly.

The declaration admits |theta| <= 1 only when theta and theta/2 are exactly
representable binary64 rationals. The four nonzero integrated controls are
therefore literal exact dyadics. A tiny angle whose half underflows is refused.
No symbolic pi, rounded irrational port coefficient, or target Hamiltonian
is inserted. The source unitary preserves two-wire occupation exactly.

## Stored response and addressed handoff

six-level exponential. It refuses any stored entry outside the exact source

For cell c and local addresses a,b, the coherent load is explicitly

    |n_(12c+a), n_(12c+b)> -> |2 n_(12c+a) + n_(12c+b)>.

The sparse implementation clears just those two mask bits, applies each
proper-code output row, and writes the resulting two bits back. All spectator

returned separately, including their exact zero operators for this code input.
The complete finite service declaration authenticates actual source geometry

## Complementary rotations and native E

Use an actual intercell seam (a,b) and one distinct internal spare in each cell.
Logical 0 has its spare occupied; logical 1 has its boundary endpoint occupied.
Start from the declared known basis state A0 B1. Two addressed services with
angles -theta and +theta give respectively

    c|0>+s|1>,       s|0>+c|1>,

where c=cos(theta), s=sin(theta). This initial-state interface is explicit;
preparation from arbitrary input native branches is not claimed here.
The actual E raw-zero Kraus operator for each fair coin is P_even/sqrt(2).
It preserves 00/11 coherence and removes odd parity. Both accepted coin
branches therefore have the same ideal Bell ray |00>+|11>, with total success

    p = 2 c^2 s^2 = sin^2(2 theta)/2.

For the admitted dyadic theta=25/32, directed arithmetic proves p>0.4999.
There is no requirement that theta equal pi/4. The two stored exponentials
can differ at the last bit, so their conditional Bell ray need not be exact;
this difference is covered by the complete map estimate, not silently erased.
For two pulses, let E=2e+e^2. The complete output instrument differs from the
ideal by at most E(2+E)/2 in half-diamond norm. The native E instrument is an
exact trace-preserving postprocessing and does not increase this error.
The stored unnormalized acceptance mass differs from p by at most twice that
bound. All four service complement exports and all 25 native raw slots are
retained; no success branch is renormalized for the comparison.

The final boundary operation runs through public `native.execute`, including
admission, fixed-q sparse validation, counted repair attempts, FIFO and terminal
status resources. It completes one native attempt and retains 25 branches,
FIFO occupancy one and a terminal status record. The result is also compared
exactly with the native kernel, and its complete output mass equals its actual
unnormalized input mass. The clocks remain two coherent source pulses plus one

## What this constructs

This is a finite, heralded logical Bell resource using an exact source-derived
number-preserving control and a literal native intercell repair. The original
rounded 22-pulse beam fails exact fixed-q handoff; its counterexample and
the frozen V2 rejection remain valid. The versioned service supplies an explicitly
versioned alternative with an audited structural return.

Neither local number-preserving services nor a native branch with definite
recorded intercell current creates coherence between distinct vectors of cell
totals from a cell-charge-block-diagonal input. This invariant survives adaptive
classical control, heralding and encoded Bell resources. Consequently this
construction does not prepare the crossing-charge-coherent growing P/Tr(P)
reference or the growing bare Dicke ground. It also does not supply spatial
Lorentz symmetry, physical energy calibration, or an autonomous field law.
