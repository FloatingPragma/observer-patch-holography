# Echo calibration of a terminal address detector

Use the two registered blank one-load stations and their original windows 0, 1/4, 1, 2 and 4. The original one-way response is known at design time. The echo protocol asks whether the complete one-way receiver distribution can be recovered from successful out-and-back counts without reading the intermediate arrivals into the estimator. Each launch begins at one of the two registered release ports. After one passive leg, measure the occupied port in the receiving cell (or quiet). After another leg of the same duration, test for return to the exact released port. Keep the intermediate address and the return flag. If the intermediate read was quiet the protocol ends. Sample 2^22 starts per release and association. Use fresh independent starts for one-way challenge reads. Run native flight and halved exchange during both legs, preserving the released sharp states and geometry.

Use only the twelve address-labelled echo coincidence rates to predict the one-way address probabilities by taking square roots. Use normalization for quiet. Report simultaneous 99% binomial confidence bounds across every calibration and challenge probability in both laws, then compare their intervals. Use the calibration counts alone to select the binary decision table and score its held challenge decisions. Report separately a coarse local occupancy check that preserves which-port coherence before the return, and an address measurement whose labels are discarded. Check whether taking a single square root of either aggregate echo gives the local arrival rate. A discrepancy beyond the sampling bounds rejects that shortcut. Positive single-port reciprocity is conditional on a time-independent symmetric generator and matched releases, readers and passive legs. The generator exposure is supplied at each appointment. The material-clock experiment has a separate source.
