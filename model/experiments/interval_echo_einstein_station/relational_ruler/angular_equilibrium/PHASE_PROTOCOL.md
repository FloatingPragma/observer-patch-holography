# Phase intervention and independent acquisition controls

The uncontrolled and angular-refresh returns were available when this extension was registered. Keep every board, source window, exposure, shot count and native Hamiltonian from the first protocol. An external midpoint gate multiplies the state in the launch window by exp(iθ) while leaving every other window phase at zero. The gate uses one radial classification and preserves the entire midpoint address distribution. Apply the same native flight before and after the gate. Read return to the launch window on separate copies.

Acquire θ=0, π/2 and π as calibration settings. Write their sampled probabilities as y₀, y₉₀ and y₁₈₀. Predict the two held settings −π/2 and π/3 by c+a cosθ+b sinθ with c=(y₀+y₁₈₀)/2, a=(y₀−y₁₈₀)/2 and b=y₉₀−c. Acquire every held outcome independently. Run the unit and double native rays in independent cohorts, using the same settings. The odd mark gives zero contact potential for both. Sample each return directly from the propagated native amplitude with the intervening phase gate. Use seed (631080,level,window,20+setting,q) in radians ordered 0,π/2,π,−π/2,π/3. For double-ray versions of the four existing arms append q=2 to their original seed. Set simultaneous calibration and validation bounds using Hoeffding's inequality at family error 0.01 over all 80 phase probabilities. Propagate the resulting single-frequency bound by the absolute sum of the calibration weights plus one for an independent held read. Report the observed phase contrast on every board. This check concerns transfer at the enrolled two exposures and a deliberately supplied phase gate.

Independently diagonalize the complete mobile Hamiltonian of the smallest board. Launch every occupied window in turn to measure the forward and reversed window kernels and compose the reset probability as a sum of independently propagated forward and reverse probabilities. Check the native unobserved, observed and phase-gated returns against explicit whole-board second-leg propagation. Acquire a reversed j=6-to-j=3 count with seed (631080,1,3,10) for comparison with the j=3 forward one-leg histogram and surveyed multiplicities. These checks give ground truth for the restricted propagation and reciprocity implementations.
