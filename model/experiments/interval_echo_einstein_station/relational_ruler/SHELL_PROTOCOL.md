# Does a uniform radial quantum preparation evolve in a closed shell basis?

In each enrolled native board hold the anchor initially sharp at home and prepare the tag in the equal-phase normalized superposition over all ports with relative range r−1. Both tags then evolve freely. Select the derivative of the amplitude into the orthogonal outcome block with the anchor still at home, the tag at r and tag degree five. At this first outward hop the native off-diagonal amplitude is −1/2 for each reachable neighbour. Compute the fraction of that amplitude's squared norm orthogonal to the equal-amplitude receiving mode within this fixed radial and degree block. A closed radial coherent dynamics with one uniform orbital per shell, even with separate degree-five and degree-six receiving orbitals, requires zero leakage. Retain the number of source and output addresses, all inward multiplicities, their squared norms and the orthogonal leakage. The conditional geometric coefficient is tested exactly. There is no additional projection or mixing during evolution.
