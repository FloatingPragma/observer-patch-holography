# Selecting the matter reference by work measurements

Use the same 246 stations, neighboring contacts and half filling as the interval experiment. Calibrate the periodic hopping action before the cooling runs. For each single occupied Fourier orbital measure an internal bond on fresh copies with the native symmetric/antisymmetric analyzer. Record both one-load bins and the quiet bin on every launch. Use $2^{30}$ launches per orbital and seed 271828. Infer an energy interval from the conditional sign among hits, with simultaneous coverage at least 99% across the orbital menu.

On each independent source, rotate to the measured orbital basis and read all occupancies. At each step choose a uniformly random unordered pair of addresses without consulting its occupancies. With one load present, exchange it only if the confidence interval for the destination lies wholly below the source interval. Count the comparison on every outcome. The finite cutoff is sixteen times the number of possible pairs. Check the resulting state and the energy deposited in the controller, including an unfinished run if one occurs. Begin with inverted filling, a uniform half-filled mixture, and an alternating sharp station word. Reverse the comparator on the cold filling and park the comparator on a hot word as controls. A seed fixes the proposal sequence for each source.

The questions are whether every allowed input cools in the long run, what probability a fixed stopping time leaves unfinished, and whether the selected source supplies both signed regional matter responses on overlapping intervals. The temperatures, moving-ball geometry and dark-matter interpretation of three-dimensional observers are separate physical identifications.
