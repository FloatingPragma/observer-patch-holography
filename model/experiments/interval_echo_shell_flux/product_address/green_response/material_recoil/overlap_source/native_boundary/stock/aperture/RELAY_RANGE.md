# Transverse ranges at fixed observer radius

The matched material release uses fixed radial ranges. Measure what else in the geometry can change while keeping those radii fixed. Use the same stationary preparations, the same two material alphabets, station 219 and the shell containing both ends of the third contact. The registered statistic is the mean of the shortest relay times over **all distinct unordered pairs** of stations on that shell. Report both alphabets, both directions of each link, and every ordinary and matched control.

An endpoint sends a random bit using two full pulses on fresh copies of the same recorded input. In one order send zero and then the positive load. In the other order reverse them. The receiver knows the recorded start, reads its own final load on each copy and returns the bit only when its pair of outcomes has zero probability under the other bit. Both hypotheses then have equal success probability. Repeat with independently drawn and prepared sharp records on every attempt. Charge one clock unit per two-pulse attempt, including erasures. Report the expected attempts to acceptance and the geometry it predicts. The gate for a decrease in transverse range requires negative change on both load alphabets. Common ordinary mass additionally requires agreement of the calibration ratios.

This measures ideal relay time with heralding and a renewable supply of recorded starts. The clock unit omits acquisition and acknowledgement latency. Testing a universal geometry requires comparing these time readings with independently moving material.
