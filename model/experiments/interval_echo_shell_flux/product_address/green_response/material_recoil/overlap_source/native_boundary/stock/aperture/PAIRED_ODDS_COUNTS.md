# How many local observations distinguish the source from the equilibrium explanation?

The source table and the spectral bound for replicated ordinary material have already been evaluated. For a new count bank freeze 1,024 accepted independent 2200 preparations per arm. At each contact read the local written magnitude. Match the two readings by preparation ID and keep the pooled rejection count. Test the native source, an independent product control and an equilibrium control at odds 59/100 with the same nominal marginal probabilities. The last ratio rounds down the lower bound from the occupied-chart spectroscopy.

Before drawing these banks, fix a one-sided exact conditional test of odds at least 59/100 at level 1%. Condition on both observed one-contact totals. Sum the exact integer weights of every feasible table with at most the observed number of double-positive receipts. Report every result, including either control rejecting. This tests the already specified source and energy comparison with new simulated readings. The earlier native counts and the choice of the comparison are known. A physical implementation would need the specified preparations, local readouts and selection efficiency.
