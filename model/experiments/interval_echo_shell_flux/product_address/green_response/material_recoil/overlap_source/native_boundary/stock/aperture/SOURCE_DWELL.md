# How many ordinary fringe readings can resolve the source?

Use the calibrated native relative frequencies 0, 32 and 33. Choose one dwell equal to pi divided by their nonzero mean (32.5) so that both nonzero phases are close to a half turn. Fix this dwell before obtaining new fringe counts. The receiver resolves the signed difference in bright probability between original and reassigned source copies. Keep the ordinary heads, paths and magnitudes from the earlier experiment. Read the accepted 2200 source as a favorable reference, and include all attempts at filling 1/16 with and without the third witness. For each pair of arms propagate the measured frequency intervals to the predicted shift and obtain separate fixed-length native receiver counts.

Report a sufficient number of independent trials per arm to distinguish zero from the specified ideal alternative at at most 1% error each way, using a fixed signed threshold halfway to the nearest allowed alternative. Distinguish accepted copies in the fixed-inventory example from attempts in the sparse example. Only the receiver shot noise enters this conditional power estimate. The emitter, frequency calibration, phase stability, detector efficiency and physical realization would have to be characterized for a laboratory forecast.
