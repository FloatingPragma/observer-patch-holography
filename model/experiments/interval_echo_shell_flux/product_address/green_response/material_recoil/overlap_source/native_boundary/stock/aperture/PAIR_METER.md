# Can the ordinary interferometer read an unknown connected charge?

The native versus independent full-source fringe shift is known. Give a new decoder only the 2200 reference-bin counts, the four ordinary occupied-versus-empty phase calibrations and the two bright-port counts comparing a held source with the native one. Withhold the held source's head outcomes and preparation fraction until scoring. Use fixed-marginal mixtures of the native source and product source at fractions zero, one half and one. Take one million trials per fringe arm per difference, one million attempted reference trials (retain failures), and one million per phase quadrature. Independently count the held head table for scoring. Recover a signed interval in nats for every source. This is an ideal simulated trial count; the endpoint preparation and interference visibility must be identified before predicting a physical laboratory signal.
