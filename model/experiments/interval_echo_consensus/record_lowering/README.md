# Native finite maps with intervenable, retained versions

An observer writes a three-input majority into a draft. A second dimer receives a copy before an intervention; a third receives the version sealed afterward. Two readers independently recover both copies and a final parity using the sealed version. On all eight possible inputs a comparison circuit using the old cache gives the same unedited outcome. It gives the wrong parity on all eight edited inputs. These are deterministic simulated readings of a compiled contact word. ## Logic at the contact

A positive literal addresses the first rail of a balanced dimer and a negative literal addresses the other. The rails carry zero or two. On two such operands the native writer's material endpoints both carry their mean, including when its memory is in a superposition. A balanced pointer comparing the first written endpoint with a zero standard is bright precisely if the material mean is two. The pointer is reversed before reversing the write. The bright outcome opens a single target exchange. Both source bits and the two queried memories return to their incoming state. A single control uses the same pointer against zero on the selected rail. No controls give an unconditional exchange. Every incoming sharp column, outgoing numerical weight and reversed column is checked from the 99-dimensional candidate operator. The calendar contains only named native contacts, local pointer-controlled shutters, the registered external intervention and a wait. [Operator calibration and physical interpretation](hardware.py)

For a finite function, fix the encodings and emit instructions for its true input rows at enrollment. For each row, positive or negative input rails test its individual literals. A reversible ladder writes the conjunction of the first two literals into a clean temporary dimer, combines successive literals, toggles the output, and reverses its temporary writes. An (n)-input minterm uses at most (max(0,n-2)) clean bits. Each output is XORed with the corresponding component of the table value; an initially blank target therefore contains the value itself. The same scratch can service successive rows and components. Encoding a finite alphabet in Boolean words specifies the meaning of its unused codes. A table whose domain is restricted to valid codes only requires the chosen extension on the other rows.

The [compiler](compiler.py) receives the table during enrollment. The contact interpreter receives the compiled word and the detector signal. The [Lean proof](Lowering.lean) models the same reversible conjunction ladder. Its `minterm` theorem handles an arbitrary number of source literals, either prior target value, enclosing saved gates and unused workspace. The `finite_map` theorem sums the matching rows of a duplicate-free finite table. The `prefix_faithful` theorem lifts this to every prefix of a program that reads distinct named sources or immutable published versions into its draft, with local interventions, seals and waits. A map that also consumes its old draft must first preserve a source copy on a separate shelf. Fitting physical registers and initially blank scratch specify the execution domain. The independent tests operate all sixteen two-input Boolean functions at both old target values on the material transducer, and check all 256 three-input Boolean truth tables and their complemented second output at every two-bit prior target. ## Appointments and costs

Each of two disjoint three-cell lanes has a writer seam, its adjacent zero reference, a separate remote head and its own zero reference. The lane holds a three-bit source, a draft, a cache, a sealed version and flag, the final target and a scratch dimer. On each carrier 256 joint runs vary the two inputs and both interventions independently. Each lane's complete conditional tape is unchanged when varying the other lane. The 56 raw balanced-digit reads per lane include both stations' assessments before computation, before and after intervention, after sealing and at termination. Every lane also has 128 binary projections, 284 echo or inverse pulses, 17 conditional shutter appointments and one designated wait. The deposited static words specify both endpoints of every contact. The indexed detector and shutter streams reconstruct the complete expanded sequence, including every dark result and closed slot.
