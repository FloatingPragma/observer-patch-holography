# A public reading that reaches every owner

A reader can receive exactly the right fractions of positive, negative and refused outcomes while disagreeing about which event occurred. This publication circuit tests agreement on individual outcomes and on a second local reading recorded at the source. It uses the registered Interval Echo contacts and a supplied local feedback and routing schedule. [Acquisition](measure.py) · [Complete branch and count banks](results.json) · [Finite theorem](Publication.lean)

Each cell has a two-bit receiving register and a two-bit outgoing register, initialized with balanced pairs of loads 0 and 2. Their four words are “nothing received”, “negative”, “positive” and “source refused”. The source observer retains the second measured bit on the source dimer and reads it again after delivery. Two native fair-pulse readings at owner zero produce negative, positive and refused records with probabilities 1/4, 1/4 and 1/2. The second pulse leaves the physical reference bit. The accepted signal is positive when this bit is one and negative when it is zero, while a refusal retains both possible reference outcomes.

Before emission, the native gateway incidence determines a breadth-first tree with ties resolved by owner number. A parent reads its own receiving register, writes its outgoing register with that value and exchanges its four outgoing rails with the child's rails. Every exchange uses only the two neighboring cells. The contact sequence along a path and back restores the internal ports. The child’s unused register replenishes the parent’s outgoing register, allowing another child to receive the same reading. Unserved branches keep the distinct “nothing received” word. The reduced operations call the existing 99-state-checked native sharp-register service. Scheduling and read-conditioned writes are supplied apparatus. The source word is unavailable to a child until the physical contacts deliver it.

Across the 20-, 80- and 320-owner boards all source histories give identical outcomes at every owner, including a deliberate source refusal. Each board’s simulated bank has 65,536 launches. Copying to all 320 owners used 2,391 intercell contact swaps in addition to local preparations, reads and routes. Omitting the first scheduled handoff, with no rerouting, makes 199 of those readers report nothing. A fresh independent emitter at the last reader retains exactly the source marginal. The probability of agreeing with the original event drops to 3/8. On the 320-owner board 40,980 of 65,536 fresh simulated reads then disagree. The native branch probabilities and sampled counts are reported separately.

The finite induction proves that a word already held by a sender reaches every served reader, for an arbitrary alphabet and a legal sequence of handoffs. Matrix elements give the reference-sensitive boundary. For an already recorded label, the theorem describes the ideal copying step. After copying a sharp label to two places and discarding one copy, a density matrix on reference and label retains precisely its blocks diagonal in that label. Arbitrary correlations and quantum coherence *within* each such block survive. The measured reference is classical. The emitter also reads the second bit on refused events. In a separate local two-rail control with no routing, a reverse pulse restores the input with probability one while its rail is unread. Reading its position first reduces the return probability to one half on each input. The seeded binomial sampler uses the clock probability recorded to twelve decimal places, so roundoff at one half gives the same counts on different numerical libraries. The result is a broadcast construction for a serviced sharp record.
