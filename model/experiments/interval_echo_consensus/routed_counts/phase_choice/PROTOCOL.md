# A phase analyzer selected by repair records

On the 20-cell Interval Echo board choose 18 distinct ports from 24 through 215 with PCG64 seed 129001. Enroll writable off-tree chords whose two ends are outside that set. At the start of each of 96 consecutive episodes prepare nine vacancies and nine doubles in a shuffled order among those 18 ports, with unit background elsewhere. Use fresh blank chord memories for each episode. Offer 60 uniformly sampled distinct-port pairs with replacement on the enrolled set. Each native routed strict repair reports write or quiet. A changed route suppresses the addressed exchanges, using the same source words, pairs, contacts and read convention. Preserve every offer result. Use PCG64 seeds 129002 and 129003 for two separate histories. The native geometry, codes, replenishments, controller and scan clock are supplied.

Group successive public reports into windows of twenty offers and record the number of writes saturated at seven. Count transitions between adjacent windows within one history, including window boundaries across replenishment. Do not connect the last window to the first. Also report the table omitting transitions across replenishment. Apply the existing eight-bucket raw three-cycle product gap to every triple, taking the lexicographically first absolute maximizer. A zero maximum is a refusal. Feed the signed gap of the chosen triple to the phase apparatus. Compare a forward chronological reading, backward reading of the same public log, the two orders pooled before selection, and the disabled-route log. Keep both independent histories even if their selected bits differ. Run the same decoder on the retained historical repair-load table as an archival check. Its original bucket definition and post-hoc provenance belong to that archive.

Declare that a positive gap selects the analyzer with the active contact exposed for 3π/2, and a negative gap selects π/2. Also run the exchanged convention on the same histories. A positive or negative choice dispatches a physical pulse before an identical full address read. A refusal dispatches no pulse and is reported separately from all 17 address outcomes. On new 20-cell phase preparations balance an excess at port zero with a vacancy at 239, then expose the edge (0,1) for θ modulo 2π. Test θ/π equal to 0, 1/2, −1/2, 1, 1/6, −1/6, 1/3, −1/3 on each selected pulse. Retain all 17 read bins with 8192 independent simulated launches per setting using PCG64 seed 129004. Use one experiment bank per source and analyzer setting, then consult that same bank when selectors request that setting. The control swapping the convention is a re-use of those banks. A separately predicted address-zero probability is (1+s sin θ)/2, where s is the declared analyzer sign. Bound all 16 bank discrepancies together at 99% by the two-sided Hoeffding interval, with the native sampling-grid allowance. Real anchor preparations should be insensitive to the selected sign. Reversing a strict history should interchange the two forecasts for the complex probes; pooled and disconnected controls must refuse. Report the numerical asymmetry of a particular driven history separately from the probability law of the phase sensor. Absolute chirality, a cosmological arrow and the empirical uniqueness of the convention require independent evidence.
