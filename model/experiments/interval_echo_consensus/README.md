A complementary service settles sharp discrepancies across the entire sphere with local priority checks and asynchronous requests. ## Which operation counts as a repair

On a blank collar the native echo maps both (2,0) and (1,1) to a state with endpoint loads (1,1). For (2,0), the squared loads fall from 4 to 2. For (1,1), they start and end at 2. The pair pointer fires with probability one in both cases. Extending the original sharp-double acceptance test to an initially balanced adjacent pair would therefore count a transaction without strict descent. The written collar already distinguishes the two inputs by their contrasts. [Native echo](../../candidate_laws/contrast_memory_spherical_v1/law.py) · [Full input table and controls](results.json)

The strict instrument requires a blank collar and tests the **absolute** written contrast of two along with the pair pointer. Its positive subspace contains both signed contrasts. Keeping those signs coherent permits the local phase read. On all six initial two-unit basis states, each accepted write lowers the squared loads by exactly two. Every resulting state is stable under another strict attempt at either address.

## A phase generated by changes in neighboring signed records

Use the native write to read the signed contrast on each seam of a primitive cell. For a proposed interchange of the two endpoint loads, compare the words before and after on every address. Transport the operated seam's own sign reversal with the interchange. For each other address compare the two signed words. Give each changed word one binary flag. Encode each flag in the even or odd state of the same unit exchange used for the signed-memory parity. Run the rails for one common exposure and undo the encoding. Take the resulting continuous operator as an experimental material law. The primitive cell program is reused at every physical contact. The zero-reference correction must give a constant diagonal on a freely moving single load, with the smallest correction zero.

The primary comparison uses equality of whole signed words. Compare also a unary displacement and every ordered pair of its unary crossings (squared displacement). Test all port values 0, 1 and 2, all primitive seams, and the squared-displacement extension on all 99 seam states. Compare reading the actual physical neighbors after assembly, reading the operated seam without transporting its sign, omitting the change flags, and running two copies per flag. Retain disagreements. Include a check in which exchange and change flags have independently adjustable rates to determine whether the earlier pin requires a common rate.

For the binary release use the original board, launch (156,157), the thirty internal seam outcomes of cell 13 and quiet, with fresh copies at each exposure. Evaluate the primitive program, the assembled-neighbor program and the omitted-flags control through native exposure 37. Bound the minimum home-record probability on the whole window against the published 94% threshold. Check the complete distributions at 1, 7 and 37 and compare the primitive program to the archived counts at the original seeds. Independently test a phase read of an empty-port signed memory with contrasts of magnitudes one and two at exposure 1/3.
