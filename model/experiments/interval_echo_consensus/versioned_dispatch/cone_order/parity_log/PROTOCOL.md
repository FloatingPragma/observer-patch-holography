# Five independent roots and every parity in one material log

Freeze the 80-cell mounted Interval Echo read/store bench. Allocate 37 disjoint seven-bit shelves in index order. The low bit contains a value, and the six upper bits contain the producing event ID. Zero stamp means unpublished. Appointments 1–5 unconditionally write the supplied five input bits into shelves 0–4, with their own IDs. No subsequent nominal command targets these roots. Appointments 6–37 target shelves 5–36 in increasing five-bit mask order. Each reads every selected root's full value and writer word independently at both heads. Require valid matching reads and the enrolled root ID. A supplied Boolean controller computes parity of just the selected measured values, with empty parity zero. Publish on the blank target with the current event's ID. Other sinks and previous diagnostic tapes are outside the public value of this event. The actuator's blank precondition is fixed throughout the enrolled source family. Its diagnostic reads are retained. Witness the single-target frame at each sealed write, and read all 37 final words with both independent heads.

Enroll all 32 five-bit input words. Execute the entire 37-appointment program in each launch, with no reset between sinks. Each nominal run should have 5 independent immutable source events and 32 coexisting sink events. For each input and sink, find the least subset of source registers whose fixed values force its output across all 32 completions. Predict the subset equals the sink's actual mask and that all its supersets force the result. Authenticate a direct edge by the child's certified support, the parent's written register, the read source writer identity, and equality of the child's received value with the parent's published value. Predict precisely 80 root-to-sink edges per log, no intervening sink edges, five height-zero roots, height zero at the empty sink and height one at every other sink. A correct point placement on one log would require realizing all 32 closed-ball cuts on the five simultaneous source roots. The five-root theorem excludes this even if a different spatial chart may be chosen retrospectively for each whole log.

For every input in a changed program, replace the sink for mask 5 (roots 0 and 2) by an actual read of roots 0 and 1 while retaining nominal mask 5 as the source declaration. Predict the independently forced mask becomes 3, disagreeing on support in all 32 inputs and on the output value in 16. In the input-21 shutter control, park the second physical head during the full read of root 0 at the full-mask sink. Expect an undecodable pointer response, refusal and a blank full-mask shelf, with every other sink published. In a separate input-21 control temporarily exchange the low writer-ID bit of root 0 before that full-mask appointment, then restore it after refusal. Both heads should see the same value and the same wrong writer, and the full-mask shelf should remain blank. The altered stamp is an external fault, separate from nominal source semantics.

Archive material address maps, measured rail codes, input enrollments, store tapes, source versions and the independently reconstructed support and event order. Treat every reading as a deterministic simulated sharp outcome of the mounted read/write instrument. Findings concern generated semantic order under the supplied schedule, parity controller, and enrolled input/menu. The experiment does not identify an autonomous host signal cone.
