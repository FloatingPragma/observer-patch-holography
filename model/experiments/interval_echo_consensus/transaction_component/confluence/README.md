## The declared repair relation

Two triangles each hold one protected bit and three data bits. Any of the three pairs, or all three positions of either triangle, may be offered at an isolated appointment. An offer copies the triangle's measured boundary value to every offered position if any of them disagree. A redundant offer emits a stutter. The admitted public state contains both protected bits, both active words, and both independently read bank addresses. The address counts the disagreements in that triangle, so the protected bits and the six disagreement flags specify exactly the same states. Inactive banks and the past sequence of reader appointments are outside the endpoint being compared. The raw histories retain both different orders.

Let U be the six-address set of unresolved positions and S the offered positions. The next unresolved set is U ∖ S. Thus the offer closes every covered mismatch, and a nontrivial change strictly decreases the single integer |U|. Two different offers S and T reach the same U ∖ (S ∪ T) in either order. If a branch has already reached that union, no additional write is needed. This proves the local diamond for both overlapping and disjoint offers without a choice of scheduler. A state is normal exactly when U is empty: any unresolved address belongs to an allowed offer. There is one such state per protected pair. Termination concerns accepted changes. A controller that only offers already-correct positions can indefinitely emit stutters before a normal state.

The [Lean proof](Repair.lean) maps the version-free active records to this relation and proves coverage, strict well-founded descent, the commuting diamond, normalization and consistency. It instantiates the [observation-relative endpoint theorem](../../../../../Lean/ObservableNormalForms/ObservableNormalForms/ObserverConfluence.lean) for every function of the two protected bits. Endpoints agree for every equal pair of source observations exactly when that function separates the consistent states. The full boundary pair separates all four. In the coarse control the far observer compares the two measured boundary rails with the native disagreement pointer. Boundary pairs 00 and 11 both return zero. The final words are 000/000 and 111/111 respectively, and their count addresses are all zero. This is a measured counterexample to uniqueness under the coarser observation even while ordinary same-source confluence holds.

## Material implementation

The physical board contains twenty owners. Each logical triangle has four banks of three balanced material dimers. The four count addresses in each selector are (197,192,193,199) and (209,204,205,211), respectively, in increasing count order. One selector port carries a double load. Two adjacent native triangles share the central seam of each selector. Any count drop of one or two uses a single native π-exchange. A whole-triangle move from three to zero uses three seam exchanges realizing an endpoint transposition and restoring its intermediate load. Public inquiries occur at completed appointments; the terminal reader cannot query intermediate stages of that three-contact route.

Owners 0 and 6 prepare the two triangles. The committing owner 13 independently reads their offered mismatch pointers against the protected dimer, performs the guarded stage, revalidates the active bank and rereads the staged word. Owner 15 queries each of the four selector addresses and then uses the measured address to choose the bank. Its six balanced data clicks distinguish all eight words. Its two additional clicks recover the protected value. Before publication it reads the original bank; after an admitted exchange it reads the new word and count. Copies with all inactive dimers initially set to the opposite value give identical public observations throughout. The twelve possible directed selector transitions and every bit column on all three enrolled stations are checked separately. The underlying ternary echo and full π-exchange columns are certified in the [native instrument](../../prepared_quorum/transport.py). [Two-triangle apparatus](apparatus.py)
