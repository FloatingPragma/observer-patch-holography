# Two observers use a measured mean to choose their next repair

A native write on two sharp material digits lets **both** endpoint observers read their exact sum. In a simulated 240-port federation this supplies twelve seven-place registers. The observers read their means, conditional routes and public decisions on individual preparations. With the three real input standards \(-\sqrt 2,0,1\), five of nine input pairs took the low route, three took the high route and one abstained. The two orders of the unlike nonzero standards gave the same independently read destination value \((3-\sqrt2)/4\). Treating the standards as equal in magnitude made both mixed orders indistinguishable at the decision boundary. ## The material write

A binary place is a balanced dimer in orientation 02 or 20. Full native exchanges deliver one load from each operand to the two ends of a blank writing seam. The native echo writes a coin and the input contrast. For incoming extremal loads \(2i,2j\), the two output loads are both \(i+j\) on every coin outcome. Stations at owners 18 and 19 separately route their respective written endpoint to zero and double standards. The two binary pointer bins resolve a ternary reading. The inverse echo restores both original inputs and the blank memory because this read is definite throughout the written superposition. The endpoints independently propagate the binary carry along their observed trits and divide by two. A supplied local controller compares its present balanced dimers to the commanded output and exchanges exactly those requiring a change. All coordinate axes of a multicomponent mean are read before any word is installed.

The archive gives the digit reads used for each accepted mean, each store command and its confirming read, along with 692 supported route templates. A path runs forward and reverses all but its final swap, exchanging its endpoints and restoring every intervening load. The writing seam is excluded from transit while its memory is occupied. Readout of a sharp material load is distinct from an address lookup in the controller. The contact effects are reduced from the registered 99-state law. These are deterministic, simulation-generated effects with complete sharp pointer words. ## Finite real registers and their domain

Give a finite menu of real preparation and reference values a material coefficient axis for each standard. Zero or a one-hot code prepares the corresponding value. Between preparations an addressed mean acts independently on each coefficient pair. The sum of the measured coefficients multiplied by their calibrated standards is exactly the real mean. The two-axis experiment uses integer tests \(v^2<2u^2\) and \(v^2>2u^2\) on nonnegative measured coefficients to select the sign of \(v-\sqrt2u\); its decision needs no input label. A finite read menu can be tabulated before a run for the reachable codes. If equal decoded reals have different codes, the table must give the same public observation to both whenever the declared interface reads only the real value. The real standards and the implementation of their comparison on reachable keys are supplied calibrations.

For a supported program whose remaining path has at most \(d\) instructions, reserving \(d\) low zero places is sufficient. Each mean consumes at most one such place and stays within the original range. Thus every reachable material midpoint is exact. One may give each of finitely many preparable reals its own axis whatever their numerical values. The initial one-hot entries then need \(d+1\) binary places. The [Lean proof](Programs.lean) derives the carry and no-overflow bounds from the two observed binary digit words, proves that the real decoder commutes with the physical move, and constructs the station read as a lookup in the supplied finite table. The theorem `complete_enrolled_run` supplies the initial one-hot preparations and the depth bound for each supported decision tree. Its conclusion equates the finite-table machine result with execution on the calibrated real values for every choice of source labels. The executable finite-tree interpreter reads only enrolled entries; a missing observation entry produces a refusal. The experimental width is seven and the federation provides twelve coefficient shelves. Larger programs require a supported layout with enough dimers, routes and independent read heads. The [bank compiler](../../../../../Lean/Geometry/SourceBankExecution.lean) supplies the lowered scalar words, routes, bounds and decoder margins for its own finite program family. Its design-dependent resource bounds apply before a layout is enrolled. The measured bus and accumulator are individual instances.

The analog scalar register in the [pooled instrument](../README.md) is a different preparation. Any binary sharp word has positive probability under both interior populations \(p=1/4\) and \(p=3/4\). A finite listener with access only to copies of the unknown mixed register therefore sees the same set of possible transcripts on both sides of one half. Even a collective read has a nonnegative response on each product input and hence the same support after averaging with either strictly positive mixture. A zero-error sign decision must abstain throughout that common support. A positive error allowance, a separated preparation alphabet, or an extra source record changes the allowed read. The finite real-register result requires a supported sharp preparation and observation menu.
