# A finite-confidence controller on continuous material means

Two observers choose and execute the next averaging seam using physical counts from independent ensembles of the same unknown real-valued preparation. Each inspected ensemble retires. Every surviving copy receives exactly the same next instruction. A separate terminal pair of observers can abstain or publish a signed interval, including its two integer scores as material words. The controller has access to the terminal sharp-count histogram only. Source coordinates, private intermediate histories and exact target means are available separately to the assessor. Both final observers measured a negative result, and their public material words reconstruct [−0.20600, −0.16289]. Changing the contact dwell from π/2 to π/3 changed both earlier decisions to negative. Reflecting the initial preparation also reversed the first decision between the native and changed laws. The two inputs beginning (−0.8,0.8) and (0.8,−0.8) have precisely the same native first pooled-read distribution, despite their different intermediate pointer histories. Both abstained there. The experiment separately exercised a tie on the second decision, a tie at the terminal publication, and two means of magnitude 0.005. All these native cases abstained at the registered stage.

Each panel reserves four independent cohorts. In the longest run four cohorts receive the first seam, three the second and two the third. The two final cohorts both undergo the terminal measurement even if one result is inconclusive. All enrolled preparations count. The ensemble copies are independently initialized resources; the four cohorts are not four inspections of a surviving individual. The two terminal scores are encoded in separate 17-bit words using 34 balanced dimers, with two additional sign/abstention dimers. The two observers can reconstruct the interval from the recorded material rails, the cohort size and the published error rule. The numerical-word check consumes the same acquired counts. [Native publication and routes](publication.py) · [Count-only replay](readback.py)

For K possible inspections of a bounded [−1,1] payoff and global error probability δ, the service uses half-width r=√(2 log(2K/δ)/N)+γ, where γ bounds an implementation's displacement of the true mean. Here K=72, δ=0.01, N=32,768 and γ=10⁻⁹. The guarantee covers all reached adaptive decisions and the two final reads simultaneously. A source with |mean| greater than 2r at each required step obtains a determinate result on the covered event. An interior or zero-margin source can abstain. A raw terminal estimate on the wrong side of a threshold does not publish unless its interval also excludes that threshold. The reported intersection is used only when both individual intervals exclude zero with the same sign. The sharp flag read uses no further statistical error budget. Unsupported native edges, out-of-chart input and insufficient preallocation refuse. [Derivation and limitations](PROOF.md) · [Checked signed interval implications](Publication.lean)

The frozen machine uses a physical scalar chart at twelve fixed work ports, supplied fresh preparations, independent randomized native measurements, public count accumulation, and an externally specified finite tree and timing. It implements approximate read-select on bounded continuous inputs with a declared failure allowance. An exactly discriminating finite read of arbitrary interior real values is outside that service. A program requiring positive availability near an unresolved threshold needs a different margin or error contract.
