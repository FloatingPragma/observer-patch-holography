# Phase within an accepted repair address

The full-readiness instrument gives identical endpoint states for the plus and minus superpositions of the left and middle doubles. Test a priority service that delays the lower-priority request without interrogating its collar until the priority request has had its turn. Both requests are supplied and retained by the two-cell controller for one service window. If the first probe finds its priority seam ready, commit and end the window. If it is quiet, query the other seam and commit only on a hit. This policy uses the same strict native write and the same prepared priority rail. It also requires the two requests to reach the arbitration window. Liveness under a missing request is outside the experiment.

Freeze the original six-dimensional input space and both arrival orders. At either priority the full output channel must agree between arrival orders within 10⁻¹⁰ and every terminal retry must be quiet. At priority A, test phase distinguishability on (left double ± middle double)/√2 within the winning A address. At priority B, use the reflected middle/right source on B. An inverse echo on the accepted collar followed by a native partial swap of the two load rails can read a relative phase locally. For this detector use relative phases +i and −i on the rails, a half contact and a sharp rail reading. Require opposite detector outcomes with probability difference greater than 1−10⁻¹⁰ in both orientations. As a control, apply the same detector to the instrument that reads both readiness flags. Require a probability difference below 10⁻¹⁰. Report the surviving phase only within the fixed-address subspace.
