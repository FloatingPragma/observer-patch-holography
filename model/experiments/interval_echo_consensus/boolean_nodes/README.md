# Boolean formula repair with native Interval Echo contacts

A node observer can tell when its constraint fails using a local balanced-pair pointer. The observer switches its own output on precisely that outcome. On the declared periodic scan this implements the input-independent Boolean formula compiler in the computation library for every formula that fits on a federation. The experiment uses a protected material register, timed contact isolation, local read-triggered shutters and a supplied address calendar. [Protocol](PROTOCOL.md) · [Native transducer](material.py) · [Lean connection to the compiler](../../../../Lean/Computation/NativeBooleanNodes.lean)

## What one node sees

Store a bit on two ports as (0,2) or (2,0), with the first port carrying twice its value. On two extremal input rails x,y the native echo puts its first endpoint at (x+y)/2 with probability one. The integer write matrix verifies the balanced-pair flag on every sharp input column and exact restoration after each applicable projected read. The installed binary pointer reports only whether both outgoing loads are one. A bright read gives the middle bin. After a dark read the extremal operands agree. Unwrite the echo and compare the first operand to a separate reference of load two with the same binary pointer. Bright now means zero and dark means two. Unwrite this probe as well. The resulting three-valued measurement equals the first endpoint load and restores both operands and all queried seams. A NAND node reads 0, 1 or 2 and sets a local scratch bit on the first two outcomes. A variable or constant paired with a fixed load of two sets that bit on the last outcome. A second identical probe compares the scratch bit with the node's old output. Its middle outcome occurs exactly on a mismatch and clocks a native exchange of the two output rails. Recover the scratch unconditionally. The old source bits, all remote owners, and each transient routing load are restored at the end of each transaction. The inactive ports carry a nonuniform test pattern. No formula truth value is available to the scheduler. [Exact column and register checks](test_nodes.py)

The free address network connects the three gateways of each owner. Two disjoint adjacent pairs and a reference port are reserved privately, each touching this network. A finite check covers all 220 choices of a three-gateway subset of the twelve ports. Each routing contact is served by the one or two owners incident to that seam on the supplied calendar. A transpose along a path of length d uses 2d−1 native exchanges and restores intermediate addresses. Each operand reaches the node's query contact by such a transpose, undone after the read. The network and constants are apparatus. Capacity is one owner per immutable input and emitted node. Sharp-bit queries and complementary outputs stay in their declared domain under every offer, even when the initial node outputs are all wrong.

## From one read to every formula

The actual compiler emits the leaf copies, constants and binary NANDs in postorder with distinct output addresses. Structural induction shows that each emitted node's read equals its specified Boolean value on every state. The Lean theorem proves that the two-query pointer decoding equals the half-sum on all four input pairs. The mismatch rule equals the compiler's canonical write as a function on the entire register. The theorem `compiled_histories` then identifies every finite prefix for arbitrary adaptive offer calendars using the same node services throughout. In a cyclic scan of L emitted nodes every member receives an offer within L attempts from every starting phase (PR-84). If no write has yet occurred, the inputs and failing node are unchanged, so a write occurs within L attempts of every non-consensus state (PR-85, q=L−1). A complete scan in emission order fixes the whole formula on the first pass. A second quiet scan certifies completion from the recorded middle-bin flags alone. Reverse scans also converge because a node whose predecessors have stabilized stays correct after its next offer. The indefinitely callable calendar accepts every nonnegative request index. The receipt ends acquisition after a quiet sweep and the next two sweeps from every already-correct small-board phase were separately tested. The receipt counts node offers and routing exchanges separately. Neither count measures a spontaneous scheduler or solves unrestricted satisfiability. [Fairness and one-cycle proofs](../../../../Lean/Computation/FixedFederationExecution.lean) · [Bounded-waste proof](../../../../Lean/Computation/FixedFederationComplexity.lean)

For a board with V ports, each routing path is simple and has at most V−1 edges. A binary probe makes two transpositions and undoes them, spending at most 4(2V−3) routing exchanges. A node offer uses at most four binary probes, eight echo or inverse-echo pulses, and three additional local exchanges for scratch and output. In emission order, computing and verifying an L-node formula therefore costs at most 2L offers and 32L(2V−3) routing exchanges. On the small board the native forward cohorts made 180 offers and 12,320 routing exchanges in total. On the larger board the corresponding totals were 432 and 34,632. These are counts on a preaddressed board with supplied protected transactions; translating them into elapsed time would require a clock and costs for routing control and shutter switching.

## Outcomes

On the 20-owner board all four inputs and all eight stale vectors of a two-input NAND were tried. On the 80-owner board the formula included a constant, a repeated variable and nested NANDs. All eight inputs and three stale vectors were tried. For both scan orders, all 32 small-board configurations and all 24 large-board configurations reached a quiet scan with every node correct, for 112/112 across schedules. Parking the query or substituting a reversible swap left only 4/32 small-board configurations and 0/24 large-board configurations correct per order. Reading the opposite stored output rail gave 0/32 and 0/24. The ternary labels preserve the entire binary pointer transcript (bright alone, dark then bright, or dark then dark). Every offered read pair is stored in time order as 3 times the first reading plus the second. Replaying these flags from the stale vector recovers every final node output.
