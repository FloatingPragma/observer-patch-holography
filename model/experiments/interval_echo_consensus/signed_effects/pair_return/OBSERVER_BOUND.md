# What four return readings certify

Four station owners each read a material bit at two appointments. Serial comparison of the first four bits reports which of six pairs contains the mobile excess. Comparing the second word with the first tests the return after analysis. With trusted preparations and calibrated readback, four probe settings per pair bound the error on **any later public event**, even when its observer keeps a quantum reference. The joint confidence is 99% under independent launches of a stable instrument. The bound concerns unconditional event probabilities on the public pair label, outgoing data and untouched reference of the enrolled one-excess code. The two compiled writers restore this output code. The test supplies serial comparison of the four local reports. A read conditioned on a particular first pair obeys its individual bound because both instruments have the same first effects. Private hardware and conditioning on an additional rare selection require separate access and probability estimates. ## From clicks to a bound for all later readers

For each first pair label, let P project onto its two input addresses. The compiled first reader has exact effect P. For each Kraus map K of that label, positivity of the other branch terms and zero complement effect imply K = KP. Thus the restricted channel on the two-dimensional input is trace preserving, and the complete labelled instrument discards input coherences between different pairs. Prepare each coordinate of the pair in turn, then each equal superposition with relative sign + or −. Correct return means that both the indicated first pair and the decoded terminal address match the prepared probe. The decoder uses the first pointer XOR the second. All four raw pointer bits, the unused labels and refusals enter the denominator. Reversing the routing and applying the independent X analyzer reads the relative sign.

For a restricted channel let J denote its normalized Choi matrix and let Φ be the normalized maximally entangled vector supported on this pair and its input copy. For either real orthonormal basis, the mean return frequency estimates Tr(J B), where B projects onto the two matching basis pairs. Write these projectors as Bz and Bx. In the Bell basis they each contain Φ; their other directions are the orthogonal vectors Φ− and Ψ+. Consequently I + |Φ⟩⟨Φ| − Bz − Bx is the singlet projector on the coded four-dimensional space, and identity on additional output dimensions if both calibrated matching tests reject them. The implemented proof uses known output confinement: outside the one-excess code an empty cell can be reported as address zero. The generic inequality for commuting return events is [kernel-checked in Lean](../../../../../Lean/EventAlgebra/ComplementaryReturnBound.lean). Entanglement fidelity is therefore at least Fz + Fx − 1. This is the complementary-basis fidelity bound of Hofmann. [Original fidelity criterion](https://doi.org/10.1103/PhysRevLett.94.160504) · [Exact projector calculation](test_observer_bound.py)

If this lower bound is f, the trace distance of J from the ideal pure Choi matrix is at most √(1−f). Any normalized pure qubit-and-reference input can be obtained by acting on the reference half of Φ with a linear map of operator norm at most √2 (the map's squared Hilbert–Schmidt norm is 2). Multiplication on both sides increases the trace norm of the Choi difference by at most a factor of two. Convexity extends the result to mixed inputs and partial trace covers larger references. Hence any downstream event changes probability by at most min(1, 2√(1−f)). For a superposition across the six pairs, both complete labelled instruments first restrict to the same exact effects. The sum of the six unnormalized input masses is one. Taking the largest pair bound covers the whole code. This last step requires the exact first effects; finite returns alone do not certify arbitrary effects on an unenrolled input.
