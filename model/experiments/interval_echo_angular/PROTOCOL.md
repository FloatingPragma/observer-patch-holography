# Which measured port directions would suffice for the directional Einstein test?

Use one complete echosahedral cell's Interval Echo one-load instrument. Launch each of its ports separately, let the native generator act for a supplied time of 1/4, and retain every terminal port. Give the inverse only the count table with a common anonymous permutation of source and detector labels. Use 32 independent count tables at each of 128 and 65,536 preparations per input port. Use NumPy PCG64 via SeedSequence([74291, budget, repetition]); for each table draw a permutation then twelve multinomial histograms. Do not pool tables or select frames by the tensor result.

Assume reciprocal, uniform nearest-neighbour exchange and the weak-exposure branch of the existing spatial instrument. Symmetrize the empirical transition table and locate the largest gap between sorted off-diagonal entries. Accept a reconstruction only if there is a unique largest gap, the inferred adjacent set is a connected regular graph and its first nonconstant Laplacian eigenspace has a nonzero projector diagonal at every port. Record the inferred rank and compare the inferred neighbours with the planted graph only after reconstruction; count abstentions and mistaken graphs. Repeat the angular design calculation for every certified high-budget table. The spectral multiplicity is an output. No Cartesian coordinates, null contractions, curvature or directional stress enter the inverse.

Use the recovered normalized Gram matrix to test the conditional null-direction design in the RER paper. A measured unit direction n supplies the formal vector (1,n) in a local orthonormal Lorentz frame *if* such a frame and time calibration can be supplied. Enumerate every subset of nine, ten, eleven and twelve receiver directions. Report the number which span nine tensor combinations, ranks of the others, and extremal least nonzero singular values of successful nine-direction designs, with the unit Frobenius normalization for symmetric tensors. Compare the highest-sensitivity nine-direction choice with a control that averages antipodal readings. Independently verify these results using a factorization of the Gram matrix and explicit symmetric tensor features. The robustness experiment concerns finite directional coverage. It does not measure the metric, a physical light cone, stress, curvature, or a shrinking-ball error.
