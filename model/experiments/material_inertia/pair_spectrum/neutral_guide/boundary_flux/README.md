# Can the native outer boundary identify an electric source?

Two native material sources have the same visible ports. The strict write of 02 leaves 11 and a coin-even seam memory with contrast −2. The ordinary blank host has 11 and blank memory. A separate written-11 control records contrast zero. The stable mobile vacancy–excess component has independently measured positive resting energy and balanced material charge. Its electric interpretation depends on whether the extreme-contrast memory can carry a second additive charge. ## A charged standard disappears from the enclosing work

The observer puts a compensated vacancy or excess in the two spatial alternatives of a physical boundary edge. A native half exchange opens and closes the interferometer. Two terminal settings measure the phase accumulated under the native contacts while the two-address aperture and source are held. The signed field reading is half the difference between the work of the two test loads after subtraction of the independently recorded blank signal. It includes the native private reference costs. This instrument starts from test-particle work. It takes the positions, terminal counts and clock as inputs; a Poisson reconstruction or assigned electric source density would give a different experiment.

## A mobile detector resolves the written memory

A single sharp mobile test load starts outside both source owners. The full 240-port native generator, including every degree reference, evolves the joint detector and central material memory. At four waits the observer reads the detector's owner and, on a separate ensemble, whether it reached either source endpoint. The simultaneous 99% probability intervals after checking all 48 comparisons are [0.0000712, 0.0001506] for written 02 and [0.0007535, 0.0009769] for written 11. The largest observed total variation between their 20-owner histograms is 0.006343. The source is locally detectable. The strict seam term makes written 11 exactly equivalent to closing its seam for these single mobile probes. After writing 02 or 20, tracing the central memory gives the equal mixture of two closed-seam flights with contact energies 32 and 33 on its two endpoints. This holds for both probe signs on the irregular carrier, with the actual sign-dependent private potentials left in place. Reversing the source write leaves every outside probe marginal invariant.
