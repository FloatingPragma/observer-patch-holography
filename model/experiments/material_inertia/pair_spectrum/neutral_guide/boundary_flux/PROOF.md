# Native fields and material scattering at two sources with the same ports

## Passive exterior

Let W be the native write, U its Hermitian echo and J the blank embedding. For every written source W|a,b⟩, U maps that state to J|a,b⟩. Since the memory generator G vanishes on the blank, h=UGU annihilates every W|a,b⟩. The raw writes of 02, 20 and 11 all leave the two ports in 11. Every other blank seam acts on two ordinary units, so its free term also vanishes. The private degree references see exactly the same port word on each preparation and contribute only the same scalar. Thus blank 11 and these three writes are stationary on the complete federation before a probe arrives. Tracing out the source gives identical exterior density matrices at every exposure, including any final measurement by several observers. A probe that enters the source changes the problem.

For an arbitrary material state with all memories blank, hJ=Jh_blank holds as an operator on both ports. Other seams act trivially on the specified seam memory. The tensor product of blank memories is therefore reducing for the full native sum, including the private port terms. A detector reading native memory on any family of boundary seams has exactly the all-blank result on the entire stable band, on either freely moving charged standard and on a free pair crossing those seams. An active echo can subsequently write the local port contrast; this uses a separate physical interaction.

## Scattering by the written material

For a mobile signed test load the rest of the host is unit filled. Remove the central seam temporarily, keeping the full native material generator on all other seams and every private reference. Denote the resulting generator by H_cut. The source memory has coin-even vectors |d⟩ for contrast d=0 or ±2. If neither endpoint contains the probe, the local word is 11. On that word the relevant source states belong to the image of W and have zero native seam energy. If one endpoint contains the test load, the local word is (1±1,1) or its reversal. With the same memory labels it is orthogonal to the entire image of W. The echo acts as identity on those vectors so h acts as the written generator G. It leaves the endpoint loads in place. The zero-contrast vector has energy zero, while the two extremes have matrix 32I+(I−R)/2, with R exchanging d=±2. The code contracts this invariant block from the full 99 entries and verifies every discarded row.

Writing 11 therefore gives H_cut. For either written extreme, diagonalizing only the memory reversal produces two conserved sectors with generators H_cut+32P and H_cut+33P, where P projects onto the detector occupying either endpoint. Either strict write has weight 1/2 in each sector. After tracing the memory every detector marginal, including on an entangled external reference, equals the corresponding mixture. This derivation retains the sign-dependent private potential on the physical federation; it does not require particle–hole symmetry of its degree profile. For a blank center the original seam's exchange and its two diagonal contact costs are restored instead. The measured response distinguishes a material obstruction and contact potential.
