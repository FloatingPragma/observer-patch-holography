# Recoil of the moving excess–vacancy pair

A smooth kick applied to both constituents gives a **positive recoil of the selected moving band**. The immediate response of the full pair has the opposite sign. Both measurements start with the lowest doublet of the same 24-line branch on the freely connected, unit-filled 20-cell Interval Echo carrier. Ordinary launches, filters and controls are those of the [wavelength test](../README.md). This exploratory instrument measures mobility in a specified owner coordinate. A spatially universal inertial mass and an electromagnetic field calibration require independent measurements.

## What an observer does

Start with one of the three sharp excess–vacancy preparations. Filter the lowest unresolved doublet, retaining the rejection count. This succeeds with probability 0.00012244, 0.00026168 or 0.00306870. Use the first nonconstant harmonic of the independently specified owner graph. Its projector column at the lowest-numbered neighboring owner, normalized to peak magnitude one, fixes a real address weight \(f\). The pair's centre read is \(X=[f(x)+f(y)]/2\), where \(x,y\) are the excess and vacancy owners. Apply the calibrated address phase \(\exp(\pm i\theta G)\), with \(\theta=1/4\). The common kick uses \(G=X\). For a differential kick use the signed load \(G=f(x)-f(y)\). External impulse, addressing, spectral filters, terminal port counters and the exchange-time reference are supplied. The kick settings and time windows specify this exploratory comparison.

On separate preparations, read (i) all terminal addresses after 1/16 native exchange time, or (ii) apply the original 24-line band filter immediately after the kick, then fly freely for 32,768 units and read both addresses. Every post-kick filter rejection scores zero. Divide the difference of the two mean positions by \(2\theta t\), conditional only on initial rest preparation. The receiver records the coarse position, every missed admission and every missed second filter. It uses no energy eigenvector to decode the count. ## Why temporal and energy resolution matter

Let \(H\) be the native generator and \(\rho\) an admitted rest state. Immediately after the phase impulse the velocity is the expectation of \(i[H,X]\). Differentiating with respect to the impulse strength gives
\[
 D_{X,G}=\operatorname{Tr}\rho [G,[H,X]] .
\]
In the address basis this observable has entry \(-H_{ij}(G_i-G_j)(X_i-X_j)\), so the calculation uses only true hopping edges. The short-time mobility can have either sign for a selected excited branch. The lowest doublet here lies in an isolated high-energy band. For the post-kick band filter \(P\), the same first derivative uses the compressions of all three operators to \(P\); the probability of a post-kick failure starts quadratically in the impulse. Finite-strength measurements use the actual physical phase and filter, with all lost probability accounted for.

On the **entire** rest doublet the numerical residual estimates give the common-kick derivative inside [−0.002416,−0.002151] without the second filter and inside [1.0438,1.2239] × 10⁻⁶ with it, across the two enrolled axes. For the differential kick the respective bounds are [0.004300,0.004830] and [1.215,1.324] × 10⁻⁹. Mobility within the band is therefore positive on both axes. The earlier three-shell timing test on these same rest preparations excludes a common scalar dispersion for its single-line interpretation.
