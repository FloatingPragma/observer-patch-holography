# Local elapsed-event publication protocol

Before editing the executable, fix these tests for a physical timing interface. Each moving observer reuses one existing work digit to retain the accepted event in two orthogonal load rails. A stationary observer uses a spare private digit for the current primary. At each local opportunity write exactly one new value, including zero. Each elapsed-word hand and each coherent π/16 oscillator must obtain permission from a physical read of that digit. Record phase, bit and elapsed word at reunion. Supplies are the guide, local gate selection and cadence, oscillator preparation, coupling and readout window. Keep all intervening waits, both travel directions, and both quiet and positive observations.

Use three- and four-bit probes on each common board (20, 80, 320 cells), with seeds 31 and 2026112301. The fixed itinerary is (8, 1, 2, 4, 16, 2), combining both capacity boundaries, a unit-interval reset and a held reversal. Test terminal phase quadratures on separate preparations with the same source seed and record their individual terminal bits. Every material event must give the same published bit to the mechanical hand and coherent hand. Its native oscillator conditional pointer probabilities must agree with independent 99-state reconstruction from the *read* public bits within 10⁻¹⁰, with observable norm error below that tolerance. At home every tested opportunity must publish the local primary including at both departure and return. The narrow and wider age retain their previous overflow and fresh-reset behavior. A suppressing unit handoff immediately after an admitted positive must overwrite one with zero, and a quiet after one must also clear it. A partially occupied memory rail or access outside the physical patch must fail visibly. A control deliberately suppresses a material publication or changes its stored value before readout. Both correctly connected hands must respond to what was physically stored. A hand wired to the primary has the existing independent positive-control disagreement. Every deterministic invariant must pass on all specimens; archive concrete counterexamples if it fails. Keep ordinary registered reunion/cohort values, native first-return outcomes and the archived statistical controls available for comparison.
