The block is the physical eight-cell Hamiltonian `H0+2^-34 T` from
`coherent_defect_wave/chiral_joint`. The immutable `atomic_spin_geometry`,
`collective_spin_response`, and `interacting_ground_preparation` receipts
and every inherited input hash are validated before calculation. The
actual native current, gauge commutators, translation and full-occupation
norm controls are replayed through their owning source module.

Each block retains its full physical Gauss kernel and kinematic carrier.
Exact ground and triplet spectral projectors dress the actual native
current. Repetition of identical full blocks, their orientation, these
spectral services, and the two-block exchange are declared architecture.
No efficient implementation of the exponentially large spectral services
is claimed. Their definition uses the finite source alone.

The coupling coefficient is the inherited lower block gap divided by
twenty-four times the inherited upper current residue. This choice gives
an explicit, volume-independent gap. The example observation time is
`Jt=1/4`. No empirical parameter chooses either number.

The calculation keeps its actual Hamiltonian clock, dressed intervention,
ground preparation and complete position, reference-axis and failure
records. Block translation momentum and the native internal cube momenta
are distinct. The controlled spacing limit is nonrelativistic.

The receipt hashes all local proof, code and test files, the repository
import closure, all three parent receipts, inherited source pins, and
the numerical requirements. Replay compares rational and symbolic strings
exactly. Only binary64 diagnostic values use absolute tolerance `1e-10`.
This package has no dependency on an external workspace or absolute path.
