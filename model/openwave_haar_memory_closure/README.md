# A computed spatial memory correction

The refined Haar source's201 retained modes have an exact Feshbach/memory
relation to all omitted modes. This package computes the nonzero positive
leading self-energy matrix and bounds the entire infinite-channel remainder
with a9/89 Neumann ratio. It gives a quantitative memory tail in the unchanged
source clock.

A same-clock Haar-vacuum control proves the boundary-only map is not autonomous,
and that retaining interior modes improves the certified small-time defect by
more than225-fold at t=1/1024. This is a specified-probe bound, not a claim of
exact autonomy or a completed4D continuum construction.

Run `python -m model.openwave_haar_memory_closure --write`, then a fresh
`python -m model.openwave_haar_memory_closure --check`.
