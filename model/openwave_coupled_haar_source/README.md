# Interacting gauge loops

Two neighboring gauge loops share an exact SU(2) electric link. Their full
Gauss quotient has an explicit spin-network basis and exact recoupling
operators, including every Haar representation. Independent
Clebsch–Gordan sums check the Wilson coefficients. The shared-link
Casimir couples the loops without an empirical fit.

The [proof](PROOF.md) identifies the complete infinite complement used by
the [spectral certificate](../openwave_coupled_haar_spectrum/PROOF.md).
These are finite-graph gauge results; physical particle identification
requires a separate continuum and scale attachment.

Run `python -m model.openwave_coupled_haar_source --write` and
`python -m model.openwave_coupled_haar_source --check`.
