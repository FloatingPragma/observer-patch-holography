# Native leptonic decay widths

The native charged ratios and weak current give a tau muon/electron
partial-width ratio of 0.97256384, compared with the unused PDG 2025 fit
0.9730±0.0022. All nine massive-neutral channels per decay are included.
An explicit calibrated weak coefficient gives widths in GeV; its
muon-lifetime ancestry is recorded. A weighted spectral bound transfers finite survival intervals to the
calibrated massive-neutral source without enumerating its full Fock space.

Run `python3 -m model.openwave_lepton_widths --check` and
`python3 -m pytest -q model/openwave_lepton_widths`.
See [the proof](PROOF.md), [inputs](inputs.json) and [receipt](results.json).
