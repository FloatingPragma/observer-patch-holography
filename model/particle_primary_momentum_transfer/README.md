# Fourier records and momentum

A coherent detector compares spatial offsets and source times while
retaining one observation origin, every outcome and the quantum reference.
Its [source-bound proof](PROOF.md) identifies the limiting original success
probability with a joint energy/momentum aperture kernel on the
relative-observation state. Finite quadrature, clock and boundary errors
use the actual primary source. Nonzero spectral weight and a particle
dispersion relation require additional response estimates.

Run `python3 -m model.particle_primary_momentum_transfer --check` to replay
the exact [receipt](results.json). Large source and selector matrices are
specified without execution or an efficiency claim.
