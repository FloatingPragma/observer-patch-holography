# Coherent spatial patterns and energy

A checkerboard pattern of neutral pair probes cancels part of the actual
Wilson hopping response. The unchanged selected state consequently has
a sharper populated energy band in this coherent detector. Its finite
cube symmetry label is A2g; this label does not determine a particle spin
or a physical momentum.

The [proof](PROOF.md) gives the source cancellation, original weights and
complete-clock errors. Run `python -m model.particle_primary_staggered_response --write`
and `python -m pytest -W error model/particle_primary_staggered_response`.
