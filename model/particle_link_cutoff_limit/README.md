# Removing the electric cutoff at fixed volume

Native word cutoffs approximate the same finite-volume Wilson Hamiltonian
in its electric form domain. Its ground energies converge, and cooled
states have trace-norm subsequences supporting complete bounded detector
histories on the same clock. A rational two-block bound encloses uncut
rotor energies from finite matrices. None of these statements takes a
physical spacing or infinite-volume limit.

See [the proof](PROOF.md). Run `python -m model.particle_link_cutoff_limit`
or `python -m pytest -q -W error model/particle_link_cutoff_limit`.
