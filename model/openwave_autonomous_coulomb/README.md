# Autonomous electric attraction

A native charged particle moves under one finite Hamiltonian with its
reference charge and all allowed flux circulations. Its actual link current
obeys charge continuity, and the electric energy produces an inward
current acceleration. Complete arrival probabilities follow from the same
Hamiltonian without position pinning. This explicit specialization retains
the native gauge coordinate but sets other interactions to zero; it does
not transfer the interacting model's ground state or physical parameters.

See [the proof](PROOF.md) and [the complete receipt](results.json).
Run `python3 -m model.openwave_autonomous_coulomb --check`.
