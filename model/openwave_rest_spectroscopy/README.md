# Operational baryon rest energies

A finite quantum register measures the full interacting source energy of a prepared baryon. The declared strong action fits five inputs; its weak contact is then included without refitting. The neutral preparation has three substantial lines near 0.939548, 0.939571 and 0.939580 GeV. The charged preparation has a dominant line near 0.938280 GeV. Complete pointer records retain preparation failures and the reference charge.

The [proof](PROOF.md), [source](source.py) and [receipt](results.json) distinguish finite spectral lines and apparatus resolution from physical infinite-volume masses or decay widths. The neutral reference in this box is massless; the fitted three-family massive Dirac construction is a separate source.

Run `python3 -m model.openwave_rest_spectroscopy --check` and `python3 -m pytest -q model/openwave_rest_spectroscopy/test_spectroscopy.py` from the repository root.
