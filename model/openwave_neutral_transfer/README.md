# Neutral particles can move

A gauge-neutral spin-half three-fermion packet transfers between sites of the
actual four-cell native field source. Its first nonzero moment is exactly
−3i√2/64, and a complete-source remainder bound proves positive arrival
probability. Every matter, scalar and link mode is retained. This is a finite
transport result; identifying a physical neutrino requires a dispersion and
observer attachment. See the [proof](PROOF.md) and [replay](results.json).
