# Two-charge propagation and interaction

On the selected eight-site source,28 local pair preparations span each
charge-two sector. Actual Hamiltonian transitions and complete local
records generate every operator there. The [proof](PROOF.md) constructs
all pair-response detector outcomes and certifies a nonzero interaction
and response between distant sites on the same clock. The
[continuum construction](CONTINUUM_PAIRS.md) also proves nonzero separated
charge-pair preparation with a finite energy bound on that source. It reuses the
finite algebra and native instrument theorems. This is a complete finite
source experiment; a relativistic particle assignment and asymptotic
scattering cross section require a further source-limit attachment.

Run `python -m model.source_charge_scattering --check` or
`python -m model.source_charge_scattering --check PATH` to rebuild and
compare the complete certificate. Tests are under this package. Exact
source blocks and integer Gram minors certify the calculation; no finite
energy level is labeled a measured particle.
