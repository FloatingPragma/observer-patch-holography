# Entropy response of spatial regions

The finite Wilson field supplies an explicit restriction to a region,
a faithful regional state at finite temperature and its modular energy.
Physical Gauss constraints preserve boundary charge sectors; their center
weights cannot be discarded or called geometric area. The
[proof](PROOF.md) connects these data to the finite entropy first law.
Rational spinor/flux controls execute the same construction inside the
208-state source, without assigning those internal cuts a spatial radius.

The regional modular energy differs from the bare local Hamiltonian.
Identifying it with a geometric diamond energy and deriving an area
response require additional properties of the spatial state family.

Run `python -m model.particle_spatial_modular_response` for the certificate,
or `python -m pytest -q -W error model/particle_spatial_modular_response`.
