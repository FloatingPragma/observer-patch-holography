unchanged selected source. Their four cube classes give proportions
0:1:2:3. The constant field is elastic; every other class has inelastic
weight, and a complete finite-clock analyzer retains positive original
mean contrast. Each native representation also has a strictly negative
source hopping expectation and nonconstant density shells. The complete
density event has a controlled original probability and conditional mean.
These are even density observables, distinct from the odd particle-creation
fields. No particle mass is assigned.
