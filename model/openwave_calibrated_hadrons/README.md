# Native hadron masses with explicit calibration

A positive baryon-density current separates the nucleon and pion energy
scales while retaining every native colour sector. Three action coefficients
are calibrated to the proton, neutron and charged pion in one electron unit.
The resulting neutron-proton gap permits beta decay kinematically. Neutral
pion, vector and Delta comparisons expose failures of this candidate; the
three fitted masses are not independent predictions.

See [the proof](PROOF.md), [inputs](inputs.json), and [complete results](results.json).

Run `python -m model.openwave_calibrated_hadrons --write` or `--check`.
