# Nuclear masses with a dynamical electric field

The native nuclear source can be dressed with a complete compact gauge field
without discarding its integer fluxes. Exact ground-energy bounds retain
all field polarization and the inherited electron conversion. This member
leaves helion too light and alpha too heavy; a positive field extension with
only its common vacuum subtracted cannot repair alpha. A physical
electromagnetic correction needs a common source and calibration rule that
passes both held-out nuclear masses.

See [the proof](PROOF.md) and [complete receipt](results.json).

Run `python -m model.openwave_nuclear_em_transfer --write`, then
`python -m model.openwave_nuclear_em_transfer --check`.
