A double at port 0 of one echosahedron can repair with either port 1 or port 10. Each repair leaves a different readable pair. The shared port ends with one load in either case. The two permitted repairs cannot join when the public record retains the seam on which the pair is read. ## Local priority control

The control stores a fixed priority in the location of another sharp double, on the disjoint native seam (2,3). The apparatus reads the first rail against vacant port 4 through seam (2,4). The echo, sharp agreement projection and inverse echo read the priority without moving it. Before acting, the controller probes both repair seams with the same reversible readiness queries, in the requested order. On every reachable sharp state these queries restore the state and collars. When both repairs are ready, only the request selected by the stored priority can commit. The other request is deferred and recorded. A lone ready request can always commit. The apparatus supplies the rail-to-seam assignment and serves both requests.

For each of the three doubled-port preparations and each of the two prepared priorities, the two request orders end in the identical material state with identical pair flags. Every suffix of strict attempts leaves that state fixed. Either priority can win when both seams are ready. The comparison fixes the token as part of the initial material state. Reversing the requests can change the chronological attempt log, including which request was deferred. The measured uniqueness concerns the terminal material state and accepted pair identity.
