## Replay

In a checkout, run from the RER repository root. In the standalone archive, run from the extracted directory containing `model/`. Use Python 3.12 with the pinned dependencies. The replay checks the saved detector results against fresh calculations.

```sh
python -m pip install -r model/requirements.txt
python -B -m model.candidate_laws.interval_echo.openwave.replay
python -B -m pytest -q model/candidate_laws/interval_echo/openwave
```

The standalone archive freezes the earlier row-4 and row-30 experiments, generator, boards and tests named in its own manifest. Later seam-origin, reversible-memory and other experiments in this checkout require their separately cited sources. It can be replayed offline once the Python dependencies are installed. The bundle's root manifest identifies each included file by SHA-256. Broader theory references in the supporting notes use the full RER checkout.
