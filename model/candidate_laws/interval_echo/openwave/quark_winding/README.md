## Reproduce the observations

From the RER repository root, the regression tests recompute both complete receipts, compare the primary tour with its independently archived predecessor and reconstruct the imposed angles from terminal ports.

~~~sh
python -B -m pytest -q -W error model/candidate_laws/interval_echo/openwave/quark_winding
~~~

To export fresh observations, supply unused output filenames.

~~~sh
python -B -m model.candidate_laws.interval_echo.openwave.quark_winding.measure --output /tmp/endpoint-charge.json
python -B -m model.candidate_laws.interval_echo.openwave.quark_winding.phase_control --output /tmp/endpoint-third-turn.json
~~~
