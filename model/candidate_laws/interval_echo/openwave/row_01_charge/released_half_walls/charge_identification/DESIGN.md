# Local charge calibration on sharp binary stocks

Use the archived complete terminal word banks for both stock sizes, both signs, both contrasts, each release time and all four boards. Treat this as a reanalysis of those records. For window lengths 2, 3, 4, 5 and 6 consecutive sites, count the original launches for which the two separated gates contain the only two walls and the wall-centred windows are disjoint. Require every window touching the first wall to have the same word as its counterpart at the second, and all other windows to alternate. Count failures as well. Report the native 14-port level-zero, one-ordinary-load, time-three cohort as the example.

Represent any homogeneous additive local read on those windows by a real lookup table. On both alternating window words the excess response must vanish separately. Calibrate the complete ring against known load on a finite set of sharp stocks formed by appending a binary prefix to a block of zeros, moving one bit, and returning to zeros. Include the all-zero stock, and pad to the physical even ring length. Prove that these closed-stock calibrations fix the response of every ring word, then determine the charge in each wall's patch without using the two-wall voltages to set the normalization. Check the calibration identity for every possible local word using exact integer window histograms. Compare a raw two-ended contrast profile, its normalized version, a redistributed nonlinear profile and two elementary miscalibrations. These are mathematical checks and calculations on recorded ternary outcomes. Universality requires measured locality, translation covariance, an additive read, two local vacuum zeros and independent whole-ring normalization. OW-01 also requires an electric interpretation.
