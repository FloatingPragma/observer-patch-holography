# One internal matter oscillation on the intact blank federation

The four-port result and the sharp-repair return losses are known. On the blank carrier every one-unit state evolves under 48 I plus half the port Laplacian. This experiment retains that construction and changes the spatial preparation and measurement. Use all 12 ports of every cell on the 20-, 80- and 320-cell boards. Pair antipodal ports by the measured three-link internal distance. Within each cell assign amplitude +1 to each axis containing an intercell gateway. Give every remaining antipodal axis the same negative amplitude so the six axis amplitudes sum to zero. The local profile comes from the isolated cell and the gateway locations. An exploratory check had identified this profile's internal frequency and equal amplitudes at gateway ports before this protocol. The preparations are deliberately coherent. The medium has no patterned writes.

Prepare the all-cell wave at rest. At one gateway compare it with the uniform one-load reference using four relative phases and a local hand on matched preparations. Repeat with intra-cell exchange doubled, preserving every intercell link, route and source. The relative rest frequency should double on this control. Use the first five distinct nonzero spatial eigenvalues of the owner graph with the measured profile norm as the vertex weight. In each eigenspace project the first supported vertex to select a basis-independent launch. The wave multiplies each cell's internal profile by one spatial amplitude. An inverse spatial preparation and a home-port read detect a departure from a single temporal frequency. A bond read on the shared gateway ports independently measures the variation across owners. Retain all misses and clock outcomes. All timing, controlled phase preparation and readout rotations belong to the apparatus.

Separately decompose these sources into amplitudes equal on antipodal ports and continuous through the gateways, with zero sum in each cell. Such amplitudes are exact eigenfunctions at the rest frequency. Report their full dimension, and the stationary fraction of each prepared spatial wave. Purely dispersing matter with positive speed requires a different frequency at each positive wave number. Inject the same internal profile at a single cell and survey the free arrival of that matter at distances of at least two intercell links. Intercell transport and a stationary component can coexist. Operators are also checked in a same-geometry control with modified intracell exchange. Preserve bounds and check which measurements can be ascribed to one propagating mode. This is a local exploratory experiment; no OpenWave prospective registration is claimed.
