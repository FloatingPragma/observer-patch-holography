## Measuring the charge on a complete receiver

Every allowed dimer on both the source-free host and the accepted flight contains one load zero and one load two, with blank internal and inter-dimer memories. A routed balanced pointer reads the sum using complete ternary native refocusing pulses. In the parity setting both neutral orientations leave the pointer on 20, while either single charged replacement puts it on 02. In the sign setting the positive and negative replacements give opposite deterministic outcomes, and the neutral preparations give a balanced pointer. The two neutral orders impart the same complex amplitude on each output, preserving arbitrary superpositions and any entangled reference. This makes a nondemolition charge read compatible with the incoming energy measurement on the same stock. The difference of *any* uniform additive load charge from the local reference is zero on a complete dimer. Written-memory contributions also agree because all working memories are blank. A single rail can have a nonzero polarization; the enrolled receiver is a full dimer.
