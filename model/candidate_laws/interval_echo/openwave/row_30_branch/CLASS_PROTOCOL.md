# Class-specific free waves

The two groups in the full-band spectrum and their association with gateway geometry were known before this protocol. The internal graph of eight cells has four direct edges, and that of twelve cells has ten. The full-band squared generator also gives opposite signs on edges within the two classes at the midpoint of their frequency gap. This follow-up asks whether either class by itself carries a narrow dispersive branch. Keep both classes, geometries, frequency conventions and all outcomes.

## Independent spatial design

Class membership uses the three pairwise internal distances among the gateways of each cell: (1,2,2) or (2,2,2). Use the uniform internal-seam orbital in each selected cell. Test two fixed spatial Laplacians for each class. The first is the induced graph of real intercell seams with both ends in the class, with its own degrees. It can have disconnected components. The second is the Schur complement of the full 20-cell unit-weight Laplacian over the complementary cells. This harmonic-extension metric measures the minimum graph Dirichlet energy with given class amplitudes. It includes paths through the opposite class, uses no fitted hopping and does not modify the flight. Normalize squared wave number by the ordinary norm of the class's cell amplitudes. Group every degenerate spatial eigenspace; retain its full multiplicity.

## Spectral comparison

Project each class onto its associated cluster within the 20 lowest full-generator states (eight lower, twelve upper, fixed by the exploratory gateway diagnostic). Report the original orbital's absolute weight in its cluster at every momentum and the conditional frequency centroid and RMS width. Require at least 80% absolute weight, at least one held nonzero squared wave number beyond the speed anchor, and width below 10% of the first shift at every momentum including zero. Report failures independently. This asks whether frequencies can be distinguished from the spread of the selected signal.

Use the zero-momentum centroid of each class as a rest reference for measuring *relative* shifts. For the two-branch interpretation use their half-separation as a single gap m. Each positive frequency is measured from their common midpoint: the upper branch should move up in energy, the lower branch down. Fix c² from the first nonzero momentum of the upper class by (2mβ+β²)/λ and test both branches at every remaining λ. Record the relative shift errors; the cutoff is 5% and the shifts must have the predicted sign. Always record the predictions of the same-speed tangent parabola and how far it lies from the square-root prediction. Call the functional comparison resolved only where these differ by more than 5% of the predicted shift. This is a spectral half-gap calibration in native units. A claim about a measured rest mass needs a patch clock and a local source and phase reference that resolve that gap.

Also test each class *separately* allowing an independent positive-mass and speed with an arbitrary common energy offset within that branch. For any positive-mass dispersion with a positive relative shift β₁ at the first nonzero λ₁, every higher λ must obey √(λ/λ₁) ≤ β/β₁ ≤ λ/λ₁. Negative shifts in this convention, discrete classes without a held momentum, and a class that admits a parabola are individually identified. Classification uses the admitted interval and measured linewidths; an allowed interval by itself supplies no mass measurement.

## Records

Select the lowest-index cell of each gateway class. Start on its first internal seam, let every seam act throughout flight, and query each cell's internal-seam pair detector at exposures 0, 32, 128 and 256 on fresh preparations. Record every local seam and quiet from 262,144 trials per setting. Report class-specific nonlocal reads and total counts by class with the per-cell denominators. A transfer is resolved where a target sees at least 25 pair clicks. The spatial grouping here uses the recorded receiver address. It does not assign a frequency band to a single click.
