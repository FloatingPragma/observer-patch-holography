# Local clocks and a held round-trip signal on one cell

OpenWave OW-27 asks for light bending, gravitational time dilation or Shapiro delay. This finite test asks the narrower question whether two candidate static sources give a common clock rate and radar delay to independently calibrated material probes. Existing collar measurements already predict a tag-selective contact energy. The empty write is a separate candidate because it changes the accessible paths for both tags. Source and detector choices below were fixed before generating the count banks. [Official simplest test and M10 comparison](https://github.com/openwave-labs/openwave/blob/d4fc3e4046c472f4ad38468df8dddfa1f97bac97/MODELS.md) · [Previous source calibration](../../../../experiments/interval_echo_einstein_station/native_tidal_response/README.md) · [Empty-seam scattering](../row_23_coupling/README.md)

1. Use the first of the six belts of cell zero, its ten perimeter edges and its pole adjacent to belt positions 2 and 8. These two transverse contacts are protected by prepared stationary memory. A sharp unit stays parked at the pole. Compare a zero-memory-magnitude written sham to magnitude-two even and odd coin superpositions, which have equal empty-sector source energy. In a separate experiment prepare the native empty write on perimeter edge 2–3 on the sham board. All unlisted exterior contacts and the one-port degree reference are shuttered during both instruments. Test the registered exchange and contrast together, and a changed-law control with contrast set to zero. Report embedded native port addresses. A controlled single-cell waveguide and sharp relay detectors are laboratory services.
2. Calibrate local clocks on separate copies by leaving a single perimeter bond and the same two stationary source contacts enabled. Launch a single unit or double load on the first clock port, read the second after 96 uniform waits of 1/16 through 6 exchange units. Estimate the frequency and fringe amplitude independently from the counts. A bond with vanishing transfer has no operational clock rate. Also read an unaffected bond as the reference clock. Compare each bond's source/sham frequency ratio between the two tag clocks. A universal lapse predicts agreement.
3. Without using clock or transit outcomes to select parameters, release a sharp calibration-matched unit or double packet at port 0 with the full ten-bond perimeter enabled. Measure first arrival at antipodal port 5 at unit intervals up to 4,096 readings. A click releases a fresh sharp tag there and starts the return leg to port 0 with the same cadence. A miss projects out just the detector port. Report the unconditional probability for both clicks by 8, 16, 64, 256 and 4,096 reference units, including attempts that failed to return. Check gates with the altered-contrast law, an equal-energy odd source, and the surviving alternative path around the empty write. On the registered law also repeat at half-unit detector cadence for the same total exposure to test sensitivity to monitoring. The radar clock is at the emitter, away from either source.
4. A common metric acting alone on the matched transport standards predicts the same source-minus-sham change for both tags. The independent clock records give a second test of the same universality. Evaluate differences at all frozen deadlines with a simultaneous 99% Hoeffding bound for all readouts. No fit of a spatial metric from transit data is permitted. The gates compare material clocks and probes. They cannot identify null radiation or exclude additional common gravity below material effects.

For the stationary sources also form a specific no-spatial-change forecast from the independently measured unit-tag clock rates. Weight each blank perimeter exchange projector by its bond's relative clock frequency, remove the common uniform frequency, and propagate the radar packet with those weights. This is the finite fixed-ruler hypothesis being tested. A spatial metric could also vary, so the primary criterion remains agreement between standards with the same blank evolution. This forecast is undefined across a bond that has no clock. Use the unit-tag clock for forecasting both probe species.
