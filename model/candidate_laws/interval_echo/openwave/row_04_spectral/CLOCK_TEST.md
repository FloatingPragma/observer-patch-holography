# Can the original 32 spectroscopy programs run from a local transfer measurement?

Use the [primary spectrometer](../row_30_selective/PROTOCOL.md) and its unmodified archive of 32 angle arrays. Its fixed-duration failure at strength ½, the scalar rate of the oriented-material generator, and the positive five-query source are known. This supplementary test concerns a second preparation route. No result of a pair release or of the port-9/11 receiver may enter its calibration.

On fresh copies of an isolated marked flippable seam start with the load at its arrow head. Read the opposite port after exposing that one native seam. Use all twelve appointments $t_j=2^j/256$, $0\le j\le11$, and $2^{39}$ binary trials per appointment. Select the first appointment whose transferred count exceeds $1/8$ of the bank. The decoder receives counts, bank size and appointments only. Before that reading, use the declared spectroscopy range $1/2\le|\kappa|\le128$ to disambiguate the increasing half-cycle. Infer a simultaneous 99% interval for the magnitude from Hoeffding bounds, retaining a missed or ambiguous calibration. Both possible signs get the same service times: a real geometry target may have a conjugate source word. Zero strength is a deliberate non-detection, not a successful calibration.

Test both signs at magnitudes ½, 1, 2, 4, 8, 16, 64 and 128. Use PCG64 with `SeedSequence([44130, index])` in increasing magnitude, positive then negative; use index 16 at zero. Require source fidelity above the old 0.98 threshold for **every one of the 32** real analyzer columns with the inferred waits. Propagate the measured rate interval through the full ordered control word with operator-norm bounds. Record the raw counts, inferred magnitude and interval, largest certified state error, minimum all-column fidelity bound, and the two enrolled port returns. Include any failure. A correct answer only for the two persistent modes does not pass the calibration test. These runs test an addressed clock for a spectrometer and its detector, not spontaneous generation of a physical strength.
