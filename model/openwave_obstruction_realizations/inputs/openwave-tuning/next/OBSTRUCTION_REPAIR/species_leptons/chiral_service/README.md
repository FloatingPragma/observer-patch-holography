# Chiral mass protection

The Wilson service allows additive mass terms. This package verifies an
explicit electric obstruction for its spatial-overlap alternative and
constructs a complete domain-wall Hamiltonian with the same fractional
charges and clock. Its boundary currents and free register masses
intertwine exactly; all bulk bands are retained. Finite-wall axial leakage
is explicit, with a proved scalar-shift suppression bound. A separate
Euclidean Ginsparg-Wilson control has the required action Ward identity.

The interacting charged-mass prediction requires a gauge-vacuum residual
bound and a pole calculation. See [the proof](PROOF.md),
[results](RESULT.json) and [source](source.py).
