# Retaining Coulomb energy in the bound

The exact positive Coulomb variance tightens the frozen ring's neutral
and charged lower bounds. It uses all65536 occupation words, the full
free comparison spectrum and the complete orthogonal Fock complement.
No source coefficient changes. The K4 neutral energy-excess bound falls
to0.263 and the prepared Green error to3.753e−5.

Ground-state fidelity requires a separate eigen-count argument. See
[the proof](PROOF.md), [all bounds](RESULT.json), and
