# Polarized beta emission

The actual native weak current produces a strictly parity-odd observer
statistic on a finite outgoing ring. The calculation retains all charged,
neutral and reverse pair channels, and a full-source bound includes every
multipair state. The same strong action uses the disclosed mass and axial
calibrations; the neutral tensor uses disclosed oscillation inputs. This
one-dimensional finite-time result does not assign a physical neutron
lifetime or three-dimensional angular coefficient.
