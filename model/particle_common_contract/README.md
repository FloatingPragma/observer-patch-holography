# Open Wilson source comparison

This package defines the open Wilson gauge-field family, its
Gauss-constrained polynomial preparation, retained conjugate reference and
Hamiltonian clock. It is a separate mathematical comparison to the
[official common construction](../SPEC.md). Its sixty-mode cells, source
spectrum and refinement are not the CCF-LT-2 native carrier or predictions.

The [finite contract](PROOF.md) and its consumers reject mixed
preparations, reference clocks, regulators and unclassified comparison
results. The [physical boundary detector](../particle_physical_boundary_state/PROOF.md)
retains every charge outcome and nonzero Wilson-loop sectors. The
[locality consumer](../particle_primary_locality/PROOF.md) bounds complete
boundary/reference records under a remote plaquette intervention on that
same Wilson state and clock.

Run `python -m model.particle_common_contract --write`, then
`python -m model.particle_common_contract --check`. The exporter constructs
finite specifications and verified bounds, without executing the full
spatial matrix or preparation tape. Applying these results to another
source requires its actual source/state/reference/clock comparison.
