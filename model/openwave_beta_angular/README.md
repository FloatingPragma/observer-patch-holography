# Three-dimensional beta angular records

The actual native neutron-to-proton current yields the allowed angular
coefficients a=-0.106544, A=-0.119435 and B=0.987109 from the calibrated
axial coupling. Complete cubic sources also have a rigorously negative
parity-odd momentum record, including a bound on every multipair channel.
The two-contact form factor and calibrated input ancestry are explicit;
the calculation supplies no physical neutron lifetime.

Run `python3 -m model.openwave_beta_angular --check` and
`python3 -m pytest -q model/openwave_beta_angular`.
