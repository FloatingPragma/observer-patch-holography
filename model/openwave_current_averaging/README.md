# Weak conversion from the complete native current

Exact free-clock averaging reduces the full native current's prepared orbit
to a two-state conversion with maximum probability 64%. Its diagonal current
energies reduce the peak from the unit value of an assumed resonant pair.
A uniform bound keeps the unfiltered source within eight parts in ten million
of that probability at a declared weak coupling, retaining every other
outcome. This is finite-box conversion, without a measured lifetime or
continuum decay claim. See [the proof](PROOF.md) and
[the complete certificate](results.json).

Run `python -m model.openwave_current_averaging --check`.
