# Unequal native quark masses

An explicit vectorlike extension couples the actual native hypercharge
current to six additional singlet pairs. Its complete free mass matrix
makes up-type branches lighter than down-type branches, while preserving
the lepton coefficients and a full charged-sector energy floor. All heavy
partners and native spectators are retained. The [proof](PROOF.md) and
[results](results.json) separate the exact splitting from its unproved
physical quark identification and state the added architecture inputs.

Run `python3 -m model.openwave_vectorlike_flavour --check`.
