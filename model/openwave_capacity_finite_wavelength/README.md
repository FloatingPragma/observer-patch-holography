# Finite-wavelength capacity transfer

An exact comoving reduction turns the supplied cosmological perturbation
equations into a controlled expansion in squared wave number. Outward
interval evolution and a complete fourth-order remainder certify metric
and matter responses for two nonzero wavelengths over a specified late-time
preparation. The physical horizon, clock and primordial preparation require
an attachment to the native observer process.

Run `python -m model.openwave_capacity_finite_wavelength --write`, then
`python -m model.openwave_capacity_finite_wavelength --check`.
The equations and error argument are in [PROOF.md](PROOF.md).
