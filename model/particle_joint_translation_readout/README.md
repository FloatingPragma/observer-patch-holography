# Position and crystal momentum of the finite field

The same periodic field has exact simultaneous translations of matter
and gauge links. A complete position detector samples an occupied mode's
site and keeps the vacuum outcome. Joint field/reference translations
give conserved crystal-momentum records. Reading position changes their
distribution with exact Born weights, and finite uncertainty follows
for these actual observables.

The [proof](PROOF.md) retains the charged reference and every number
sector. These are whole-system finite records, without an identification
with one particle's momentum or a universal physical uncertainty constant.

Run `python -m model.particle_joint_translation_readout` for the certificate
and `python -m pytest -q model/particle_joint_translation_readout` for tests.
