# Energy windows from the original source

Local current identities control the energy spread of the actual phase
experiment more sharply than a full operator norm. The second moment is
bounded by a constant divided by spacing, using the actual mean electric
energy to remove the link-cutoff dependence. This gives a
positive finite energy window with the same selected state and complete
clocks. Its guaranteed probability decreases with capacity; a surviving
fixed-energy particle response requires further spectral control.

The [proof](PROOF.md) states the exact source and error bounds. Replay with
`python -m model.particle_primary_weighted_spectral_tail --check`.
