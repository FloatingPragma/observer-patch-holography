# A positive-energy window from complete records

A changing correlation can certify original weight between two positive
energies, after accounting for slow response, negative transfers and
ultraviolet tails. The [proof](PROOF.md) uses the selected source's cooling
and time-filter bounds; an actual primary contrast is an explicit input.
Exact finite controls distinguish a surviving excitation from a zero atom
or a response escaping to infinite energy. No particle mass is assigned.

Run `python -m pytest model/particle_positive_window` for the exact controls.
