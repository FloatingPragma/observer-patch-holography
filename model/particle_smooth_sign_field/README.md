# Smooth fields with controlled local records

A fixed positive smooth regulator gives the gauge-coordinate field an
exponentially summable local interaction. Its explicit polynomial
approximations control complete local quantum records at fixed time,
uniformly in volume, including the electric field and every fermion
occupation. The [proof](PROOF.md) retains the same state and clock and
gives finite-volume and representation error plans.

This is a declared alternative action. Its interacting chiral and
relativistic continuum limits require separate proofs. Zero smoothing
is needed only to recover the original discontinuous-sign action;
ordinary finite-range Wilson dynamics is another allowed design.

Run `python3 -m model.particle_smooth_sign_field` for the certificate.
