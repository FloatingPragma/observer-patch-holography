# Rotating a native charged packet

The same kinetic and pairing source supports a moving charged packet whose
measured spin integrates to one half. Literal cube rotations give a two-copy
apolar field period of 180 degrees, an oriented spin-frame period of
360 degrees and an interferometric source-amplitude period of 720 degrees.
All preparation failures and detector complements are retained. The field
is a declared tensor readout, and the spin integral is canonical excess spin;
continuous spatial angular momentum and a physical particle identity require
separate attachment. See [the proof](PROOF.md) and [complete records](results.json).

Run `python3 -m model.openwave_spin_frame_records --check` and
`python3 -m pytest -q model/openwave_spin_frame_records`.
