# Baryon charge profiles and radii

The calibrated strong source gives a heavier neutron-assigned state with
positive inner and negative outer charge. One shared length converts its
complete native charge records into charge-radius and form-factor intervals.
The two measured nucleon radii cannot both be matched by this source with
any common length. Every preparation failure is retained.

The [proof](PROOF.md) states the exact current, source and orientation-average
domains. Run `python -m model.openwave_baryon_form_factors --write`, followed
by `--check` and its tests, to reproduce the records.
