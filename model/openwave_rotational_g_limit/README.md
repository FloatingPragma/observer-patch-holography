# Magnetic moment and precession approach the same value

The native Dirac current gives a magnetic coefficient approaching two in a
controlled low-momentum limit. Static moments and actual finite-time
precession use the same localized source, angular momentum and rest-energy
reference. Exact finite matrix identities replace large lattice solves.
At the most weakly relativistic member the analytic precession error is
below 0.004863. This is a declared regulator and parameter limit, without a
physical electron mass or fine-structure calibration.
