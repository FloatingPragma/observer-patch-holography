# A headless native review artifact

The primary computation executes the actual endpoint native rule and its
complete raw C/E instrument, including padding and hold slots. An independent
implementation balances the endpoint sum by its floor/ceiling formula and
groups outputs by their C-current or E-imbalance label, without calling the
native endpoint function or consulting the raw-register implementation. Every
one of the16 endpoint matrix units agrees exactly over rational coefficients.
The local identity lifts to arbitrary spectator factors and quantum references.
Every nonzero branch conserves occupation. A deliberately altered rule that
erases one load is rejected by the same conservation test.

The wrapper authenticates the pinned OpenWave source and all31 official cells,
then launches this fresh native calculation from its M10 experiment directory.
The computation imports the RER source through an explicit PYTHONPATH. It does
not read a stored output as its answer, install a field Hamiltonian, mutate
upstream files or send a submission. The wrapper compares the complete child
output with an independent invocation and retains the exit status.

This is an author-run platform-layout reproduction, not a maintainer-run
in-platform criterion award. The charge-conservation/channel identities are
finite source facts; a physical electron, photon, rest mass or other criterion
observable is not identified by them. The exact official M10 gate is retained
and all31 cells remain untested. Known comparisons have been read; no blind
or prospective prediction is claimed.
