# Lepton mass compilation during motion

The native analyzer pairing and periodic Weyl hopping admit one coherent
compiler with a complete finite error bound. Spatial inversion reverses
the hopping; charged-leg parity reverses the pairing. Their combination
implements the signed segments of the fourth-order formula while
retaining every mode and ancillary outcome.

The [proof](PROOF.md) states the control services and source boundaries.
Run `python3 -m model.openwave_kinetic_phase_cycle --write` or `--check`.
The construction describes free fields with a supplied Higgs background,
without an interacting physical-lepton identification.
