# Nuclear charge splitting

The exact native isospin map fixes the strong mirror gap at1.29333251 MeV,
so an isospin-scalar nuclear fit cannot reproduce the observed0.52952556 MeV.
An inherited-alpha Coulomb comparison has the correct sign but leaves both
helium masses outside their certified intervals. Every fixed-charge spin
multiplet and the full source complement are retained. See
[proof](PROOF.md), [source](source.py) and [results](results.json).
