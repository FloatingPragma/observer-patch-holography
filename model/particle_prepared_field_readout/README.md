# A prepared field and its detector

A gauge-invariant finite preparation evolves under one fixed field action
and clock. A complete detector records how many of sixty fermion modes
remain occupied at the origin. The source proves a nonzero transfer event
and bounds every outcome, with a composed comparison to periodic
exact-sign dynamics. The code calculates exact resource and probability
enclosures without allocating the very large field.

The [proof](PROOF.md) specifies the state, boundary references and error
budget. Physical particle identification requires an interacting
relativistic refinement of these same records.

Run `python3 -m model.particle_prepared_field_readout` for the certificate,
or `python3 -m pytest -q model/particle_prepared_field_readout` for its checks.
