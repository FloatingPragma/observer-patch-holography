# What starts a particle clock?

A complete energy-conserving native collision cannot create a rest-mass
phase in any energy-compatible measurement branch. Exact battery records
and a two-copy exchange control identify where a phase resource enters.
Relative coherence between degenerate copies has zero free frequency;
exchange oscillations use the declared interaction strength.

The [proof](PROOF.md), [producer](source.py) and [receipt](results.json)
retain every inactive state, failed battery word and readout work term.
