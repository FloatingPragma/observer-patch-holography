lepton number minus one, raw baryon-three number zero, and odd fermion

All native local Yukawa words preserve lepton number \(L\) and baryon
number \(B_3\). Each hopping coordinate connects indices in the same
native family, on which both weights are constant. Hence both charges
commute with the complete spatial Hamiltonian, for either boundary
choice below. On the full native fermion carrier,
\((-1)^N=(-1)^{L+B_3}\). The operator's neutrality therefore uses an
actual current; no charge is set to zero by naming the candidate.

Repair transparency is a different property. The independently rebuilt
six-site dark preparation has exact particle number four relative to
its vacuum and zero number variance. Its source supplies no identification
of that current with the R15 electric current. Repair transparency and
a number-sector energy offset provide no neutral rest-mass attachment.
