# Native clocks and finite curvature

The same native clock source gives an exact weak-source log-lapse response,
including the finite geometry-coordinate correction. Commuting lattice
differences then give exact linearized Bianchi and gauge identities, with
all boundary cells retained. The nearest-neighbour Poisson and curvature
stencils have an explicit nonzero correction.

The metric interpretation and a nonlinear physical Einstein limit remain
separate requirements. See [the proof](PROOF.md).
