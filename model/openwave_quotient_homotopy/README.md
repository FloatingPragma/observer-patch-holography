# A continuous loop behind fractional charge

The native charge representation admits a continuous generating loop of
(SU(3) times U(1))/Z3. Quark phases of2pi times2/3 and-1/3 close together
with their colour phases. Every120/364-state Gauss coordinate is checked.
The electric-string state has uniform conjugate-angle density, so the
loop theorem does not identify a localized particle texture.

See the [proof](PROOF.md), [producer](source.py) and [receipt](results.json).
