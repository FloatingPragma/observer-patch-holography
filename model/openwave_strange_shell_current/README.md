# Native strange current at an open bulk energy shell

The complete bulk Lambda source pole has a certified nonzero native weak
current response. An exact CAR identity bounds the vertex norm squared
between six and seven times the inherited Cabibbo factor on every compact
Lambda state. The full pole's compact probability transfers the lower
bound without a fitted ground vector. All compact five-body outputs,
noncompact outputs and probe failure are retained. The stated probabilities belong to the
normalized relative-coordinate total-momentum-zero fibre; a normalizable
center-of-mass wave-packet transfer is not executed.

The same strong source has an enclosed proton–pion energy shell. This
package refines its momentum bracket, but does not identify the compact
five-body output with an interacting scattering eigenstate. The on-shell
scattering transfer and physical Lambda lifetime remain open. See
[proof](PROOF.md) and [records](results.json).

Run `python -m model.openwave_strange_shell_current --write`, then
independently `python -m model.openwave_strange_shell_current --check`.
