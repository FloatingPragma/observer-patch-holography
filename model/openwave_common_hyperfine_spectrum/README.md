# Common native hyperfine spectrum

One positive native-current action fits seven disclosed inputs, including a
charge-zero spin-one vector at0.77526GeV and a genuine spin/isospin-three-halves
Delta candidate at1.232GeV. The proton, neutron, charged pion, axial magnitude
and deuteron binding are recalibrated on that same action. The two resonance
numbers are Breit-Wigner calibration conventions, without a complex-pole or
width calculation.

The exact positive quark–antiquark pair interaction is zero on all pure-quark
states and on spin-zero one-pair mesons. Complete baryon, meson and nuclear
spectra retain every channel. The ground-projector distance from the five-input source is about0.0403,
so charge profiles require their own seven-input calculation. Native
weak-current records and complete transfer error bounds are retained; all-Fock count and SU3 fusion bounds test
the common quadrupole/string scale without dropping coloured occupations.
The neutral-pion discrepancy is an explicit held-out control.

`python -m model.openwave_common_hyperfine_spectrum --check`.
