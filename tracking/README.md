# Internal Tracking Index

This directory contains reproducibility and coordination records. It is not
part of the public theory reading route.

- [`claims_scoreboard.md`](claims_scoreboard.md) is the generated claim
  scoreboard (regenerated by `python3 tools/build_scoreboard.py`).
- [`open_issues/open_problem_ledger.json`](open_issues/open_problem_ledger.json)
  is the generated open-problem ledger (regenerated by
  `python3 tools/build_open_problem_ledger.py`).
- [`observation_ledger.json`](observation_ledger.json) is the V3 observation
  ledger source (rendered to `docs/OBSERVATION_LEDGER_V3.md` by
  `python3 tools/build_observation_ledger.py`).
- [`premise_register.json`](premise_register.json) is the V3 premise register
  source (rendered to `docs/PREMISE_REGISTER_V3.md` by
  `python3 tools/build_premise_register.py`).
- [`sm_lagrangian_correspondence.json`](sm_lagrangian_correspondence.json) is
  the Standard Model Lagrangian correspondence source (rendered to
  `docs/SM_LAGRANGIAN_CORRESPONDENCE.md` by
  `python3 tools/build_sm_correspondence.py`).
- [`null_model_scorecard.md`](null_model_scorecard.md) is the generated
  negative-control scorecard (regenerated by
  `python3 tools/check_null_models.py`).
- [`author_contributions/`](author_contributions/) contains the reproducible
  authorship-contribution snapshot and generator.
